# 영역 2 (액트 2 모래 폐허) 맵 타일 작업 명세 (Codex용)

`data/maps.csv`에서 만든 표다 (2026-10-10, 1단계: 마을 + 필드 4 · 2단계: 곁가지 던전 7 · 3단계: 사원 1~3층 · 성소). 규칙은 [영역 1 명세](map-spec-region1.md)와 같다.

- **지금 바닥은 임시**: 액트 1 타일셋(AshCampTiles) 바닥 266 + 가운데 길 265를 맵 전체에 깔아 두었다 (분홍 체크 방지). 곁가지 7곳은 같은 크기의 액트 1 곁가지(굶주린 굴 · 뼈 구덩이 2층 · 목매단 동굴) 바닥을 복사했다. 사막 타일셋이 오면 통째로 다시 칠한다.
- 그림 요청: [codex-act2-art-20261010.md](requests/codex-act2-art-20261010.md) §1-3.
- 기능 엔티티(포털·웨이포인트·NPC·화로·스포너)는 빌드가 관리하므로 메이커에서 옮기지 말고 위치 변경은 Claude에게.
