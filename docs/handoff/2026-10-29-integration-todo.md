# 44·45 1차 통합 때 함께 넣을 것 (2026-10-29 오후, Claude 정리)

44·45 1차 네 갈래(가·나·다·라)는 각자 worktree 브랜치에서 일하고 있다. 브랜치 이름은 `wip/4445-ga`, `-na`, `-da`, `-ra`다.
통합 에이전트는 네 브랜치를 합친 다음, 아래 사용자 결정을 **한 번에** 반영하고 메이커에서 검증한다.
반영을 통합 때로 미룬 이유가 있다. 글귀를 바꿀 파일과 갈래들이 고치는 파일이 겹치기 때문이다.

## 사용자 결정 (10-29 오후 · AskUserQuestion)

1. **게임 전체 용어 통일.** 처음부터 순화어로 쓰던 말들이라 이력상 「되돌릴」 곳은 없다. 새로 바꾸는 작업이다.
   - 「보통」(난이도 이름) → **노말**
     - 바꿀 곳: `data/difficulty.csv`, 웨이포인트 단추, 미리보기 카드 58·64, 게임 안내 「보통 → 악몽 → 지옥」, 도감 「(보통에서 나오는 것)」 등.
     - 난이도 내부 키는 그대로 두고 표시 이름만 바꾼다.
   - 「의뢰」 → **퀘스트** (30여 곳)
     - 퀘스트 추적, 새 퀘스트, 일일 퀘스트, 미니맵 범례 「● 퀘스트」, 게임 안내 「퀘스트 따라가기」, 81 「{웨이포인트} · 퀘스트」, 64 해금 조건 등.
     - 퀘스트 창 제목은 「퀘스트 — 무덤 왕국」으로 이미 맞다.
   - 「소지품」 → **인벤토리**
     - 메뉴 칸, 창 제목, 단축키 줄 「I 인벤토리」, 대장간 모드 제목 「인벤토리 · 망자의 장비」 등.
     - 메뉴 칸 폭에 들어가는지 확인한다.
   - 「파티 플레이」(방 고르기 화면) → **「파티플레이」** (메뉴와 같게)
2. **101줄 밖 「-다」 서술 시스템 알림 63줄(17개 파일)을 전부 새 말투로 바꾼다.**
   - 시스템 안내·결과·오류는 「-습니다 / -해주세요」 또는 명사 끝으로 쓴다.
   - 짧은 사건 연출 줄과 스킬 설명은 「-다」를 허용한다.
   - 예: 「가방이 가득 찼다」 → 「가방이 가득 찼습니다」.
   - 바꾼 줄은 「바꾸기 전 → 후」 표로 보고한다. 사용자가 「변경 보고」를 원한다.
3. **5번 글귀(일시 그림자가 사라질 때 안내 줄) 확정: 「그림자가 흩어졌습니다 · Lv5부터 직접 획득 가능」.** 지금 들어가 있는 「…직접 거두세요」를 바꾼다. 안내 줄 한 줄 안에 드는지 메이커에서 확인한다.
4. **PC Enter 채팅은 하지 않는다.** 엔진 채팅(「/」)을 그대로 둔다. 엔진 ChatComponent에는 입력 칸을 여는 API가 없다.
