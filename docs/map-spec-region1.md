# 영역 1 맵 타일 작업 명세 (Codex용)

`data/maps.csv`에서 생성한 표다. 값이 바뀌면 이 문서도 다시 만든다 (`node tools/build.cjs maps` 후 Claude가 갱신).

## 규칙

- 1칸 = 1월드 단위. 맵 타일 범위: 가로 x = -w/2 .. w/2-1, 세로 y = -h/2+1 .. h/2 (기존 14×8 맵과 같은 기준).
- **포털 줄**: 필드·곁가지 던전은 왼쪽 x = 범위 왼쪽+1, 오른쪽 x = 범위 오른쪽(마지막 칸), 둘 다 y = 0. 포털과 그 앞 2칸은 이동 가능 타일로 비워 둔다.
- 아래 표의 **기능 위치**(입구·웨이포인트·NPC·고정 몬스터·화로·제단) 주변 1칸은 이동 가능하게 둔다. 이 엔티티들은 빌드가 관리하므로 메이커에서 옮기지 말고 위치 변경은 Claude에게 요청한다.
- 장식은 `Decor_` 접두사 이름으로. 빌드는 장식을 건드리지 않는다.
- 악몽·지옥 맵(_nm·_hell)은 보통 맵을 복제하므로 **보통 맵만** 칠한다.
- 몬스터 출현 범위 = 맵 가장자리에서 2칸 안쪽 전체. 출현 범위 안에 큰 벽 덩어리가 있으면 몬스터가 벽 안에 나올 수 있으니 길·공터 위주로.

> **10-10 지형 자동 생성:** `data/map_layouts.csv`에 있는 맵(늪·형장·교수대 숲·납골당 1~3층·곁가지 6곳)은 빌드가 타일을 만든다 —
> 필드는 테마 장애물(늪 웅덩이·무너진 담장·숲 덤불) + 들쭉날쭉한 가장자리 + 포털·웨이포인트·입구를 잇는 자갈길, 던전은 방·통로 미로.
> 이 맵들은 메이커에서 타일을 칠하지 않는다 (다시 빌드하면 덮인다). 장식(Decor_)은 그대로 두고, 필드는 그 자리를 바닥으로 남기며 미로에 묻힌 장식은 꺼진다.
> 피 묻은 황무지(map01)·마을·여왕의 무덤은 아직 칠한 그대로다.
