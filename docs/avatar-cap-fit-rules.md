# 모자·후드 제작 및 얼굴 노출 검수 규칙

2026-10-09 사용자 지시: 모자 생성 시 얼굴 크기를 맞추고, 얼굴을 가리는 문제가 재발하지 않도록 한다.

## 제작 기준

1. 공식 Cap PSD의 origin·zmap·가이드·레이어 이름과 타입은 보존한다. 그림은 지정 paint 레이어에서만 수정한다.
2. 실제 게임의 기본 피부·얼굴·머리 조합을 기준으로 머리 외곽과 얼굴 영역을 측정한다. 이미지 생성 캔버스 크기나 PSD 메타데이터 통과만으로 착용 크기가 맞는다고 판단하지 않는다.
3. 기본값은 얼굴이 드러나는 모자다. 양쪽 눈·코·입이 보이도록 얼굴 영역에 투명한 개구부를 둔다. 테두리가 눈 아래로 내려오거나 얼굴 전체를 덮으면 실패다. 가면 컨셉은 사용자 승인 후 별도 기준으로 제작한다.
4. 얼굴 영역의 위치·크기는 공식 템플릿과 실제 캐릭터 합성으로 정한다. 임의의 고정 픽셀 수나 그림 전체 비율로 추정하지 않는다.
5. 머리 윗부분을 덮는 모자와 목·어깨를 덮는 망토/복장 영역을 구분한다. 모자 그림에 불필요한 어깨 장식까지 붙여 몸과 얼굴을 덮지 않는다.
6. 현재 기본 데모닉 머리와 검수용 흰색 긴 머리에 각각 합성해 색 대비·앞머리·모자 테두리를 확인한다. 머리 교체만으로 후드의 얼굴 가림 문제가 해결된 것으로 처리하지 않는다.

## 등록·적용 승인 조건

- 공식 아바타 편집기의 전체 지원 동작과 앞/뒤/좌/우 방향에서 확인한다. 대기·걷기·공격·시전·피격 등 실제 게임에서 사용하는 동작을 포함한다.
- 게임 내 같은 캐릭터의 모자 미착용/착용 화면을 같은 배율로 비교한다. 1배 픽셀 크기와 플레이 카메라 배율 모두에서 눈·입·표정이 식별되어야 한다.
- PSD 보호 레이어 검사, 업로드 성공, RUID 연결, 실제 얼굴 노출, 전체 동작 검수를 각각 기록한다. 앞 단계 성공으로 뒤 단계를 통과 처리하지 않는다.
- 실제 착용 스크린샷 없이 완료 보고하지 않는다. 얼굴이 가려지면 시각 검수 FAIL로 기록하고 PSD 보정 후 다시 검수한다.
