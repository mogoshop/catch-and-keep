# Codex 요청 — 룬 그림 24종 · 웨이포인트 바닥 문양 (2026-10-09, Claude)

사용자 피드백(10-09 저녁): 룬이 모두 같은 그림이라 구분이 안 되고, 웨이포인트가 칼 휘두르는 NPC처럼 보인다. 코드는 지금 임시 그림으로 동작하며, 아래 그림이 들어오면 **CSV 칸만 채우면 바로 바뀐다** (코드 수정 없음).

## 1. 룬 그림 24장 (필수)

- 등록 위치: `data/runes.csv`의 맨 끝 `icon` 칸에 RUID. 비어 있으면 공용 룬 그림(`ui_icons.csv` `rune`)을 쓴다.
- 크기 약 128×128 정사각형, 배경 투명. 가방 칸·소켓·바닥 드롭에 같이 쓰인다 (칸 안 약 80px).
- D2처럼 **같은 돌판 모양 + 룬마다 다른 각인 문자**. 등급(낮은 룬 → 높은 룬)이 돌 색으로 구분되면 좋다.

| 단계 (드롭 레벨) | 룬 (id 이름) | 돌 색 제안 |
|---|---|---|
| 낮은 룬 (Lv1~) | r_as 아스 · r_mir 미르 · r_keil 케일 · r_nod 노드 · r_baen 바엔 · r_ruk 루크 · r_seb 세브 · r_ireun 이른 | 회색 돌 |
| 중간 룬 (Lv20~) | r_drak 드락 · r_wen 웬 · r_hawin 하윈 · r_kura 쿠라 · r_zel 젤 · r_mor 모르 · r_tab 타브 · r_yel 옐 | 청동·녹슨 주황 |
| 높은 룬 (Lv45~) | r_nox 녹스 · r_kan 칸 · r_sel 셀 · r_ur 우르 · r_xil 크실 | 검붉은 돌 |
| 최상위 룬 (Lv65~) | r_ab 아브 · r_rev 레브 · r_obl 오블 | 검은 돌 + 금빛 각인 |

## 2. 웨이포인트 바닥 문양 2장 (권장)

지금은 메이플 리소스의 파란 마법진(`02c6c4f9…`)을 바닥에 깔고, **아직 안 켠 웨이포인트는 어둡게·켜면 밝게** 칠한다. 전용 그림이 있으면 더 D2답다.

| 키 (`ui_icons.csv`) | 용도 | 크기 |
|---|---|---|
| `waypoint_off` | 꺼진 문양 — 바닥에 새긴 원형 석판·룬 원, 빛 없음 | 약 256×160 (위에서 비스듬히 본 타원) |
| `waypoint_on` | 켜진 문양 — 같은 석판, 각인이 푸르게 빛남 | 같은 크기 |

- 사람·NPC 형태 없이 **바닥 장식만** (플레이어가 위에 올라선다).
- 등록: `waypoint_off,<RUID>,#FFFFFF,1,웨이포인트 꺼짐 (코덱스)` 형식.
- 웨이포인트가 있는 맵: town(+악몽·지옥), rotmarsh, execution, gallows, crypt1, crypt3(새로 추가). 맵 배치는 이미 끝났다.
