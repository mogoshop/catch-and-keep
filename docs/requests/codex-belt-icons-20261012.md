## 그릴 것 — 6장

기준 그림은 이미 게임에 들어간 `assets/codex-items-v1/belt-leather.png`와 `belt-bone.png`다. 같은 결로 그린다: 단독 물건, 투명 배경, 같은 시점·크기·외곽선.

| id | 한 가지 아이디어 |
| --- | --- |
| belt3 사슬 허리띠 | 녹슨 쇠사슬을 가죽에 엮은 띠, 작은 무덤 왕관 버클 |
| belt4 근위 요대 | 여왕 근위대 붉은 천 요대 + 금속 판, 등불 문장 버클 |
| belt5 망령 허리띠 | 바랜 수의 천을 감은 띠, 버클에 희미한 초록 혼불 |
| belt6 혼각 요대 | 검은 뼈 판을 이어 붙인 요대, 해골 버클 눈에 초록 빛 |
| belt7 사신의 띠 | 검은 천 띠에 낫 모양 버클, 끝이 2갈래로 늘어진 천 |
| belt8 명계 요대 | 짙은 보라·금 장식 요대, 가운데 큰 혼석(보라 발광) |

- 등급이 오를수록 금속·발광 장식이 조금씩 늘어난다. 일반형(가죽·뼈)보다 한눈에 비싸 보여야 한다.
- 색은 무덤 회색·녹슨 철·검정 바탕에 포인트 하나만 쓴다: 강화형은 초록 혼불, 정예형은 보라 혼석.
