# 코덱스 요청: 게임 안내 영상 위 설명 레이어 그림 (2026-10-27, Claude)

사용자 결정 (10-27): 게임 안내 창 화면 칸에 **유튜브 안내 영상**을 띄운다 (메이커 시험 통과 — docs/design/35 §8).
영상은 Claude가 메이커에서 장면 10개(4~6초씩, 약 1분)를 녹화해 만든다. 출시 트레일러(`assets/promo-video-20261023/promo-trailer-v4.mp4`)처럼 **영상 위에 설명 레이어**를 얹는데, 그 레이어에 쓸 그림 부품을 받는다.
Claude가 ffmpeg로 영상에 합성한다 (글자도 Claude가 넣는다 — 그림에는 글자 넣지 않기).

## 영상 규격

- 1280×720, 30fps. 게임 안내 창에서는 864×486으로 줄어 보인다 → **작게 줄어도 읽히는 굵은 모양**.
- 장면마다: 실제 플레이 화면 + 아래 자막 띠(쪽 제목) + 누를 키 표시 + 봐야 할 곳 강조 원/화살표.

## 그릴 것 (모두 투명 배경 PNG, 글자 없음)

| 이름 | 크기 | 내용 |
|---|---|---|
| `ov-caption-plate` | 1280×120, 9-slice (좌우 장식 고정) | 화면 아래 자막 띠. 어두운 반투명 바탕 + 위쪽 얇은 금·보라 선, 양끝 작은 해골·혼불 장식. 트레일러 제목 결과 같은 세트지만 **훨씬 얌전하게** (글이 주인공) |
| `ov-keycap` | 96×96, 9-slice | 키보드 키 한 칸 — 낡은 뼈색 돌 키캡 + 금테. 늘려서 `Space`·`우클릭` 같은 긴 키도 만든다 |
| `ov-keycap-press` | 96×96, 9-slice | 같은 키를 누른 순간 (살짝 눌리고 보라 빛) — 두 장을 번갈아 써서 「누름」을 보여 준다 |
| `ov-mouse-left` / `ov-mouse-right` | 96×128 | 마우스 그림 — 왼쪽/오른쪽 버튼이 보라로 빛남 |
| `ov-tap` | 128×128 | 모바일 손가락 누름 표시 (원 두 겹 퍼짐) |
| `ov-ring` | 256×256 | 「여기를 보세요」 강조 원 — 금빛 얇은 고리 + 바깥 보라 번짐. 크기를 바꿔 혼·몬스터·버튼에 씌운다 |
| `ov-arrow` | 160×96 | 강조 화살표 — 뼈 손가락 또는 낫 끝 모양, 오른쪽을 가리킴 (돌려 쓴다) |
| `ov-step-badge` | 72×72 | 순서 번호 동그라미 (안에 숫자는 Claude가 씀) — 「1 → 2 → 3」 단계 설명용 |

- 게임 UI(창 테두리·버튼·책갈피 샘플 `assets/codex-guide-ui-v1`)와 같은 결: 청동·금테, 뼈색, 혼불 보라.
- 영상 위에 얹히므로 **가장자리 반투명 번짐은 최소**로 — 줄였을 때 뭉개지지 않게.

## 장면 목록 (참고 — 어디에 쓰이는지)

| 장면 | 쪽 | 레이어 |
|---|---|---|
| 몹 처치 → 혼 → 추출 → 그림자 | 1-1 잡으면 내 편 | 자막 띠 · 강조 원(혼) · 키 E |
| 이동·공격·스킬 | 1-2 조작 | 마우스 왼/오른 · 키 A S D F |
| 해골 일으키기 | 2-1 | 키 A · 강조 원(해골) |
| 정예 혼 추출 | 2-2 | 키 E · 강조 원(정예 혼) |
| 집결로 보스 앞에 모이기 | 2-4 | 키 C · 화살표 |
| 스킬 강화 노드 찍기 | 3-3 | 순서 번호 1·2 · 강조 원(노드) |
| 빛 기둥 → 줍기 | 4-1 | 강조 원(빛 기둥) · 마우스 왼 |
| 웨이포인트 켜기 | 5-2 | 강조 원 · 화살표 |
| 보스 처치 → 혼 | 5-3 | 강조 원(보스 혼) · 키 E |
| 붉은 원 피하기 | 7-1 | 화살표(빠져나가는 방향) |
