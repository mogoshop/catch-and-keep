# 코덱스 요청: 게임 안내 영상 인트로 · 아웃트로 레이어 (2026-10-27, Claude)

사용자 요청 (10-27): 「유튜브에 올릴 거면 인트로랑 아웃트로도 있었으면 한다. 레이어를 코덱스에게 요청해서 Claude가 영상화하자」.
본편: `assets/claude-guide-video-v1/guide-video-v6.mp4` (1280×720 · 95초 · 실제 게임 녹화 + 설명 레이어).
움직임(페이드 · 확대 · 재 날림 · 닦아내기)은 Claude가 합성한다 → **한 장짜리 투명 PNG 부품**으로 받는다.

## 결 (기준 그림)

- 유튜브 채널 배너 `assets/codex-youtube-channel-v1/banner-2560x1440.png` — 양피지 · 보랏빛 안개 · 폐허 실루엣 · 투구 해골과 낫
- 로고 `assets/codex-youtube-channel-v1/sources/original-logo-ink.png` (단풍잎 + 메이플 / 리저렉션 / 네크로맨서 편) — **글자 획은 다시 그리지 말고 그대로 따서 쓴다**
- 본편 레이어 `assets/codex-guide-video-overlay-v1/png/` (자막 띠 · 키캡 · 강조 원과 같은 금테 · 보라 혼불)

## 흐름 (Claude 합성 계획)

- 인트로 약 4초: 어두운 폐허 바탕 → 보라 혼불이 모이며 로고가 떠오름 → 재가 흩날림 → 먹 번짐으로 닦아 내며 본편 첫 장면
- 아웃트로 약 10초: 본편 마지막 장면이 먹 번짐으로 덮임 → 로고 + 안내 한 줄 → 오른쪽에 유튜브 최종 화면(구독 · 다음 영상) 자리
- 글귀는 사용자 확정 전이라 **그림에 글자를 넣지 않는다** (Claude가 합성 때 쓴다)

## 그릴 것 (글자 · 숫자 없음, 영상 1280×720의 2배 크기로)

| 이름 | 크기 | 내용 |
|---|---|---|
| `io-logo-light` | 가로 1600 · 투명 | 로고를 **양피지 없이 투명**으로 딴 것 + 어두운 바탕에서 읽히는 판: 검은 획은 옅은 뼈색(#E8DCC4 근처), 「네크로맨서 편」과 단풍잎은 밝은 보라, 얇은 어두운 테두리 |
| `io-logo-ink` | 가로 1600 · 투명 | 같은 로고, 원래 먹색 그대로 (양피지 바탕 위에 쓸 판) |
| `io-bg-intro` | 2560×1440 · 불투명 | 배너 결의 바탕을 **어둡게** — 가운데는 로고가 앉을 빈 안개, 아래쪽 폐허 실루엣, 가장자리 보라 안개. 투구 해골은 없다 |
| `io-bg-outro` | 2560×1440 · 불투명 | 배너처럼 밝은 양피지 판 — **왼쪽 절반**에 로고 자리, 오른쪽 절반은 비워 둔다 (최종 화면 칸이 올라감). 오른쪽 아래 구석에 투구 해골과 낫을 작게 |
| `io-glow` | 1400×800 · 투명 | 로고 뒤에 까는 보라 혼불 빛무리 (부드러운 가장자리) |
| `io-ember-1` ~ `io-ember-6` | 각 64~160 · 투명 | 재 조각 · 불씨 · 작은 보라 혼불 — 모양 서로 다르게 6장 (Claude가 흩날리게 움직인다) |
| `io-ink-wipe-01` ~ `io-ink-wipe-08` | 각 2560×1440 · 투명 | 먹 번짐 닦기 8장 — 01은 한쪽 구석 작은 얼룩, 08은 화면 전체를 덮음 (장면 바꿈에 쓴다). 먹색은 보랏빛 검정 |
