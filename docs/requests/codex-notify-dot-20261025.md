## 지금 상태

- 그림: `data/ui_icons.csv` `red_dot` (RUID `2860136c…`)를 `#E4573B`로 칠해 26×26으로 쓴다. 원본이 작은 메이플 점이라 늘리면 가장자리가 뭉개진다.
- 움직임: Claude가 오늘 고쳤다. 크기를 키웠다 줄이는 대신, **크기는 그대로 두고 깜빡이게** 했다(0.6초 켜짐 · 0.3초 흐림). 그러니 그림은 **한 장의 정지 그림**이면 된다.
- 쓰이는 곳:
  - 화면 아래 메뉴 줄 · 메뉴 창 칸 · 스킬 창 카드·탭·버튼 · 그림자 창 버튼 · 모바일 패드
  - 모두 버튼 오른쪽 위 모서리에 26×26으로 붙는다.

## 그릴 것

| 이름 | 크기 | 내용 |
|---|---|---|
| `ui-notify-dot` | **52×52 PNG** (게임에서 26px로 반 줄여 쓴다) | 붉은 원 하나. 게임 테두리와 같은 결: 어두운 금속 테두리 1~2px + 안쪽 붉은 보석(`#E4573B` 언저리), 위쪽에 작은 하이라이트 하나. 픽셀 아트 외곽선, 반투명 가장자리 없이 또렷하게 |

- 투명 배경, 원이 캔버스를 거의 꽉 채운다(가장자리 여백 2px 정도).
- 26px로 줄였을 때 동그랗고 또렷해야 한다 — 계단이 들쭉날쭉하지 않게, 정수 배율(2배)로 그린다.
- 숫자·느낌표 넣지 않는다.
