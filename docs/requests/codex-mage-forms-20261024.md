# 코덱스 요청: 해골 마법사 변이 5종 — 광기 · 저주 · 쌍발 · 관통 · 폭발 (2026-10-24)

사용자 결정 (10-24): 해골 마법사에도 변이를 넣었다 (해골 전사 변이 방패·쌍칼·대검과 같은 규칙 — 변이 랭크마다 마법사 1기가 그 모습으로 선다). 게임 쪽 기능은 끝났고, 지금은 다섯 변이가 모두 같은 그림(메이플 「리치」 + 원소 색)이라 구분이 안 된다.

**그림 샘플 승인제를 지킨다**: 다섯 변이 서 있기 샘플 1장씩 → 사용자 승인 → 승인분만 전체 프레임.

## 기준 그림

- 해골 전사 변이 3종(`assets/codex-skeleton-forms-v1/previews/forms-v2-lineup.png` — 방패·쌍칼·대검, 사용자 승인)과 **같은 그림체·같은 해골 비율·같은 크기감**. 다섯 마법사가 해골 전사 변이 옆에 서도 한 군단으로 보이게.
- 몸은 해골 전사보다 가늘고 로브를 입은 해골. 눈은 보라 혼불 (네크로맨서의 해골 표시). 손에 지팡이·완드.
- 시점: 게임과 같은 3/4 위에서 본 각도, **오른쪽을 본다** (왼쪽은 게임이 좌우 뒤집기).
- 캔버스 192×128 PNG 투명 배경, **발이 바닥 가운데 아래** (발 기준점 (96,123) — 해골 전사 변이와 같게). 게임에서는 0.5배로 작게 서므로 0.5배에서도 변이마다 실루엣·색이 갈려야 한다.
- 게임은 마법사 몸을 물들이지 않는다 (원소 색은 화살 색으로만 보인다) → 그림 자체 색이 변이 색이다.

## 다섯 변이 (색이 서로 겹치지 않게)

| 변이 | 하는 일 (게임) | 그림 제안 | 대표 색 |
|---|---|---|---|
| **광기** | 반경 3 아군 피해 +12~20% (오오라) | 핏빛 너덜 망토 · 이마에 작은 뿔 장식 · 지팡이 끝에 **붉은 불꽃 고리**가 떠 있다 (주변을 북돋는 깃발 같은 존재감) | 진홍 `#D8364A` |
| **저주** | 맞은 적 받는 피해 +8~16% | 해진 수도 두건을 깊게 눌러쓴 해골 · 지팡이에 **매달린 해골 등불**(녹보라 불) · 허리에 저주 부적 몇 장 | 녹보라 `#8E5BD8` + 독빛 `#7FD86A` |
| **쌍발** | 화살 2발 | 지팡이 대신 **양손에 짧은 뼈 완드 2개**, 두 손을 앞으로 내민 자세 · 짧은 어깨 망토 | 청동 금 `#E0B054` |
| **관통** | 화살이 2~4마리 꿰뚫음 | **길쭉한 뼈 작살 모양 지팡이**(끝이 창날) · 몸을 낮추고 겨누는 자세 · 가는 실루엣 | 서리 하늘 `#7FC8FF` |
| **폭발** | 맞은 자리에서 터짐 | 등에 **해골 화약 단지**를 멘 해골 · 손에 금 간 구슬 지팡이 · 로브 끝이 그을린 | 잿불 주황 `#FF8A3A` |

- 일반 해골 마법사(변이 아님)는 지금 메이플 「리치」 그림을 그대로 쓴다 — 이번 요청에 넣지 않는다 (원하면 사용자가 따로 요청).
