# Codex 요청 — 액트 1 「잿빛 변경」 그림체 시험 (2026-10-12, Claude)

액트 1 몬스터를 메이플식으로 새로 그리기 **전에** 분위기 정도부터 고른다. 대표 3종을 세 단계로 그려 사용자가 하나를 고른다.
**이번 요청은 시험 그림만 그린다. 기존 그림·RUID·데이터는 건드리지 않는다.**

## 배경

- 액트 2·3 메이플식 그림([codex-act23-maple-remake-20261012](codex-act23-maple-remake-20261012.md))은 메이플과 잘 섞인다.
- 다만 사용자 평은 「**너무 귀여운 느낌이 크다**」이다. 액트 1은 세계관상 가장 어두운 액트라 결이 달라야 한다.
- 사용자 확정(10-12):
  - **섬뜩한 공포까지는 원하지 않는다.**
  - 부두술·악마 색을 새로 입히지 않는다.
  - **기존 액트 1 설정의 느낌을 살린다.**

### 액트 1 설정 — 잿빛 변경 (Lv 1~15)

전쟁과 역병으로 버려진 변방의 무덤 지대다.
- 죽은 자를 부리던 **교단**이 무너진 뒤 이 땅의 **망자**가 깨어났다.
- 플레이어는 네크로맨서로, 교단에서 쫓겨난 사제 오렌의 의뢰를 받아 망자를 정리한다.
- 길은 잿불 야영지 → 피 묻은 황무지 → 썩은 갈대 늪 → 무너진 형장 → 교수대 숲 → 지하 납골당 → 여왕의 무덤이다.
- 속성은 물리와 독. 팔레트는 **잿빛 · 탁한 늪 초록 · 녹슨 갈색 · 피의 적갈색**.

몬스터 구성 (`data/monsters.csv` region 1):
| 무리 | 몬스터 |
| --- | --- |
| 망자 | 잿빛 망자병 · 썩은 좀비 · 해골 전사 · 굶주린 악령 · 목 없는 처형인 · 납골당 지휘관 바르그 |
| 무덤 생물 | 무덤 구더기 · 시체 까마귀 · 무덤 새끼거미 · 뼈 둥지 |
| 교단 | 광신 궁수 · 썩은 사제 모르그 · 피의 사제 · 유물 지기 |
| 악마 (소수) | 지옥견 · 타락 꼬마악마 |
| 보스 | 묘지기 여왕 (이 땅의 망자를 모두 다스리던 자, 지하 납골당 가장 깊은 곳) |

지금 액트 1 일반 몹은 메이플 원본 그림을 쓴다. 예를 들어 굶주린 악령 = 메이플 「레이스」이고, `data/monsters.csv`의 stand RUID로 확인할 수 있다. 메이플의 어두운 지역(폐광·슬리피우드 개미굴·죽은 나무의 숲) 몹 정도의 무게감이 지금 액트 1의 기준이다.

## 바꾸지 않는 것 (메이플과 섞이게 하는 뼈대)

[메이플 분석](../art/maple-style-analysis.md)의 규칙과 액트 2·3 납품 규격 그대로다.
- 1px 고유색 외곽선, 부드러운 2~3단 명암, 몸 가장자리 알파 0/255, 원본 크기·배율 1.
- 왼쪽을 보고, 발밑 가운데 기준으로 발밑 아래 3px를 비운다.
- 고해상도로 그린 뒤 nearest 축소 + 색 제한 (700색 이하).

## 세 단계 — 「귀여움」을 얼마나 덜어낼지

| | **A. 가라앉힌 메이플** | **B. 지친 망자** (Claude 추천) | **C. 무거운 무덤** |
| --- | --- | --- | --- |
| 한 줄 | 액트 2·3과 같은 비율·표정에 색만 가라앉힘 | 비율을 조금 늘리고, 귀여운 큰 눈 대신 지치고 무표정한 얼굴 | 비율을 더 늘리고, 그림자를 깊게, 얼굴은 눈빛만 |
| 등신 | 2~3 | 2.5~3 | 3~3.5 |
| 얼굴 | 큰 눈, 표정 있음 | **작은 눈·실눈·퀭한 눈**, 처진 입, 무표정이나 멍한 얼굴 | 투구·두건·붕대 그림자 속 **빛나는 두 점**만 |
| 무서움 : 우스움 | 6 : 4 | 7 : 3 | 8 : 2 (그래도 공포·고어 없음) |
| 몸 밝기 (휘도) | 70~110 | 60~95 | 50~80 + 윤곽 빛 |
| 채도 | 0.30 안팎 | 0.20~0.30 | 0.15~0.25 |
| 발광 | 거의 없음 | 눈·상처·무기에 독 초록이나 핏빛 은은하게 | 눈·오라·연기가 형태를 읽게 해 준다 |
| 디테일 | 액트 2·3 수준 | 붕대·녹·이끼·찢어진 천을 큰 덩어리로 (잡결 금지) | B + 금 간 뼈, 녹슨 갑옷 판 |
| 비슷한 메이플 | 쿨리 좀비 | 스켈레톤 장교 · 레이스 · 쿨리 좀비의 중간 | 엘더레이스 · 타락한 상급 마법사 |

**세 단계 공통 금지:**
- 피 튀김, 내장, 일그러진 공포 얼굴 (섬뜩함은 원하지 않음).
- 부두 인형·핀·악마 뿔 같은 새 소재 (설정에 없는 것).
- 액트 2·3의 동글동글한 「귀여운 큰 눈」. A는 예외.
