## 고쳐 주면 좋은 것 (우선순위 순)

1. **바닥이 너무 어두워 몬스터가 묻힌다.** 밝기(휘도 평균, 0~255)를 재면:
   - 액트 2: 바닥 55~128 / 몬스터 38~106
   - **액트 3: 바닥 34~83 / 몬스터 35~64** — 게임에서는 맵 어둠(DarkVision 밝기 0.1~0.14)까지 더해진다
   - 특히 겹치는 조합: 밀수꾼 두목(43) ↔ 밀수꾼 동굴 바닥(43), 익사한 선원(41) ↔ 검은 모래(34), 난파선 골렘(46) ↔ 선창 바닥(42)
   - 요청: 바닥 11장을 **휘도 70~100 정도로 밝게** (무늬·색은 그대로, 명도만). 또는 몬스터에 은은한 윤곽광(rim light). 바닥 쪽이 고치기 쉽다.
2. **폭풍 갈매기가 까마귀처럼 검고 작다** (44×50, 휘도 35). 중간 밝기 바닥에서도 검은 점으로 보이고, 액트 1 시체 까마귀와 헷갈린다.
   - 요청: **흰빛·잿빛 갈매기**(날개 끝만 검게, 눈은 청백 빛), 70×50 정도.
3. **게 껍질 오버레이가 몸 실루엣과 맞지 않는다.** 바위 집게 왕 stand 위에 겹치면 몸보다 훨씬 큰 집게 고리가 따로 떠 보인다 (유령 게가 하나 더 있는 모양).
   - Claude 쪽 대안: 껍질이 닫힌 동안 몸 그림에 청백 색조를 입히면 된다 (스프라이트 색은 코드로 바꿀 수 있다). 이 그림은 「껍질 닫힘」 순간 한 번 터지는 고리 이펙트로 쓰겠다 — **다시 그릴 필요 없음**.
4. **벽 반복 이음매**: `coast-rock-wall` 5×5 미리보기에 칸 경계 선이 보인다. 등대 바닥 세로 경계(납품서의 1.72배)와 함께 메이커에서 확인 후 필요하면 가장자리만 다듬기.

## 업로드·연결 순서

1. (1·2를 고친다면) 고친 PNG로 교체 — **업로드 전에 고치는 편이 RUID를 두 번 받지 않아 낫다.**
2. 그룹 OJYYQ에 `a3-*` Sprite 업로드 → Catalog CSV.
3. Claude가 `resource-mapping.csv`·`animation-registration.csv`에 RUID를 채우고 `tools/import_frames.cjs` → 모델 12종 · NPC 3 · `ui_icons` 18키 · 이펙트 연결 → 메이커 확인.
4. 맵 칠하기(Codex)는 `map-art-plan.json` 기준. 2·3단계 위치는 `data/maps.csv`가 최신이다 (`docs/map-spec-region3.md`도 2·3단계로 갱신 예정).
