# 코덱스 요청: 전체 제작 1차 — 손맛 연출 · 스킬 창 V3 + 제물 카드 · 액트 1 맵 그림 (2026-10-28, Claude)

밤사이 샘플 3묶음(`docs/requests/codex-overnight-20261028.md`)을 사용자가 **승인**했다. 이번 묶음은 승인된 샘플을 기준으로 실제 게임에 넣을 **전체 제작**이다. 사용자가 자는 동안 끝까지 돌린다.

- 승인 내용
  - 액트 1 맵 그림 샘플 3장(`assets/codex-a1-handmade-v1/`) → 결 그대로 액트 1 전체로 간다.
  - 스킬 창은 **V3 「해금 시간선 + 스킬 공방」을 몸통**으로 하고, **V4의 「혼의 제물」 3택 카드만** 붙인다(기획서 38 결정 #24-A). V4의 트라이포드 보드·V1·V2는 그리지 않는다.
  - 손맛 연출 샘플(`assets/codex-feel-fx-v1/`) → 레벨업 빛기둥 8프레임과 골드 더미 가운데 단계는 **그대로 쓴다**(다시 그리지 않는다).
- 순서 = 게임에 들어가는 순서(로드맵 #25-A 「템포 → 뽕 → 스킬 창 → 맵」): **① 손맛 연출 → ② 스킬 창 → ③ 액트 1 맵.** 시간이 모자라면 ③의 뒤쪽(바닥 무늬 → 벽 변형)부터 남긴다.
- 공통
  - 그림에 글자·숫자를 넣지 않는다. 숫자·이름은 게임이 그 위에 쓴다.
  - 돌려줄 곳은 `assets/` 아래 새 폴더. `assets/`는 커밋하지 않는다.
  - 폴더마다 `png/` · `resource-mapping.csv`(key,file,resource_name,category,ruid,border — ruid 빈칸, 9조각은 border에 px) · `resource-properties.csv`(피벗) · `previews/` · `DELIVERY.txt`(만든 것 · 못 만든 것 · 고민한 점).
  - **새 그림은 반드시 기존 세트와 나란히 놓은 비교판**을 `previews/`에 넣는다. 혼자 보면 좋은데 옆에 놓으면 튀는 그림이 가장 흔한 반려 사유다.
  - 색: 창백한 혈색 · 어두운 가죽 · 녹슨 금 · 뼈. 액트 1은 회갈색·피 붉은색. 주황·초록이 튀지 않게.

사용자 결정 #23-A: **바닥 · 벽 · 랜드마크는 코덱스, 작은 소품(상자 · 술통 · 뼈 · 무덤 · 횃불 등)은 메이플 원본**(`data/handmade/maple_sprites.csv`)을 쓴다. 그래서 이번에는 메이플 원본에 없는 것만 그린다.
