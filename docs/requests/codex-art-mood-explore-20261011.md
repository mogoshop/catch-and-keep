# Codex 요청 — 미감 탐색 2차: 게임 화면 한 장씩, 5방향 (2026-10-11, Claude)

1차 시험([codex-art-style-trial-20261011](codex-art-style-trial-20261011.md), 납품 `assets/codex-style-trial-v1/`)의 결과다.
- 비율 문제는 풀렸다. A·B는 플레이어 옆에 서도 덜 어색하다.
- 하지만 사용자 평은 **「빡 오는 게 없다」**.
- 프레임 단위 제작은 너무 오래 걸린다.

그래서 이번에는 **프레임·투명 PNG를 만들지 않는다.** 방향마다 **게임 화면 목업 한 장**만 그려서 빠르게 많이 비교한다. 미감이 정해진 다음에 캐릭터 한 종으로 규격을 고정하고, 그 다음에 프레임을 만든다.

## 1차가 밋밋했던 이유 (Claude 검토)

1. **그림 해상도와 결이 플레이어와 다르다.**
   - 메이플 아바타·NPC는 작은 도트 그림이다. 게임 줌에서 픽셀 계단이 보이고, 1px 짙은 외곽선에 색 수가 적다.
   - 1차 시안은 288px짜리 매끈한 벡터풍 일러스트다. 에어브러시 명암에 테두리가 부드럽다.
   - 비율을 맞춰도 「도트 옆에 붙인 모바일 RPG 일러스트」로 보인다.
2. **디자인에 한 방이 없다.** 「후드 쓴 깃털 노인」은 렌더링만 바뀌었지 기억에 남는 상징이 없다. 메이플 몬스터는 한 가지 아이디어로 읽힌다(버섯에 얼굴, 돌 골렘에 이끼). 다크 판타지라도 몬스터마다 64px에서 바로 읽히는 **상징 하나**가 필요하다.
3. **색이 한 덩어리다.** 회청색 몸이 회청색 바닥 위에 있고, 강조색 대비가 없다. 명도는 올랐지만 화면이 심심하다.
4. **화면 단위로 보지 않았다.** 미감은 캐릭터 한 명이 아니라 바닥·벽·빛·이펙트·몬스터가 함께 만든다. 1차는 캐릭터 단품 비교였다.

## 그릴 것: 방향마다 게임 화면 목업 1장

**규격** (5방향 모두 같은 장면)

| 항목 | 내용 |
| --- | --- |
| 크기 | 1920×1080, 게임 화면처럼 탑다운(위에서 비스듬히), UI 없음 |
| 장소 | 액트 3 폭풍 해안: 젖은 바위 바닥, 해안 바위 벽 한쪽, 부서진 난파선 장식 1개, 등불 1개 |
| 플레이어 | 가운데에 1명. **실제 게임 아바타를 그대로 붙인다** (`docs/requests/style-trial/ingame-compare.png`의 「인꾸」, 또는 1차 `references/`의 플레이어 컷). 다시 그리지 않는다. 화면 높이 약 124px |
| 일반 몬스터 | 폭풍 주술사 2마리(1마리는 번개 공격 중) + 익사한 선원 1마리 |
| 보스 | 익사한 제독 바렌 1명. 플레이어 키의 약 2배 |
| NPC | 항구 관리인 브람 1명, 화면 구석. 플레이어 키 1.1배 정도 |
| 이펙트 | 번개 연쇄 한 줄기가 플레이어에게 꽂히는 순간 |
| 어둠 | 게임처럼 플레이어 주변만 밝고 가장자리는 어두운 시야 (밝기 0.3 정도) |

**방향 5가지**

| | 방향 | 핵심 | 비슷한 느낌 |
| --- | --- | --- | --- |
| 1 | **메이플 도트** | 실제 메이플 몬스터처럼 작은 도트 그림이다. 원래 크기에서 몸 키 70~90px, 1px 짙은 외곽선, 한 캐릭터 24색 이하로 그린다. 게임 줌으로 키웠을 때 픽셀 계단이 아바타와 같은 굵기로 보여야 한다. 어두움은 깊은 팔레트와 발광 포인트로 낸다 | 메이플 엘나스·폐광·시계탑 하층의 어두운 몬스터 |
| 2 | **다크 메이플 강대비** | 1차 B의 비율(3~3.5등신)을 쓴다. 그림자를 거의 검은 넓은 덩어리로 깔고, 강조색 둘을 세게 넣는다(폭풍 청백 발광 + 녹슨 주황 같은 보색 하나). 실루엣도 과감하게 한다 | 메이플 아케인리버·검은 마법사 군단 |
| 3 | **잉크 고딕 동화** | 큰 머리에 긁힌 잉크 외곽선, 삐뚤한 형태를 쓴다. 바랜 종이색 바탕에 포인트 색 하나만 둔다. 귀엽지만 섬뜩하게 | Don't Starve, 팀 버튼 |
| 4 | **그래픽 코믹** | 2~3등신이다. 단색 면 2~3개에 칠흑 그림자 덩어리를 넣고, 테두리 빛과 발광으로 형태를 잡는다. 결은 그리지 않는다 | Hades, 마이크 미뇰라(헬보이) |
| 5 | **1차 B 그대로** (대조군) | 1차 B 그림을 같은 장면에 놓는다. 다른 방향과 나란히 비교하는 기준이다 | — |

**디자인 한 방 (방향 1~4 모두)** — 렌더링만 바꾸지 말고 캐릭터마다 64px에서 읽히는 상징을 하나씩 세운다:

| 캐릭터 | 상징 아이디어 (더 좋은 안이면 바꿔도 된다) |
| --- | --- |
| 폭풍 주술사 | 머리 위에 작은 먹구름이 따라다니고 지팡이 새 해골 눈이 번쩍인다 |
| 익사한 선원 | 몸에서 물이 뚝뚝 떨어지고 따개비·해초가 붙었다. 입에서 거품 |
| 익사한 제독 | 거대한 닻을 끌고 다니고, 찢어진 유령선 돛이 망토다 |
| 브람 | 커다란 등불과 비옷. 사람이라 몬스터와 달리 따뜻한 색 |
