# Codex 요청 — 게임 고르기 카드 그림 2장 (2026-10-22, Claude)

## 왜

캐릭터 선택 뒤 「게임 고르기」 화면(사용자 10-22 개편)에 큰 그림 카드 두 장이 있다: **솔로 플레이** · **파티 플레이**.
지금은 썸네일 v5의 04(후드 초상)·01(모닥불)을 잘라 임시로 쓰고 있어 두 카드의 화풍이 서로 다르고(수묵 초상 vs 픽셀 장면) 의미도 약하다.
사용자: 「이미지 만들도록 하자」.

현재 화면: Claude가 보낸 캡처 / 코드 `tools/build/roompicker.cjs` (CARD_SOLO · CARD_PARTY)

## 만들 것 — 샘플 먼저 (승인제)

**두 장 한 쌍으로 샘플 1세트** → 사용자 승인 → 최종본. 두 장은 같은 화풍·같은 빛·같은 시점이어야 한다(나란히 놓인다).

| 카드 | 장면 |
|---|---|
| **솔로 플레이** | 꼬마 네크로맨서 한 명이 앞장서고 뒤로 보라 그림자 군단(해골 전사·해골 마법사·쓰러뜨린 몬스터의 그림자 2~3)이 줄지어 따른다. 「혼자지만 군단과 함께」 |
| **파티 플레이** | 네크로맨서 넷(머리색·눈색이 서로 다른 꼬마 넷)이 모닥불 둘레에 모여 있고, 각자의 그림자 몇이 뒤에서 어울린다. 「함께 모여 출발」 |

- 직업은 **네크로맨서 하나뿐**이다. 파티 카드도 서로 다른 직업이 아니라 서로 다른 외형의 네크로맨서 넷으로 그린다 (부제 「네크로맨서 편」)
- 화풍: 썸네일 v5 **01 불가의 두 동료** 계열 (메이플 꼬마 비율 · 픽셀 느낌 · 어두운 보라·재빛 + 따뜻한 불빛 한 점). 프로젝트 플레이어·해골전사 자산을 참고로
- **글자 넣지 않는다** (카드 이름·설명은 UI가 그 아래에 쓴다)
- 크기: **1320×750 PNG** (게임에서 616×350으로 줄여 쓴다 — 작게 봐도 주인공 실루엣이 읽히게, 인물은 화면 가운데 60% 안)
- 두 카드 밝기·채도를 맞춘다. 한쪽만 튀지 않게
