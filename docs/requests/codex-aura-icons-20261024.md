# 코덱스 요청: 오오라 아이콘 3종 (2026-10-24)

사용자 결정 (10-24): 오오라를 글자(「질풍 오오라」)로 보이지 않는다. 아이콘으로 바꾼다.
- 생명 오브 바로 위 버프 칩 줄 (56×56 원형 칩 — 마우스를 올리면 효과 설명)
- 소환수 띠 칸 오른쪽 위 작은 표시 (28×28 — 「×4」 수 표시처럼 작게, 그 소환수가 내뿜는 오오라)

**그림 샘플 승인제를 지킨다**: 3종 중 1장(질풍) 샘플 → 사용자 승인 → 나머지 2장.

## 그릴 것

이미 납품된 버프 칩(`ui_icons.csv`의 `buff_command`, `buff_bone_armor` — 액트 3 납품)과 같은 그림체·테두리·크기감으로 3장.

| 키 | 오오라 | 효과 | 색 (몬스터 발밑 원과 같은 계열) | 그림 제안 |
|---|---|---|---|---|
| `aura_haste` | 질풍 오오라 | 주변 아군 공격·이동 속도 +20% | 노랑 `#FFD95A` | 휘몰아치는 바람 소용돌이 + 작은 깃털 |
| `aura_dmg` | 광기 오오라 | 주변 아군 피해 +25% | 붉은색 `#FF7A66` | 불타는 해골 눈 또는 핏빛 송곳니 |
| `aura_guard` | 수호 오오라 | 주변 아군 받는 피해 −20% | 하늘색 `#7FD4FF` | 빛나는 방패 문양 |

- 128×128 PNG 투명 배경, 가운데 정렬. 28×28로 줄여도 형태가 읽히게 굵은 실루엣 (가는 선·작은 글씨 금지).
- 칩 바깥 원 테두리는 버프 칩 세트와 같게. 글자 넣지 않는다.
- 네크로맨서 군단의 그림자 소환수가 내뿜는 기운이라 바탕은 어두운 보라 톤 + 오오라 색 빛.

## 등급 테두리 3장 (10-24 C안 추가)

오오라는 같은 종류도 수치가 10~25%로 달라 등급이 있다: **옅은**(10~14) · **짙은**(15~19) · **극한**(20~25). 아이콘 위에 덧씌우는 원형 테두리 3장.

| 키 | 등급 | 색 |
|---|---|---|
| `aura_tier1` | 옅은 | 바랜 뼈색 `#C9BFA8` 얇은 테 |
| `aura_tier2` | 짙은 | 차가운 푸른 `#9FD0FF` 테 + 작은 빛 점 |
| `aura_tier3` | 극한 | 주황 금빛 `#FFB04A` 두꺼운 테 + 불꽃 같은 가장자리 |

- 128×128 PNG, 가운데는 투명(아이콘이 비쳐 보이게). 28px로 줄여도 세 등급 색이 갈리게.
