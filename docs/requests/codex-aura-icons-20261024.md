# 코덱스 요청: 오오라 아이콘 9종 + 등급 테두리 3장 (2026-10-24)

사용자 결정 (10-24): 오오라를 글자(「질풍 오오라」)로 보이지 않는다. 아이콘으로 바꾼다.
- 생명 오브 바로 위 버프 칩 줄 (56×56 원형 칩 — 마우스를 올리면 효과 설명)
- 소환수 띠 칸 오른쪽 위 작은 표시 (28×28 — 「×4」 수 표시처럼 작게, 그 소환수가 내뿜는 오오라)

**그림 샘플 승인제**: 질풍(신속) 샘플은 10-24 사용자 승인 완료 → 나머지는 같은 그림체로 진행 (아래 순서).

## 그릴 것 (10-24 B안: 오오라 9종으로 확장 · 질풍 샘플 승인)

**✅ 사용자 승인 (10-24)**: 질풍 샘플(`png/aura_haste_sample.png`)의 그림체 그대로 간다. 이 그림은 **신속 오오라**(공격 속도) 아이콘으로 쓴다 — 키 `aura_haste`. 같은 청동 원형 테두리 · 십자 장식 · 어두운 보라 바탕 · 가운데 굵은 실루엣 하나 · 글자 없음.

이미 납품된 버프 칩(`buff_command`, `buff_bone_armor`)과 같은 크기감. 계열 색(바탕 빛) — 공격 붉은 · 속도 노랑 · 방어 하늘 · 회복 초록 · 약화 보라.

| 키 | 오오라 | 효과 | 계열 색 | 그림 제안 |
|---|---|---|---|---|
| `aura_haste` | 신속 (승인됨) | 공격 속도 + | 노랑 | (샘플 그대로) 금빛 바람 소용돌이 + 깃털 |
| `aura_move` | 기동 | 이동 속도 + | 노랑 | 날개 달린 발굽·발자국이 앞으로 휙 |
| `aura_dmg` | 광기 | 피해 + | 붉은 `#FF7A66` | 불타는 해골 눈 또는 핏빛 송곳니 |
| `aura_crit` | 냉혹 | 치명타 확률 + | 붉은 | 갈라진 단검 끝의 반짝임 / 과녁을 꿰뚫은 뼈 |
| `aura_thorns` | 가시 | 근접 평타 피해 반사 | 붉은 | 가시 넝쿨이 감싼 방패 |
| `aura_guard` | 수호 | 받는 피해 − | 하늘 `#7FD4FF` | 빛나는 방패 문양 |
| `aura_resist` | 저항 | 모든 원소 저항 + | 하늘 | 네 원소(불·얼음·번개·독) 조각이 원 안에서 막혀 흩어짐 |
| `aura_regen` | 재생 | 초당 생명 회복 | 초록 | 맥박 치는 심장 + 새싹 |
| `aura_corrode` | 부식 | 주변 적 저항 − (약화) | 보라 | 녹아내리는 갑옷 조각 · 산성 방울 |

- 128×128 PNG 투명 배경. 28×28로 줄여도 형태가 읽히게 굵은 실루엣 (가는 선·작은 글씨 금지).
- 순서: 이미 승인된 그림체라 샘플 단계 없이 8장 한 번에 (단, 계열이 처음인 **재생**·**부식** 2장을 먼저 보여 주고 나머지 6장을 이어 그려도 좋다).

## 등급 테두리 3장 (10-24 C안 추가)

오오라는 같은 종류도 수치가 10~25%로 달라 등급이 있다: **옅은**(10~14) · **짙은**(15~19) · **극한**(20~25). 아이콘 위에 덧씌우는 원형 테두리 3장.

| 키 | 등급 | 색 |
|---|---|---|
| `aura_tier1` | 옅은 | 바랜 뼈색 `#C9BFA8` 얇은 테 |
| `aura_tier2` | 짙은 | 차가운 푸른 `#9FD0FF` 테 + 작은 빛 점 |
| `aura_tier3` | 극한 | 주황 금빛 `#FFB04A` 두꺼운 테 + 불꽃 같은 가장자리 |

- 128×128 PNG, 가운데는 투명(아이콘이 비쳐 보이게). 28px로 줄여도 세 등급 색이 갈리게.
