## 1차 B가 아쉬운 이유 (Claude 검토)

- **잿빛 망자병:** 회색 얼굴에 졸린 눈이라 「아픈 병사」로 읽힌다. 죽은 자라는 표식이 없다.
- **묘지기 여왕:** 흰 머리의 우울한 공주로 읽힌다. 살아 있는 사람 같다.
- **시체 까마귀:** 그냥 지저분한 까마귀다.
- **색:** 몸 전체가 카키·회색 한 톤이라 어두운 바닥 위에서 탁하게 뭉친다 (`previews/act1-trial-ingame-B.png`). 어둡지만 무섭지도 또렷하지도 않다.

## 망자 표식 — 얼굴은 보이게, 죽은 자임은 확실하게

공포는 **얼굴을 가려서가 아니라 「살아 있지 않은 부분」을 보여서** 만든다. 메이플 결(1px 고유색 선, 부드러운 명암, 큰 덩어리, 원본 크기)은 그대로다.

| 표식 | 표현 | 메이플 결을 지키는 법 |
| --- | --- | --- |
| 죽은 피부색 | 회녹색·푸른 잿빛 피부, 입술·눈가는 검푸르게 | 피부 덩어리 하나에 2~3단 명암 |
| 퀭한 눈 | 눈 주위가 꺼진 검은 구멍, 그 안에 **작게 빛나는 눈동자**(무덤 초록) — 얼굴은 다 보인다 | 눈 크기는 작게, 빛은 2~3px 점 |
| 드러난 뼈 | 광대뼈 한쪽, 턱선, 손가락 뼈, 찢어진 천 사이 갈비뼈 몇 개 | 뼈는 밝은 상아색 덩어리 → 어두운 몸에서 **형태를 읽게 하는 밝은 면** 역할 |
| 오래된 상처 | 꿰맨 자국, 박힌 채 녹슨 화살·못, 금 간 피부 | 피는 **말라붙은 검붉은 얼룩**만. 흐르는 피·살점·내장 금지 |
| 무덤의 흔적 | 흙덩이, 이끼·곰팡이 얼룩, 거미줄, 수의 붕대, 끊어진 족쇄 | 큰 덩어리 2~3개만, 잡결 금지 |
| 재 | 몸에서 재가 부스러져 날림 (잿빛 변경의 상징) | 몸 밖 작은 점 3~6개 |
| 망자 자세 | 고개가 한쪽으로 꺾임, 한쪽 어깨 처짐, 턱이 살짝 벌어짐, 다리를 끔 | 실루엣으로 「사람이 아님」이 읽히게 |
| 색 대비 | 몸은 어둡게(휘도 55~85), 뼈·피부는 밝게, 눈·등불·상처 빛은 **무덤 초록** + 말라붙은 **핏빛** 포인트 | 어두운 바닥에서 뼈와 눈빛이 먼저 보이게 |

**금지:**
- 흐르거나 튀는 피, 살점, 내장, 머리 절단면.
- 일그러진 공포 얼굴.
- 얼굴 전체를 검게 가리기.
- 설정에 없는 부두·악마 소재.

## 추가 (사용자 10-12): 중세 고딕 — 여왕을 지키는 철갑 병사

사용자 요청은 「블러드본·블라스퍼머스처럼 중세가 배경인 느낌」이다. 보스가 여왕이니 **여왕을 지키는 중세 철갑 병사**를 보고 싶고, 망자답게 **혈흔이 옅게 보이고 절뚝거린다.**
- 그 게임들은 **분위기 참고만** 한다. 특정 캐릭터·갑옷 디자인을 베끼지 않는다.
- 그림체는 위와 같은 메이플 결(B+2 수준)이다.

### 액트 1 세계관을 중세 고딕으로 묶는 법

여왕의 무덤 왕국으로 읽힌다. 근위대, 장례 행렬, 무너진 교단 성당이 그 소재다.
| 소재 | 표현 |
| --- | --- |
| 철갑 | 녹슨 판금 갑옷·사슬 갑옷, 찌그러진 투구. **면갑을 들어 올려 죽은 얼굴이 보이게** (얼굴을 가리지 않는다) |
| 여왕의 문장 | 바랜 망토·겉옷(타바드)에 **여왕의 문장** (무덤 왕관 + 등불, 여왕 그림과 같은 무늬). 근위대임을 알리는 표식 |
| 장례·성당 | 녹은 촛농, 작은 조종, 향로, 수의 천, 성당 쇠창살 조각 |
| 옅은 혈흔 | 판금 이음새·옷자락에 **스며 나온 듯한 옅은 검붉은 얼룩** (말라붙은 것만, 흐르는 피 금지) |
| 절뚝거림 | 한쪽 정강이 갑옷이 부러져 다리를 끌고, 몸이 한쪽으로 기운다. 무기를 지팡이처럼 짚는다 |
| 색 | 녹슨 철 회청 + 바랜 핏빛 겉옷 + 무덤 초록 눈빛. 철의 밝은 반사 면이 어두운 바닥에서 형태를 읽게 해 준다 |
