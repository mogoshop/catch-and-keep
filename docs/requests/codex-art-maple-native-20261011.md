# Codex 요청 — 미감 3차: 메이플 원본 방식으로 몬스터 몇 장 (2026-10-11, Claude)

**먼저 읽을 것:** [docs/art/maple-style-analysis.md](../art/maple-style-analysis.md)와 `docs/art/maple-reference/`의 그림 3장. 메이플 원본 몬스터 113종을 실제로 받아 잰 결과다.

1·2차 결과([1차](codex-art-style-trial-20261011.md) · [2차](codex-art-mood-explore-20261011.md)) 사용자 평은 「나쁘지 않지만 양산형 방치형 게임 같다. 메이플 월드에 올려 기존 에셋과 융화되겠느냐 하면 아니다」였다.
분석에서 찾은 핵심 차이는 넷이다:
- **크게 그려 줄인 그림과 원본 크기 도트의 차이.**
- **색 수 6~20배.**
- **흐린 가장자리.**
- **표정 대신 디테일.**

이번에는 **메이플 원본과 같은 방식**으로, 게임에 바로 넣을 수 있는 원본 크기 그림을 **몇 장만** 그린다. 프레임 세트는 아직 그리지 않는다.

## 규칙 (분석 문서의 「앞으로의 그림 규칙」 그대로)

| 항목 | 규칙 |
| --- | --- |
| 크기 | **원본 크기로 그린다. 게임 배율 1, 줄이거나 키우지 않는다.** 일반 몹 키 80~105px, 보스 180~240px, NPC 75~95px |
| 가장자리 | 실루엣이 딱 끊긴다 (반투명 0, 알파는 0 또는 255). 반투명은 발광 오라에만 |
| 외곽선 | **1px**, 부위 고유색의 짙은 색 (남색 망토 → 짙은 남색 선). 흰 수염·뼈 → 회색 선. 안쪽 선은 최소 |
| 명암 | 빛은 왼쪽 위. 부드러운 2~3단 그라데이션 + 작은 하이라이트. **잡결·깃털 한 올·질감 붓 터치를 그리지 않는다** |
| 색 | 한 그림 **300~1,000색**. 몸 휘도 80~130, 채도 0.35 이상. 강조색 하나를 세게 |
| 비율 | 사람형 **2~3등신**, 머리·눈·손·무기 크게 |
| 얼굴 | 표정이 먼저. 빛나는 눈, 찌푸린 눈썹, 이빨 웃음. 섬뜩함은 눈으로 |
| 위험한 느낌 | 몸을 어둡게 칠하지 말고 실루엣 밖 **발광 오라**로 (엘더레이스·데미안처럼) |
| 아이디어 | 64px에서 읽히는 아이디어 하나 + 소품 하나. **무서움 6 : 우스움 4** |
| 금지 | 굵은 일정한 먹선, 딱딱한 3단 셀 명암, 정면 대칭 자세, 사실 비율 (1차 시안·2차 목업의 결) |

**옆에 놓고 비교할 진짜 메이플 몹** (`docs/art/maple-reference/maple-packs.csv`에 RUID가 있다):
- 엘더레이스: 두건 속 검은 얼굴 + 보라 오라.
- 타락한 상급 마법사: 2.5등신 사제 + 오라.
- 검은 마녀: 큰 모자, 지팡이.
- 족장 크릴라: 빛나는 눈의 새 괴물.
- 도둑 까마귀: 소품 하나로 성격.
- 쿨리 좀비: 우스운 좀비.
- 해군 하사 유령: 바다 유령.

## 그릴 것 — 4장 (각 stand 1장, 투명 PNG, 원본 크기)

| 파일 | 대상 | 아이디어 (더 좋으면 바꿔도 된다) | 비교할 메이플 몹 |
| --- | --- | --- | --- |
| `stormcaller.png` | 폭풍 주술사 (일반 몹) | 깃털 망토 두건 속 검은 얼굴에 청백으로 빛나는 두 눈. 머리 위에 작은 먹구름 하나가 붙어 다닌다. 새 해골 지팡이 | 엘더레이스 · 타락한 상급 마법사 |
| `drownedsailor.png` | 익사한 선원 (일반 몹) | 퉁퉁 불은 파란 얼굴에 따개비, 입에서 거품. 헤 벌린 우스운 표정. 부러진 노 | 쿨리 좀비 · 해군 유령 |
| `admiral.png` | 익사한 제독 바렌 (보스) | 거대한 삼각모와 수염 속 빛나는 눈, 몸보다 큰 닻. 찢어진 유령선 돛 망토. 청록 오라 | 족장 크릴라 · 데미안 (보스 존재감) |
| `harbormaster.png` | 항구 관리인 브람 (NPC) | 비옷 입은 다부진 아저씨가 큰 등불을 들었다. 사람이라 몬스터와 달리 따뜻한 색, 친근한 표정 | 메이플 마을 NPC |

**네 장을 그리기 전에 확인:**
- 각 그림을 해당 메이플 몹 원본 옆에 같은 배율로 놓고 같은 게임으로 보이는지 확인한다. 각 PNG 옆에 `-vs-maple.png`를 하나씩 둔다.
- 플레이어 아바타 컷(`docs/requests/style-trial/ingame-compare.png`의 「인꾸」)과도 나란히 놓는다.

## 납품

- 위치: `assets/codex-maple-native-v1/png/` (4장) · `previews/` (`*-vs-maple.png` 4장 + 네 장을 한 줄로 놓은 `lineup.png`)

- 각 그림마다 잰 값을 처리 결과에 적는다: 키 px · 색 수 · 반투명 픽셀 비율 · 몸 휘도 · 채도. `docs/art/maple-reference/metrics.json`과 같은 방식으로 잰다.

- 처리 결과: `docs/requests/codex-maple-native-delivery-YYYYMMDD.md`
