# Codex 요청 — 그림 전수조사 결과: 새로 그릴 것 (2026-10-11, Claude)

사용자 요청(10-11): 「버프·디버프 칩은 코덱스 그림으로, 새 스킬·강화도 그림 요청, 이번 수정과 상관없이 그림이 더 필요한 곳을 전수조사해서 진행. 밀린 것도.」
조사 범위: `data/*.csv` 전체 · UI 코드 · 이펙트 · 예전 요청서 9개. **이미 받았는데 연결만 안 된 것은 Claude가 연결한다** (아래 「Claude 쪽」). 이 문서는 **새로 그려야 하는 것**만 담는다.
액트 3 몬스터·NPC·타일은 따로: [codex-act3-art-20261011](codex-act3-art-20261011.md).

## 0. 공통 규칙

| 항목 | 내용 |
|---|---|
| 화풍 | 지금 게임과 같음: 어두운 고딕, 배경 투명, **글자 없음**. 아이콘은 기존 `codex-ui-v2` 스킬 아이콘과 같은 톤 (닳은 철·청동·뼈) |
| 색 규칙 | 소환 보라 · 혼 청보라 · 독 녹색 · 저주 붉은색 · 냉기 하늘색 · 번개 청백 |
| 저장소 | **그룹 저장소(OJYYQ)** |
| 넣을 곳 | 각 표의 「넣을 칸」에 RUID를 넣는다. `ui_icons.csv`는 `key,ruid,color,alpha,note` 한 줄 추가 (color `#FFFFFF`, alpha `1`) |
| 납품 기록 | `docs/requests/codex-art-backlog-delivery-YYYYMMDD.md` |

순서는 **우선순위 순**이다. 1·2부터 주면 가장 먼저 화면이 좋아진다.

## 1. (최우선) 버프·디버프 칩 4장 + 디버프 테두리

화면 왼쪽 위 버프 줄. 지금은 색 원 + 글자라 「저게 뭐냐」는 지적을 받았다 (10-11). 코드는 이미 그림을 받을 준비가 돼 있다: `ui_icons.csv`에 아래 키가 생기면 색 원 대신 그 그림 + 남은 시간 글자를 보여 준다.

| 넣을 칸 (`ui_icons.csv` key) | 뜻 | 그림 제안 | 크기 |
|---|---|---|---|
| `buff_command` | 호령 오라 (상시) | 해골 군기와 뿔나팔, 금빛 오라 | 64×64 |
| `buff_bone_armor` | 뼈 갑옷 (흡수량 숫자 표시) | 상아빛 갈비뼈 방패 한 장 | 64×64 |
| `debuff_chill` | 냉기 둔화 (이동 −40%) | 서리 낀 발자국과 얼음 결정 | 64×64 |
| `debuff_potion_curse` | 미라의 저주 (물약 회복 −30%) | 누런 붕대가 감긴 금 간 붉은 물약병 | 64×64 |
| `debuff_frame` | 디버프 테두리 (모든 디버프 칩 위에 겹침) | 붉은 가시 원형 테두리, 가운데 투명 | 64×64 |

- 칩 모양: **둥근 배지**. 아래쪽 1/3은 어둡게 두어 남은 시간 글자(흰 글씨, 13px)가 읽히게.
- 신전 6종(분노·수호·지혜·혼·군세·샘)은 이미 받은 `shrine_*` 아이콘을 Claude가 연결한다 → 같은 배지 모양으로 맞추면 좋다 (다르면 Claude가 원형 테두리를 겹쳐 맞춘다).
- 액트 3에서 **번개 감전** 디버프가 생긴다 → `debuff_shock` (청백 번개가 감긴 손) 1장도 같이.
