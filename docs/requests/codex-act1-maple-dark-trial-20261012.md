**눈으로 본 차이**
- **메이플:** 머리 큰 단순한 덩어리, 2~3단 매끈한 명암, 몹마다 대표 색 하나(검은 마녀 보라 · 크릴라 남색+청록 눈빛). 무서움은 표정 한 방(빛나는 눈 · 이빨 웃음 · 눈 밑 그늘)에서 나온다.

## 재는 법 (Claude가 쓰는 계산과 같다)

- 몸 안쪽 = 알파 ≥ 200이고 상하좌우 이웃이 모두 불투명인 픽셀.
- 가장자리 = 알파 ≥ 200인데 투명(알파 < 40) 이웃이 있는 픽셀.
- 휘도 = 0.2126R + 0.7152G + 0.0722B.
- 잔결 = 몸 안쪽에서 가로·세로로 이웃한 두 픽셀의 휘도 차 평균.
- 채도 = (max − min) / max 평균.
- 같은 계산 코드는 `docs/art/maple-style-analysis.md`의 수치를 낸 방식이다. 메이플 원본 102종 중앙값은 잔결 20.9 · 채도 0.40 · 몸 휘도 101이다.
