# Codex 요청 — 이야기 카드 배경 그림 11장 (2026-10-12, Claude)

## 왜

10-12에 **이야기 카드**를 넣었다 (`docs/design/18-story-readability-review.md` §5).
- 새 캐릭터 시작 내레이션, 액트 마을 첫 입장 장 표시, 액트 보스 뒤 장 마무리.
- 화면을 어둡게 덮고 가운데에 글만 띄운다.

사용자 평 (10-12): 「빈 화면이라 아쉽다. 그림이 있어 좀 더 풍부했으면 한다.」
→ 카드마다 **전체 화면 배경 그림**을 깐다.
- 코드는 이미 준비돼 있다. `ui_icons.csv`에 `story_*` 행이 생기면 바로 나온다.
- 지금은 그림이 없어서 장 표시·장 마무리에만 그 액트 보스 의뢰 그림을 작은 액자로 임시로 띄운다.

## 결 — 의뢰 그림과 같은 회화풍

정답 예시는 지금 의뢰 그림 원본이다. 원본 크기 1254px, 어두운 고딕 회화풍.
- `assets/codex-quest-minimap-v1/originals/quest_art6.png` (액트 1 · 여왕의 무덤 — 왕관 · 장례 천 · 고딕 문)
- 액트 2 의뢰 그림 `quest_art12` (대사제), 액트 3 `quest_art18` (제독) 원본

인게임 메이플식 몬스터 그림과는 다른 결이다. 의뢰 창·이야기 카드처럼 **전체 화면 일러스트**에만 쓰는 결이다.

**공통 규칙**
| 항목 | 규칙 |
| --- | --- |
| 크기 | **1600 × 900 PNG** (16:9). 테두리·글자·로고 없이 그림만 |
| 밝기 | 게임에서는 검은 바탕 위에 **불투명도 50%로 어둡게** 깐다. 어둡게 해도 형태가 읽히도록 주제의 명암 대비를 분명히 |
| 구도 | 화면 **가운데 가로 띠(위아래 35~65%)에 글이 올라간다** (제목·본문). 그 띠는 비교적 차분하고 어둡게, 주제는 위쪽 1/3이나 좌우에 둔다 |
| 빛 | 액트 1 = 무덤 초록 + 잿불 주황 / 액트 2 = 모래 금빛 + 붉은 노을 / 액트 3 = 폭풍 청회색 + 등대 불빛 |
| 혼각 | 세 액트를 잇는 **검은 돌** (혼이 각인된 돌). 갈라진 흑요석 같은 덩어리, 금 사이로 **초록 빛**이 맥박친다. 등장할 때마다 같은 모양 |
| 금지 | 흐르는 피·살점, 일그러진 공포 얼굴, 악마·부두 소재 (액트 1 세계관과 같다) |

## 그릴 것 11장

### 시작 내레이션 5장 (쪽마다 한 장)

| 키 | 글 (그 쪽에 함께 나옴) | 그림 |
| --- | --- | --- |
| `story_prologue1` | 잿빛 변경. 역병과 전쟁으로 무너진, 묘지기 여왕의 왕국. | 재가 내리는 하늘 아래 무너진 고딕 성채와 끝없는 무덤 들판. 쓰러진 왕국 깃발(무덤 왕관 + 등불 문장) |
| `story_prologue2` | 땅속에서 검은 돌 「혼각」이 떠오르자, 묻힌 자들이 다시 걷기 시작했다. | 갈라진 땅에서 떠오르는 혼각, 초록 빛. 주위 무덤에서 손과 녹슨 투구가 솟는다 |
| `story_prologue3` | 혼각은 망자를 부린다. 그리고 그 돌을 쥔 자를 끝내 먹어 치운다. | 혼각을 쥔 교단 사제의 손 — 팔을 따라 검게 갈라지고, 작은 혼 얼굴들이 돌 속으로 빨려 든다 (얼굴은 그림자로) |
| `story_prologue4` | 너는 마지막 네크로맨서. 망자를 부리지 않고, 혼을 등불에 거두는 자. | 플레이어 네크로맨서의 **뒷모습**. 후드 망토, 손에 든 등불로 떠도는 혼들이 부드럽게 모여든다. 얼굴은 보이지 않게 |
| `story_prologue5` | 잿불 야영지의 사제 오렌을 찾아가라. | 폐허 사이 모닥불 하나가 꺼지지 않는 야영지. 멀리 지팡이를 짚은 노인 실루엣(사제 오렌), 천막 몇 채 |

### 장 표시 3장 (액트 마을에 처음 들어올 때, 제목·부제만)

| 키 | 제목 · 부제 | 그림 |
| --- | --- | --- |
| `story_act1` | 제1장 · 잿빛 변경 — 무덤이 된 왕국, 깨어난 여왕 | 지하 납골당 깊은 곳, 장례 촛불 사이 왕좌에 앉은 묘지기 여왕의 실루엣과 늘어선 근위대 (여왕 얼굴은 멀리 작게) |
| `story_act2` | 제2장 · 모래 폐허 — 끝나지 않는 왕국을 꿈꾼 대사제 | 붉은 노을 아래 모래에 반쯤 묻힌 사원과 거대한 왕 석상들. 사원 꼭대기에 태양 원반 지팡이를 든 대사제의 실루엣 |
| `story_act3` | 제3장 · 폭풍 해안 — 가라앉은 함대와 꺼진 등대 | 폭풍 치는 밤바다, 불 꺼진 등대 아래 반쯤 가라앉은 함대의 돛대들. 바다 밑에서 희미한 초록 빛 |

### 장 마무리 3장 (액트 보스 의뢰를 보고한 뒤)

| 키 | 글 | 그림 |
| --- | --- | --- |
| `story_end1` | 여왕이 쓰러지자, 무덤 왕국에 처음으로 고요가 내렸다. / 그러나 관 속의 혼각은 조각이었다. 나머지는 사막으로 흘러갔다. | 열린 석관, 꺼져 가는 초록 빛 속 **반쪽짜리 혼각 조각**. 관 옆에 벗겨진 무덤 왕관 |
| `story_end2` | 대사제가 쓰러지고, 사막의 모래가 가라앉았다. / 성소의 기록은 바다를 가리켰다. 검은 돌을 실은 함대, 제독 바렌. | 무너진 성소 제단 위 펼쳐진 낡은 두루마리(글자는 알아볼 수 없게), 열린 문 너머로 멀리 보이는 바다와 함대의 돛 |
