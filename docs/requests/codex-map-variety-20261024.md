## 공통 규칙

| 항목 | 내용 |
|---|---|
| 시점·화풍 | 지금 맵 장식과 같은 **탑다운(위에서 비스듬히)** · 메이플 다크 카툰 · 같은 외곽선 굵기. 기준: `assets/codex-act23-maple-v1`, `assets/codex-act4-v1`, 액트 1 `marsh-*` · `execution-*` 장식 |
| 크기 | **게임에서 보일 크기 그대로 그린다** (그린 픽셀 ÷ 100 ≈ 게임 칸). 캐릭터 키 약 75px · NPC 약 160px. 액트 4처럼 작게 그려 2배 넘게 키우지 않게 |
| 바탕 | 투명 PNG. 장식·랜드마크는 **발밑 가운데가 기준점** (발밑 옅은 그림자 포함). 바닥 무늬는 **가운데 기준점**, 그림자 없음 |
| 바닥 무늬 | 납작하게 땅에 붙은 그림만 (세워진 물건 금지). 가장자리는 바닥에 녹아들게 부드럽게 — 네모 테두리가 보이면 안 된다. 색은 바닥보다 살짝 어둡거나 밝게만 |
| 액트 색 | 1 잿빛 흙·핏빛 · 2 모래 황토·바랜 뼈·청록 유약 · 3 젖은 청록 모래·녹슨 쇠·창백한 소금 · 4 검붉은 현무암·용암 주황·유황 노랑·혼 보라 |
| 매력 | 액트마다 「귀엽게 웃긴 것」 하나씩 섞어도 좋다 (예: 해골이 쓴 냄비 모자, 모래에 파묻혀 손만 흔드는 해골). 무섭기만 하지 않게 |
| 금지 | 글자·숫자·로고. 메이플 원래 오브젝트를 그대로 따라 그리기. 피·시신을 사실적으로 (실루엣·뼈까지만) |
