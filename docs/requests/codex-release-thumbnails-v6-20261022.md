## 05 낫과 낡은 투구 — 「잡은 적이 내 편으로 일어난다」를 한 가지로

1. 투구 속 해골 눈구멍에 **보라 혼불**을 켠다
2. 바위 뒤에서 일어나는 **작은 보라 그림자 실루엣 1개** (메이플 꼬마 몬스터 비율). 과하지 않게, 정물 구도는 유지
3. 양피지 가장자리를 재빛·어두운 보라로 살짝 눌러 흰 배경 목록에서도 카드 경계가 보이게
4. 회색 칼날 뒤 배경을 한 단계 어둡게, 또는 칼날 테두리에 은은한 보라 빛 (작게 볼 때 낫 모양이 흐리다)
5. 단풍잎 약 1.5배
