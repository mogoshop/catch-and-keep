사용자 (10-28): 「액트 3는 현재 바닥이 어떻게 되지 — 물에 젖은 느낌이 나나?」 → 지금은 액트 1 바닥(늪·처형장·지하실 흙)에 푸른빛만 입혀 써서 **이끼 낀 흙처럼 보인다**. 사용자 선택 C: 코덱스 액트 3 묶음 + 그동안 Claude가 젖은 효과(고인 물·물방울·바닷가 안개)를 먼저 깐다.

액트 3 배경: 소금바람 항구 → 소금 갯벌 · 난파선 해안 · 번개 절벽 · 가라앉은 어촌 → 폭풍 등대 1~3층 → 꼭대기 「폭풍의 눈」. 곁가지: 집게 동굴 · 난파선 선창 · 밀수꾼 동굴 · 물에 잠긴 예배당 · 등대지기의 집.
**맵 바닥은 「물에 젖었다」가 한눈에 보여야 한다** — 젖은 표면의 반사광(밝은 하이라이트 몇 점), 고인 물, 소금이 하얗게 말라붙은 가장자리.
