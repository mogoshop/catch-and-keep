# 실기기 확인 체크리스트 — F01·F02·F07~F11·I04 (10-30, 사용자 직접 확인용)

메이커 도구로는 실제 손가락 터치와 마우스 포인터를 쓸 수 없어 남은 칸입니다. 아이패드나 휴대폰으로 5~10분이면 확인할 수 있습니다.
각 항목의 「통과」 조건을 보고 결과 칸에 ○ / × / 해당 없음을 적어 주세요. ×이면 무엇이 보였는지 한 줄 적어 주시고, 가능하면 화면을 캡처해 주세요.
지금 캐릭터로 확인할 수 없는 항목(레벨 부족, 보상 없음 등)은 「해당 없음」으로 두셔도 됩니다.
