# Codex 요청 — 의뢰 그림 · 미니맵 · 조준 표시 (2026-10-09, Claude)

사용자 피드백(10-09 재출시본)으로 화면 구성을 바꿨다. 코드는 임시 그림으로 먼저 동작하며, 아래 그림이 들어오면 `data/ui_icons.csv`에 키만 추가하면 바로 바뀐다.

## 1. 의뢰 그림 6장 (필수) — 디아블로2 의뢰 일지 방식

퀘스트 창(Q)이 위 2×3 그림 + 아래 내용으로 바뀌었다. 지금은 6칸 모두 같은 책 아이콘(`icon_quest`)이라 구분이 안 된다.

| 키 (ui_icons.csv) | 의뢰 | 장면 제안 |
|---|---|---|
| `quest_art1` | 첫 번째 망자 | 혼에서 일어나는 해골 전사 |
| `quest_art2` | 굶주린 구덩이 | 늪 구덩이에서 기어 나오는 무덤 구더기 |
| `quest_art3` | 사라진 병사의 유물 | 형장에 떨어진 낡은 투구·유물 |
| `quest_art4` | 숲의 속삭임 | 교수대 숲의 피의 제단 |
| `quest_art5` | 묘지기의 무덤 | 목 없는 처형인 실루엣 |
| `quest_art6` | 묘지기 여왕 | 여왕의 무덤 입구·왕관 |

- 크기 정사각형 약 256px (칸 안 표시 150px), 어두운 고딕 톤, 테두리 없이 그림만 (칸 테두리는 코드가 그린다).
- **흑백판 6장도 함께**: 키 `quest_art_gray1` ~ `quest_art_gray6`. 엔진이 그림을 흑백으로 바꾸지 못해 아직 열리지 않은 의뢰는 지금 어둡게만 칠한다. 흑백판이 있으면 그것을 쓴다.
- 등록: 기본 이미지 가져오기 → RUID를 `ui_icons.csv`에 `quest_art1,<RUID>,#FFFFFF,1,의뢰 그림 1 (코덱스)` 형식으로.

## 2. 미니맵 (권장)

미니맵을 와우·디아블로 이모탈처럼 바꿨다: 평평한 바닥색 + 표시물은 색 점(출구 빨강·의뢰 노랑·거점 파랑·NPC 흰색) + 아래 짧은 이름, 나는 움직인 방향을 가리키는 초록 삼각형. 두루마리 그림은 모두 뺐다.

| 키 | 용도 | 크기 |
|---|---|---|
| `minimap_round` | **둥근 미니맵 테두리** — 가운데는 투명 원, 원 바깥 네 모서리는 불투명(어두운 돌/뼈 장식)으로 덮어 사각 지도를 둥글게 보이게 한다 (MSW에는 원형 마스크가 없다) | 약 360×360 |
| `minimap_me` | 내 위치 화살표 (위를 향함, 흰색 — 색은 코드가 칠함) | 32×32 |
| `minimap_exit` | 출구 표시 (작은 문/화살 모양, 흰색) | 24×24 |

지금은 메이플 리소스의 작은 노란 삼각형(`fb55e389…`)을 초록으로 칠해 쓰고 있다.

## 3. 조준 방향 표시 (선택)

사냥터에서 캐릭터 앞에 보이던 몬스터 화살 그림을 메이플 리소스의 회색 꺾쇠(`400cf2ff…`, `>` 모양)로 바꿨다. 더 어울리는 그림을 원하면:

| 키 | 용도 | 크기 |
|---|---|---|
| `aim_chevron` | 반투명 꺾쇠(>) — 오른쪽을 향함, 흰색·가장자리만 밝게 | 32×40 |
