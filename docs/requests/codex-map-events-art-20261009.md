# Codex 요청 — 맵 이벤트 그림: 신전 · 저주받은 상자 · 뼈 둥지 (2026-10-09, Claude)

사용자 피드백(10-09 밤): 사냥이 단조롭다 → D2식 맵 이벤트를 넣었다. 사냥터마다 **신전 2 · 저주받은 상자 1 · 뼈 둥지 1** (곁가지 던전은 신전 1 · 상자 1)이 무작위 위치에 놓인다.
코드는 지금 **메이플 리소스 임시 그림**으로 동작한다. 아래 그림이 들어오면 **CSV 칸만 바꾸면 바로 반영**된다 (코드 수정 없음, 단 상자의 열린 그림은 1줄 — 아래 2번 참고).

공통: 탑다운(위에서 비스듬히 본) 시점, 배경 투명, 어두운 고딕 판타지(잿빛·뼈·보랏빛 저주) — 지금 몬스터·UI 화풍. 맵 바닥(MapLayer0) 위에 서는 오브젝트라 **발밑 그림자(살짝 어두운 타원)** 가 있으면 좋다.

## 1. 신전 (필수) — 1장, 색은 코드가 입힌다

| 항목 | 내용 |
|---|---|
| 등록 위치 | `data/objects.csv` `Shrine` 행의 `ruid` 칸 (지금 임시: `48b77fc2…` 뿔 해골 석주) |
| 크기 | 약 **180×280** (세로로 긴 석주·제단). `scale` 칸 0.55 기준 — 원본 크기가 다르면 scale도 맞춰 주세요 |
| 모양 | 돌 제단 위의 **빛나는 수정/불꽃 받침**. 종류가 6개(분노·수호·지혜·혼·군세·샘)라 **빛나는 부분을 흰색·밝은 회색으로** 그려 주면 코드가 종류별 색(빨강·파랑·노랑·보라·초록·하늘)으로 물들인다 |
| 상태 | 쓰면 코드가 회색으로 어둡게 칠한다 (별도 그림 불필요). 원하면 `shrine_used` 1장을 더 주면 연결한다 |

## 2. 저주받은 상자 (필수) — 2장

| 키 | 용도 | 크기 |
|---|---|---|
| 닫힌 상자 | `data/objects.csv` `CursedChest` 행 `ruid` (지금 임시: `85c313c1…` 쇠테 상자) | 약 **140×110** |
| 열린 상자 | `RootDesk/MyDesk/World/CursedChest.mlua`의 `OpenRuid` 기본값 1줄 (지금 임시: `a35c8fab…` 금화 상자 아이콘) | 같은 크기 |

- 닫힌 상자: 쇠사슬·봉인 부적·보랏빛 저주 기운이 새어 나오는 낡은 상자. **다가가면 열리고 매복이 솟는다**는 게 한눈에 보이게 (D2 「저주받은 상자」).
- 열린 상자: 뚜껑이 열려 안이 비어 있고 저주 기운이 흩어진 상태.

## 3. 뼈 둥지 (필수) — 1장

| 항목 | 내용 |
|---|---|
| 등록 위치 | `data/monsters.csv` `bonenest` 행의 `stand`·`move`·`hit`·`die` 칸 (4칸 모두 같은 RUID여도 된다. 지금 임시: `bf49bc6d…` 해골 더미) |
| 크기 | 약 **220×120** (가로로 넓은 더미). `scale` 0.9 · 히트 박스 `hitW 1.4 · hitH 0.7` 기준 |
| 모양 | 뼈·두개골이 엉긴 **몬스터 둥지**, 가운데 틈에서 보랏빛·녹색 기운. 플레이어가 **공격해서 부수는 목표**라 몬스터처럼 또렷해야 한다 |
| 선택 | 부서지는 순간 그림(`die`)이나 맥박치는 애니메이션(`stand` 애니메이션 클립)이 있으면 더 좋다 |

## 4. (선택) 신전 축복 아이콘 6장

지금은 화면 위쪽 글자로만 「분노의 신전 · 주는 피해 +25% · 42초」를 보여 준다. 작은 아이콘(약 64×64, 배경 투명)이 있으면 글자 앞에 붙인다.
`ui_icons.csv`에 `shrine_fury` · `shrine_ward` · `shrine_wisdom` · `shrine_soul` · `shrine_legion` · `shrine_spring` 키로 등록해 주면 연결은 Claude가 한다.

## 등록 후 할 일 (Codex)

1. RUID를 위 칸에 넣는다 (큰 원본이면 `scale`도 맞춤).
2. `node -e "const m=require('./tools/build/models.cjs');const {load}=require('./tools/build/lib.cjs');for(const r of load('monsters').filter(r=>r.id==='bonenest'))m.buildMonster(r,null);for(const o of load('objects').filter(r=>['shrine','cursedchest'].includes(r.id)))m.buildObject(o);"` — 이 세 모델만 다시 만든다 (전체 `models` 빌드는 다른 몬스터 모델을 덮어쓰니 쓰지 말 것).
3. `npm run gen` → `npm test` → 메이커 새로고침 2번 → 사냥터에서 확인 (로그 `[VRF] events <맵> 신전 2 · 상자 1 · 둥지 1`).
