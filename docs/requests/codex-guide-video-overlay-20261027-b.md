## 그릴 것 (투명 PNG, 글자·숫자 없음)

### 1차 요청서에 있던 나머지 (그대로)

| 이름 | 크기 | 내용 |
|---|---|---|
| `ov-mouse-left` / `ov-mouse-right` | 96×128 | 마우스 — 왼쪽/오른쪽 버튼이 보라로 빛남 (지금 「클릭」 글자 키캡 자리를 바꾼다) |
| `ov-tap` | 128×128 | 모바일 손가락 누름 표시 (원 두 겹 퍼짐) |
| `ov-arrow` | 160×96 | 강조 화살표 — 뼈 손가락 또는 낫 끝, 오른쪽을 가리킴 (돌려 쓴다) |
| `ov-step-badge` | 72×72 | 순서 번호 동그라미 (숫자는 Claude가 씀) |

### 추가

| 이름 | 크기 | 내용 |
|---|---|---|
| `ov-tip-strip` | 720×48, 9-slice | **보조 설명 띠** — 자막 띠 바로 위에 붙는 얇은 띠. 왼쪽 끝에 작은 「!」 대신 보라 혼불 점 하나, 나머지는 어두운 반투명. 자막 띠보다 얌전하게 |
| `ov-ring-warn` | 256×256 | 강조 원 **경고판** — 기존 `ov-ring`과 같은 모양, 붉은 금테 (정예 혼 · 붉은 원 · 사망 한도에 씀) |
| `ov-check` | 96×96 | 켜짐·완료 표시 — 보라 혼불 속 체크 (웨이포인트가 켜지는 순간에 띄운다) |
| `ov-plus-rank` | 96×96 | 랭크 올림 표시 — 위로 솟는 금빛 화살 + 작은 해골 (「랭크를 올리면 더 많이」 장면) |
| `ov-town-return` | 96×96 | 마을로 돌아감 — 잿불 모닥불 + 굽은 화살 (「마을에 가야 다시 소환」 장면) |
