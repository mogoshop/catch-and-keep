# Codex 요청 — 액트 3 「폭풍 해안」 그림 (2026-10-11, Claude)

설계: [design/17-act3-storm-coast.md](../design/17-act3-storm-coast.md)
사용자 결정(10-11): **액트 3 그림은 전부 코덱스 신규.** 그림이 오기 전까지 Claude가 메이플 리소스 **임시 그림**으로 먼저 구현하고, 들어오면 **CSV 칸만 바꿔** 교체한다.

구현 순서대로 나눴다 (1단계 → 2단계 → 3단계). 1단계 그림부터 주면 가장 빨리 화면에 붙는다.

## 0. 공통 규칙 (액트 2와 같음)

| 항목 | 내용 |
|---|---|
| 시점·화풍 | 지금 게임과 같은 **탑다운(위에서 비스듬히)**, 배경 투명, 어두운 고딕 판타지. 액트 3 팔레트: 젖은 검푸른 바위 · 소금 흰빛 · 썩은 나무 갈색 · **번개 청백** · 냉기 하늘색 |
| 방향 | 몬스터·NPC는 **왼쪽을 보는 그림** (코드가 오른쪽은 좌우 반전) |
| 기준점 | **발밑 가운데**. 발밑 그림자(옅은 타원)가 있으면 좋다 |
| 저장소 | **그룹 저장소(OJYYQ)** 에 올린다 (개인 저장소 그림은 그룹 월드에서 안 보인다) |
| 애니메이션 | 몬스터는 상태 5개 **stand · move · attack · hit · die** 프레임 (액트 2처럼 `animation-registration.csv` → Claude가 `tools/import_frames.cjs`로 연결) |
| 크기 | 아래 px는 원본 기준 권장. 다르면 `monsters.csv`의 `w`·`h`·`scale`도 맞춰 준다 |
| 색 | 코드가 정예·변종일 때 색을 덧입힌다 → 너무 어둡거나 채도가 극단적이지 않게 |

2. 이펙트·장판 RUID는 `docs/requests/codex-act3-delivery-YYYYMMDD.md`에 이름과 함께 적어 준다 (Claude가 코드에 연결).
3. 처리 결과는 같은 delivery 문서로 남겨 준다.
