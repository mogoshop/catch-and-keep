3. **캐릭터 클로즈업 쇼케이스 (4편: D, 01·07 일부 포함)** — 글자 없이 캐릭터·이펙트를 화면 크게 → 변신/뽑기/비교 연출 한 번 → 제목 로고. 짧은 루프(13~15초).

## 4. 9:16 세로 변환 시험

시험 장면: A 3:31 대혼전, B 6:46 보스전, C 15:28 습격 격퇴. 각 3초, 1080×1920, libx264 crf 18.
- (a) 중앙 크롭: 캐릭터·해골·보스·데미지 숫자가 폰에서 크게 보이고 「습격 격퇴 · 20마리」 배너도 읽힘. 대신 위쪽 안내 문구가 양옆 잘린 반쪽 글자로 남고(A), 아래 단축키 줄이 반쯤 걸림.
- (b) 가로 화면 + 위아래 여백: 게임 화면이 세로 1920 중 608px(32%)뿐이라 캐릭터·숫자가 너무 작아 읽히지 않음. 글자 자리는 넉넉함.
- **결론: (a) 중앙 크롭이 훨씬 잘 읽힘.** 참고 광고의 큐레이터형(b와 같은 배치)은 원래 가로 화면 자체가 큰 도트 그래픽이라 성립하지만, 우리 화면은 탑뷰 작은 캐릭터 + HUD가 많아 (b)에서 정보가 뭉개짐. 권장: 중앙 크롭 위에 훅 글자를 반투명 띠로 얹고, 아래 단축키 줄 자리는 CTA 띠로 덮는 혼합. 다음 녹화는 HUD·이름표를 끄고 카메라 줌을 당겨 찍으면 크롭 손실이 줄어듦.

## 5. 한계

- 참고 광고의 음성 나레이션 유무는 파형으로만 봤고 실제로 듣지 못해 판별 불가로 적음. 21편 모두 화면 녹화라 처음·끝 0.3~1초에 인스타 화면·제어 센터가 섞임.
- 13번 게임 이름, 19번 게임 이름은 화면에서 판독 불가.
- play.mp4는 20초 간격 108칸 + 5초 간격 345칸 + 후보 구간 1초 간격 띠로 봤음. 그 사이 몇 초짜리 순간(예: 망령 도약, 본 골렘 소환 순간, 레벨업 결산 판)은 놓쳤을 수 있음. 본 골렘 거인·화염 노바·망령 도약을 이름으로 확인할 수 있는 장면은 찾지 못함.
- 프레임 드롭은 키프레임 간격·중복 프레임 비율로 추정한 것이며, 게임 자체 프레임 수치는 녹화에 없음.
- 하이라이트 대표 프레임 시각은 ±0.5초 오차가 있을 수 있음(빠른 탐색 기준).
