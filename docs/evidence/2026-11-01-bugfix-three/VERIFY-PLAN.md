# 11-01 실플레이 문제 3건 (A안) — 메이커 확인 절차

구현 레인은 메이커를 쓰지 않았다 (다른 레인 점유). 오프라인 확인은 `npm test` 20/20 · `python3 tests/quality/run.py --lua <lua> bugfix_three` 66건 · 기존 품질 그룹 전부 · GameHUD ui_lint 오류 0.
아래는 메이커에서 **실제 플레이어 여정**으로 확인할 순서다. 함수 직접 호출(`maker_execute_script`로 RemainingFocus 등 부르기)로 대신하지 않는다.

공통 준비: 메이커 플레이 중지 → `refresh` 2번(새 UI 요소·새 동기화 속성 `MonsterSpawner.Alive`) → `logs(kind="build")` 오류 0 → `clear_logs` → 플레이.

## 1. 미니맵 노란 점 (남은 망자 안내)

바뀐 것: `HudMap.RemainingFocus` — 살아 있는 몬스터(대기 묶음 제외 `MonsterSpawner.Alive`) ≤ `GameConst.MinimapRemainMax`(3) **그리고** 남은 수(대기 묶음 포함 `Remaining`) ÷ 처음 총수(`InitialTotal` = `Total`) ≤ `MinimapRemainRatio`(0.2)일 때만. 퀘스트 목적지가 다른 맵이거나 이 맵 안 목적지 점(NPC·제단)이 있으면 덮어쓰지 않는다.

### 1-a. 이 맵이 목표 (안내가 나와야 함)
1. 의뢰 1 「굶주린 굴」(clear · hollow)을 받은 캐릭터(새 캐릭터 슬롯 Lv1~3)로 마을에서 걸어서 **굶주린 굴(hollow)** 입장.
2. 몬스터를 실제 공격 입력으로 처치해 나간다. 미니맵을 계속 본다.
3. 기대:
   - 처치 초반·중반: 노란 목표 점·고리가 몬스터를 가리키지 않는다. 미니맵 아래 글 = 「이 지역에서 퀘스트 진행」.
   - 로그 `[VRF] minimap remain focus alive=… total=… ratio=… goalElsewhere=false -> hide:many` 또는 `-> hide:ratio` (값이 바뀔 때만 한 줄씩).
   - 살아 있는 수 3 이하 **그리고** 남은 비율 0.20 이하가 되는 순간: `… goalElsewhere=false -> show` 한 줄, 미니맵 노란 점이 가장 가까운 몬스터로 · 안개 속이어도 보임 · 글 「남은 망자 N — 가까운 곳 표시」(N = 살아 있는 수).
   - 같은 맵 서버 로그 `[VRF] clear remaining=R (pending P) live=L total=T` 와 대조: 클라이언트 alive = L, ratio = R/T.
4. 깨우기 대기 묶음이 남아 있는 동안(서버 로그 pending > 0)은 살아 있는 수가 3 이하여도 `-> hide:ratio`여야 한다.

### 1-b. 퀘스트 목적지가 다른 맵 (덮어쓰면 안 됨)
1. 의뢰 2 「가라앉은 지하실의 수장」(boss · cellar2)을 받은 상태로 **가라앉은 지하실 1층(cellar1, 처치 전용 맵)** 입장.
2. 몬스터를 거의 다(살아 있는 수 1~3) 처치할 때까지 진행.
3. 기대: 미니맵 노란 점은 계속 **cellar2로 가는 출구 포털**(글 「다음 길: …」). 로그 `… goalElsewhere=true -> hide:goal-elsewhere`. 몬스터로 점이 옮겨 가지 않는다.
4. (선택) 의뢰 보고 단계(목표가 마을)로 같은 맵에 들어가도 같은 결과(출구·웨이포인트 안내 유지).

## 2. 정예 승격 혼동 (스킬 창 「선택 보상」 줄)

바뀐 것: 스킬 창 머리 줄 가운데(예전 트리색 범례 자리)에 「선택 보상」 3칸(`SkillWin/Choice/C1~3`) · 범례는 시간선 판 머리 줄(`SkillWin/TL/Legend`)로 · 선택 보상 카드와 새 칸 아이콘 모서리에 「선택 보상」 꼬리표 · 정예 승격 상세에 구분 문장.

1. 의뢰 5 「목 없는 처형인」(chest · cave)을 막 끝낼 캐릭터(Lv9 안팎)로 목매단 동굴(cave)에서 상자 의뢰 완료 → 마을에서 보고.
2. 선택 보상 카드 창이 스스로 열린다 → 세 카드 아이콘 오른쪽 아래에 「선택 보상」 꼬리표(금빛 판) 확인 → 군단 「정예로 서는 그림자」 → 확인 창 「고르기」.
   - 로그 `[VRF] choice reward render slot=2 tier=1` · `[VRF] choice pick slot=2 axis=command tier=1`(서버).
3. 스킬 추천 띠(포인트가 있으면)를 눌러 스킬 추천 카드를 열고 꼬리표가 **없는지** 확인.
4. K로 스킬 창 열기. 기대:
   - 머리 줄 가운데 「선택 보상」 + 3칸: 칸 1(의뢰 2 끝냈으면 고른 보상 · 아니면 「고르기」/잠금), 칸 2 = 정예 승격 아이콘 + 꼬리표 · 「정예로 서는 그림자」 · 「노말」, 칸 3 = 잠금 아이콘 · 「메마른 우물의 혼」 · 「의뢰 전」.
   - 로그 `[VRF] skill choice row slot=1 axis=… tier=…` · `slot=2 axis=command tier=1` · `slot=3 axis=locked tier=0`.
   - 트리색 범례(■ 소환 ■ 영혼 ■ 저주 ■ 이동)는 시간선 판 「해금 시간선」 제목 오른쪽, 「다음 해금 …」 글과 겹치지 않는다. 머리 줄 선택 보상 칸이 「남은 포인트」 글·초기화 단추와 겹치지 않는다.
5. 칸 2 클릭. 기대: 아래 공방 자리 = 정예 승격 아이콘 · 「정예로 서는 그림자」 · 「선택 보상 · 목 없는 처형인 · 노말」 · 설명 2줄 · 「지금 단계: 노말 / 다음 단계: 악몽 ×1.35 · 지옥 ×1.45 / 선택 보상 — 스킬과 별개로 늘 적용됩니다」. 랭크 점·강화 노드·배우기/스킬 칸에 넣기 단추가 사라지고 칸 2 테두리가 금테.
   - 로그 `[VRF] skill choice pick slot=2 shown=2` · `[VRF] skill choice detail slot=2 axis=command tier=1`.
6. 칸 2를 한 번 더 클릭 → 원래 스킬 공방(단추·노드 복귀). 다시 칸 2 → 시간선 아무 스킬 클릭 → 그 스킬 공방으로.
7. 시간선 Lv33 열의 **정예 승격** 클릭 → 설명 칸 끝에 회색 줄 「선택 보상 「정예로 서는 그림자」와는 다른 스킬입니다」. 뼈 창·골편 투척·그림자 소환 등 다른 스킬 설명에는 그 줄이 없다.
8. 고를 차례인 칸이 있는 캐릭터(의뢰 2·5·9 중 끝냈는데 아직 안 고름)라면 그 칸 「고르기」 클릭 → 스킬 창이 닫히고 선택 보상 카드 창이 그 칸으로 열린다 (`[VRF] skill choice open reward slot=N`).
9. 모바일(iPad 미리보기)로 4~5를 반복해 머리 줄이 잘리지 않는지 본다 (칸 높이 52 = 기존 초기화 단추 48과 같은 줄 · 터치 88 미만은 기존 머리 줄과 같은 조건).

## 3. 랭킹 「내 순위」

바뀐 것: `RankingSystem.RequestBoard`가 상위 10과 별도로 요청자 본인 순위·값(`MineDigest` → "순위|값" / "none")을 `ShowBoard(kind, diff, digest, mine)`로 보낸다. 창 목록 아래 구분선 + `RankWin/Paper/Mine` 한 줄.

1. 아무 캐릭터로 게임 방 입장 → 0.5초 이상 기다림(입장 성장 기록).
2. L로 랭킹 창 열기(성장 순위 탭). 기대:
   - 목록(상위 10) 아래 구분선, 금빛 한 줄 「내 순위  N위 · LvX · 노말 액트 Y」.
   - 서버 로그 `[VRF] rank mine board=rank_progress_0 rank=N value=V` (V = 레벨×100 + 난이도×10 + 액트). 메이커 저장소는 배포판과 따로라 보통 N = 1~몇.
3. 보스 처치 시간 탭: 기록이 있으면 「내 순위  N위 · S초」, 없으면 「내 순위  기록 없음」 · 로그 `board=rank_boss_<id>_<diff> rank=0 value=0`.
4. 기록 없음 경로: `maker_reset_data_storage`로 저장소를 비운 직후(사용자 승인 필요) 입장 0.5초 안에 L → 「내 순위  기록 없음」 · 다시 열면(5초 뒤) 순위가 보인다(내 순위 조회가 성장 기록을 한 번 적음).
5. 탭을 빠르게 여러 번 눌러도 같은 판 5초 안에는 `[VRF] rank mine` 줄이 늘지 않는다(연타 방지).
6. 심연을 켠 설정(depthEnabled 1)이면 심연·이번 주 탭에서도 「내 순위  N위 · F층 · M분 SS초」 형식.

## 판정
- 위 `[VRF]` 줄이 모두 나오고 값이 기대와 같으며 빌드 오류 0이면 PASS. 하나라도 빠지면 FAIL → 구현 레인으로.
- 화면 확인(겹침·꼬리표 위치)은 사용자 요청이 있을 때만 캡처.
