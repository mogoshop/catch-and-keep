## 1. 맵 레이어
- Map Layer › Relationship Between Map Layer and Player Avatar › Example 2 — 4개 레이어에 타일·오브젝트를 나눠 둠. 아바타는 밟고 선 타일의 레이어에 속함 → 초록 타일(낮은 층) 위 아바타는 Layer4 나무 뒤로, 연두 타일(Layer3) 위에서는 Layer2 장난감 앞으로. 「불길·덤불을 통과하는 연출」에 쓰라고 권함.
- Map Layer › Relationship… (본문) — 아바타 외 엔티티는 처음 놓인 레이어에 고정. 아바타만 밟은 엔티티(타일·발판)에 따라 레이어가 바뀜.
- Map Layer › Understanding Map Layer › Model's Layer Order — 기본 OrderInLayer: 오브젝트 0 · 타일 1 · 몬스터·NPC·발판·포털·아이템 2 · 남 아바타 3 · 내 아바타 4. 「3 이상은 넣지 말 것」(아바타가 가려짐).
- Map Layer › Layer Priority Rules — 정렬 = ① 맵 레이어(SortingLayer) ② OrderInLayer ③ Z.
- Map Layer › Map Layer Window Configuration — 레이어는 최대 10개.
- Utilizing RectTileMap › Layer Setting › Adding a Layer — 레이어를 추가하면 RectTileMap 엔티티가 하나 더 생김(레이어마다 타일맵).
- Utilizing RectTileMap › Applying Tile Set by Layer — 레이어마다 다른 타일셋을 쓰라고 권장.
- Understanding MapleStory Movement Concepts › Intensive Movement › SortingLayer — RigidbodyComponent를 가진 엔티티(플레이어)는 지금 밟은 타일맵 레이어로 SortingLayer가 바뀜. 예시는 숲 오브젝트를 Layer2에. ※ RectTile 몸(KinematicbodyComponent)에 대한 언급은 없음.

## 2. RectTile 그림
- RectTile Creation › Preparation — 기본 타일 64×64px. 높이 타일은 여러 칸.
- RectTile Creation › Tile Type — 기본(무늬 없음/있음) · 연결 타일(길) · 높이 타일(벽: 64px 두 칸 권장 · 계단).
- RectTile Creation › Drawing Default Tiles › Connection Tiles — 길 하나에 최소 12장(3×3 + 2×2), 겹치는 경계에 그림자를 그려 자연스럽게.
- RectTile Creation › Drawing Height Tiles › Wall Tiles — 위아래 4~6px 여백, 윗면은 밝게·아래는 어둡게, 마지막에 그림자·풀.
- RectTile Creation › Patterned Tiles — 무늬는 자동 효과보다 손으로, 불규칙한 모양을 섞어 단조로움을 피함.

## 3. 조명
- Using LitMode and Light Sources › Applying Light Sources — 빛 적용 4가지: LightComponent · 머티리얼 LitMode · LitMode 속성 컴포넌트 · 서비스.
- 같은 문서 › Applying Light Sources (절) — TargetAllSortingLayers / TargetSortingLayers. 층마다 따로 빛 텍스처를 만들어 그림 → 「모바일에는 부담일 수 있음」.
- 같은 문서 › LitMode — Default(WorldConfig.UseLitDefaultMaterial 따름) · Lit(빛 받음) · Unlit(빛 무시, 가벼움). UI·TextComponent 등은 늘 Unlit.
- 같은 문서 › LitMode › Components — AreaParticle·BasicParticle·SpriteParticle·DamageSkinSetting은 LitMode를 따로 정할 수 있음.
- Controlling Overlay Lights › Types of Light Sources — Spot(원 · Scale 영향 없음) · Freeform(모양 직접) · Global(화면 전체 · 한 SortingLayer에 Global 여럿 동시 불가) · Sprite(스프라이트 모양 빛).
- Controlling Overlay Lights › Controlling Light Sources › Removing… / OverlayLightService — 서비스로 만든 빛은 씬에서 안 보이지만 엔티티를 만들지 않아 OverlayLightComponent보다 부하가 적음.
- Controlling Overlay Lights › Checking Overlay Light — SetOverlayLightEnabled(true) 필요, 광원이 하나도 없으면 화면 전체가 어두움.
- Controlling Overlay Lights › Main Properties › Light Combinations — Additive(겹칠수록 밝음) / AlphaBlend(LightOrder 큰 쪽 색).
