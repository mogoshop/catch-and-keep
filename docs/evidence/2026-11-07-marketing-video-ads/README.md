# 홍보 영상 시안 (2026-11-07)

ffmpeg 조립기 `tools/promo/build_ad.mjs`로 만든 시안 13편. 1차(`v1-`)는 `play.mp4`(35분 실제 플레이 녹화), 2차(`v2-`)는 새 녹화 `rec/scene-*.mp4`(HUD·이름표 끔, 무음) 재료.
글귀는 확정본이 아니라 고르기용이라 받은 그대로 썼습니다. mp4는 `assets/maple_maketing_video/out/`과 `video/`에 있고 커밋하지 않았습니다.

## 다시 만들기

```
node tools/promo/build_ad.mjs tools/promo/cuts/rec/v2-ad1-fixed.json
```
컷 목록(JSON)에서 `src`(재료 경로, `assets/maple_maketing_video/` 기준)·`start`·`dur`·`cx`/`sy`(크롭 위치)·`cap`(자막 번호)·`blur`(흐림 상자)만 바꾸면 됩니다. 글귀 세트는 `tools/promo/copy.json`.
- 세로: 위 380px 훅 띠 → 원본 540×770을 정확히 2배로 키운 화면(1080×1540) → 아래 한 줄 띠. 크롭 폭은 608이 아니라 540(2배 정수 확대). 608×1080→1.78배와 비교해 글자·캐릭터 윤곽이 덜 뭉개졌습니다.
- 출력: H.264 High, CRF 18, 30fps, AAC 192k, faststart. 컷 사이 0.2초 디졸브(가로 0.25초), 마지막 1.5초 엔드카드(가로 2.5초).
- 글자: ffmpeg에 drawtext(freetype)가 빠진 빌드라 `promo_overlay.py`(Pillow)가 투명 PNG로 그려 겹칩니다. 글꼴은 `~/Library/Fonts`의 Pretendard(ExtraBold 훅 · Bold 아래 줄 · Black 자막/엔드카드). 너비를 넘으면 자동 축소(이번 13편은 축소 없음).

## 흐림 (1차 · play.mp4)

- ffmpeg 쪽 자동 감지(어두운 상자+글씨)는 바닥 타일 경계에 수백 곳 걸려서 버렸습니다.
- 대신 이름표 견본 4개(`tools/promo/tags-play.json`, 같은 글자는 같은 그림)를 프레임마다 정규화 상호상관으로 찾고(흰 정도 채널 + 밝기 채널), 앞뒤 6프레임 동안 자리를 유지하며 모자이크+흐림. 진짜 이름표 점수 0.6~1.0, 「COMBO」 글자 오검출 0.57이라 견본별 문턱을 둠.
- 「그림자 획득」(7:03) 컷은 섬광에 이름표가 물들어 문턱을 낮추고(0.50/0.55) 상자를 넓혀 처리 → 이 컷은 흐림이 넓게 번져 화면이 뿌옇습니다.
- 파티 목록(왼쪽)·미니맵·랭킹·채팅은 세로 중앙 크롭 밖. 가로 트레일러의 제3장 컷은 왼쪽 위 「파티 (3) · 닉네임」 줄을 고정 상자로 흐림.
- 접촉판 16칸 + 혼잡 컷 원본 배율 확대로 확인: 읽히는 닉네임은 찾지 못함. 다만 견본 4개 밖의 이름(다른 파티원 이름, 몹 사이로 가려진 반쪽 이름표)은 남을 수 있어 1차는 내부 검토용으로만 권장.

## 소리

- 1차: play.mp4 게임 소리를 컷마다 잘라 0.2초 크로스페이드로 잇고 loudnorm 2단계(I=-16 LUFS, TP=-1.5) → 약 +32 dB. 엔드카드 전 0.6초 페이드아웃.
- 2차: 새 녹화는 무음이라 play.mp4 7:37 이후(1초 RMS 변동 최소, 배경음 위주 구간) 소리를 -20 LUFS 바닥 소리로 깔았습니다. 효과음이 화면과 맞지 않으니 어색하면 컷 목록에서 `"audio": "none"`으로 무음 처리하면 됩니다.
- 음악은 라이선스 확인된 것이 없어 넣지 않았습니다.
