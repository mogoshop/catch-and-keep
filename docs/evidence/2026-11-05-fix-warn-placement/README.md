# 화면 정중앙 안내 메시지 정리 (11-05)

사용자(11-05): 「아이템창이 차서 습득할수없다등의 안내 메시지가 정중앙에 나오는경우가 있네. 위치조절이 안된 안내메시지가 있는지도 파악해줘.」

## 결론
- 정중앙에 뜨던 안내는 **경고 한 갈래**뿐이었습니다. `Util.Warn`(91곳)·`HudMain.ShowWarn` 직접 호출(5곳)이 창이 없을 때 `WarnPop`을 **내 캐릭터 머리 위**에 띄웠고, 탑뷰 카메라는 캐릭터가 화면 가운데라 사실상 정중앙이었습니다.
- 조치: 경고를 **채널 B 왼쪽 알림 더미의 주황 줄**로 옮겼습니다(창 열림 여부 무관 · 창이 떠 있으면 더미가 창 밖 가장자리로). 실패 소리 유지, 문구는 그대로입니다.
- 되돌리기: `HudMain.WarnToFeed = false` 한 줄이면 예전 머리 위 글씨.

화면 가운데 근처에 뜨는 그 밖의 요소 (안내가 아닌 연출·조작 표시라 대상 아님): 머리 위 COMBO(`ComboHead`) · 추출 결과(`ExtractPop`, 혼 자리) · 추출 확률(`SoulHint`, 발밑) · 줍기(`PickPop`, 발밑 · 채널 D) · 의식 고리(`RiteRing`) · 습격 글귀/판(`RaidText`·`RaidPlate`) · 일으키기 막대(`RescueHUD`) · 사망 띠(`DeathBand`) · 이야기 카드·결산 판(`StoryCard`·`QuestRewardWindow`). 위쪽 가운데 `Tip`(상황 안내)·`GatePrompt`(출구 안내)·맵 배너는 상단이라 정중앙 아님.

### `tools/notice_channels.cjs`가 Warn을 세지 않던 이유
예전 설계에서 Warn은 4채널 밖 「머리 위 경고」로 두고 표 크기를 줄이려고 **파일별 수만** 적었습니다(GROUPED). 이번에 Warn이 채널 B가 됐으므로 `Util.Warn`·`HudMain.ShowWarn`·`NoticeFeed.PushWarn`을 한 곳씩 세도록 넓혔습니다 → 배정표 251곳. `npm test` 「알림 채널 배정」 통과(21/21).
- 재생성한 `notice-channels.md`에는 다른 차선이 고친 파일의 줄 번호 이동(DepthGate·PlayerTravel·PlayerQuest)이 섞여 있습니다(그대로 둠).

## 바뀐 것
- `HudMain.ShowWarn`: 실패 소리 + `WarnToFeed`(기본 true)면 `NoticeFeed:PushWarn`. false면 예전 경로.
- `Util.Warn`: 소리·자리 결정을 ShowWarn에 맡김(직접 호출 5곳도 같은 자리·소리).
- `NoticeFeed.PushWarn`: 주황(`WarnColor` #FFB45A = 예전 WarnPop 색) · 같은 경고(숫자만 다른 글 포함) **2초 안 다시 오면 세지 않고 줄 시간만 늘림**(`WarnDedupSec`) · 2초 뒤 같은 경고는 기존 규칙대로 「×N」 · 상한 60초 규칙(`LimitPatterns`)은 경고에 적용 안 함(직접 한 행동의 결과라 매번 이유를 보여 줌). 보통 줄은 `BaseColor` #EFE6D2.
- UI 파일 변경 없음(기존 Feed 줄의 글자색만 실행 중에 바꿈).
- `docs/ui/message-rules.md` 경고 줄 갱신.
