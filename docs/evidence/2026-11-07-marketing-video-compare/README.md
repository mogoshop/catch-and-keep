## 「옛날」 장면을 만든 방법 (남의 영상 내려받기 없음)
1. 메이커 MCP `maker_list_maplestory_maps`로 공식 메이플 맵 **Snail Park (000020000, 메이플 아일랜드)** 를 골라 `maker_import_maplestory_map`으로 불러옴
   — 임시 맵 `map/oldsnail.map`(MapleTile, 스킬 템플릿)을 만들고 그 안에 불러옴(옆보기 · 발판 · 해바라기 · 버섯집 · 초록 달팽이 8마리 = AIWander+Rigidbody).
2. 하늘: 이 프로젝트는 지도마다 `MapAmbience` 조명을 쓰는데 불러온 맵에는 없어 화면이 검게 나옴 → 녹화 중에만 클라이언트에서 전체 조명(흰색 1.0)을 켜고,
   배경 템플릿이 그려지지 않아 기본 스프라이트(1705e3c5…)를 하늘색으로 크게 깔고 구름 스프라이트 2장(1ef8075b…, 9258d7ad…)을 얹음(런타임만).
3. 초보자: 플레이어(탑뷰 캐릭터)는 투명 처리하고 카메라 기준점으로만 씀. 아바타 NPC를 런타임 `mapempty` + `AvatarRendererComponent` + `CostumeManagerComponent`로 만들어
   하얀 반팔 면티(ae8d3590…) · 블루 스키니진(e6ff0ea6…) · 가죽 샌들(202544d7…) · 검은색 토벤 머리(29246028…) · 남자얼굴4(340ae5b8…) · **몽둥이(ce073997…)** 를 입힘.
   걷기 `walk1` · 공격 `swingO1/swingO2`(ActionStateChangedEvent → 몸 엔티티) · 방향은 Scale.x 반전.
4. 달팽이: 불러온 초록 달팽이(StateAnimation stand 17b55730… · hit eac48e84… · die 51c2f4b5…) + 1마리를 **파란 달팽이 리소스 팩 mob/0100101.img**
   (stand 0c691646… · hit 938c814d… · die1 af2e35a7…)로 바꿈. 맞는 순간 hit 클립 + 데미지 스킨 숫자/MISS, 처치는 die 클립 뒤 숨김(클라이언트 연출).
5. 카메라 줌 120 · HUD 전부 끔 · 이름표 없음. 끝난 뒤 플레이를 멈추고 `map/oldsnail.map` 삭제 · 메이커 맵을 map01로 되돌림 · refresh. 불러온 맵은 커밋하지 않음.
