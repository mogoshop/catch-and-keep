# 홍보 영상 3차 시안 11편 (2026-11-07)

2차 피드백 반영: ① 큰 검정 띠 + 긴 문장이 촌스럽다 → 띠 없이 작은 흰 글자 한 줄 ② 메이커 재녹화는 「실제 사냥」 같지 않다 → 사용자가 직접 찍은 `play.mp4`(파티 사냥 · HUD 켜짐 · 실제 템포)를 주재료로, `rec/`는 거인·습격·보스 처치·결산 판 보조컷만 ③ 여러 버전.

## 화면 · 글자

- 세로: `play.mp4` 540×960 크롭을 정확히 2배 → 1080×1920 전체 화면(위·아래 띠 없음). 크롭 x 690~1230 = 캐릭터 중심, 파티 목록(왼쪽 x<300)·미니맵·퀘스트 판(오른쪽 x>1480)은 화면 밖. 위에서 y 120부터 → 아래 「스킬 추천」 줄·메뉴·단축키·경험치 줄까지 HUD 그대로. 보스 컷만 y 0부터(위 보스 체력 막대 전체).
- 결산 판 컷은 판 둘레만 잘라 폭에 맞추고 위아래는 어둡게 흐린 같은 화면.
- 글자: Pretendard SemiBold 44px 흰색 · 얇은 그림자 · 아주 옅은 검정 바탕(알파 56/255). 왼쪽 아래(x 72, y 1220 — 「스킬 추천」 줄 위) 또는 위쪽 가운데(y 330 — 보스 막대·콤보 숫자 아래). 노랑·느낌표·「」·외곽선 없음.
- 엔드카드: 검정 바탕 「메이플 리저렉션」 Bold 92px + 부제 Regular 40px(흰색 67%), 1.2초(가로 트레일러 2초).
- 컷 사이 0.15초 디졸브. H.264 CRF 18 · 30fps · AAC 192k.

## 닉네임 처리

- 파티 목록·랭킹·채팅은 크롭 밖(11:40 랭킹·13:14 채팅 구간은 쓰지 않음).
- 머리 위 이름표(내 캐릭터·파티원·소환수 아래 주인 이름)는 이름표 견본 5개(3차에 돌바닥 위 소환수 이름표 `t5` 추가) 상호상관으로 찾고, **「어두운 상자 + 흰 글씨」인지 한 번 더 확인**(흰 화소 5~40% · 어두운 화소 35% 이상)한 뒤 **상자 크기 그대로(여백 1px)** 안만 부드럽게 흐림(`blurStyle: soft`). 2차까지의 모자이크·넓은 상자(회색 조각)보다 「흐린 이름표」로 보임. 앞뒤 3프레임 유지.
- 문턱을 낮추면(0.52) 캐릭터 얼굴·「골드 +99」를 이름표로 오인해 원래 문턱 유지.
- 견본으로 못 찾는 이름표(7:02 컷 캐릭터 몸에 반쯤 가린 파티원 이름표+칭호)는 추적 상자 하나를 따로 둠.
- 확인: 편마다 접촉판 + 혼전 컷(난파선·보스·분홍 폭발·처치 띠) 원본 배율 확대. 분홍 폭발 컷은 소환수 이름표가 겹겹이 쌓여 흐린 조각이 여럿 보임(지저분함이 남는 유일한 컷).
- 한계: 몹·데미지 숫자에 반쯤 가린 이름표나 섬광에 물든 이름표는 몇 프레임 남을 수 있음. 외부 공개 전 한 번 더 눈으로 확인 권장.

## 소리

- play.mp4 게임 소리(-50 LUFS 안팎)를 컷마다 잘라 0.15초 크로스페이드 → loudnorm 2단계 I=-16 LUFS · TP -1.5 → 엔드카드 전 0.6초 페이드아웃. 음악 없음.
- rec 컷은 무음 녹화라 `audioFrom`으로 play.mp4의 비슷한 장면 소리를 그 컷 길이만큼 이어 붙임(효과음은 화면과 정확히 맞지 않음).
