## ④ 퀘스트 추적판 — 미리보기 잘림 (실제 배치는 화면 안)

실행 중 좌표 (15:19, iPad 미리보기, 마을):

- 화면 2048×1536 → `_UILogic:ScreenToLocalUIPosition`: 화면 (0,0) = 루트 (−960, −720), 화면 (2048,1536) = 루트 (960, 720). **화면 전체 = UI 루트 1920×1440 전체.**
- `NavigationHUD/SafeArea/QuestTrack`: 왼쪽 위 정렬, 피벗 (0,1), 자리 (24, −196), 크기 420×176 → 루트 왼쪽에서 24~444, 위에서 196~372. 루트(=화면) 안에 전부 있다.
- 같은 왼쪽 위 정렬의 `GameHUD/MFrame`(체력 틀): 자리 (24, −16), 480×108 → 왼쪽 24~504.
- 그런데 미리보기 캡처(51b)에서는 추적판과 체력 틀이 **같은 선에서** 왼쪽이 잘리고, 오른쪽 지도·공격 단추도 오른쪽이 잘린다. 캡처 위치로 거꾸로 재면 미리보기는 1080 높이 기준으로 그린 뒤 가운데 약 1440 폭(루트 x 240~1680)만 보여 준다 — 메모해 둔 「iPad 미리보기 UI 잘림」과 같은 현상.
- 판정: 추적판만의 결함이 아니라 미리보기 잘림. 코드·빌드 배치는 고치지 않았다.
- 51번은 이전 세션 캡처로, 추적판이 빌드 자리(왼쪽 위)가 아니라 화면 가운데에 있다 — 내용을 보이려고 실행 중에 자리를 옮겨 찍은 것으로 보인다(기록 없음). 자리 판정 근거는 51b와 위 좌표.
- 남은 확인: 실제 iPad에서도 양옆이 잘리는지는 아직 못 봤다. 잘린다면 추적판만이 아니라 왼쪽·오른쪽 끝에 붙은 HUD 전부(체력 틀·지도·공격 단추)의 문제다 (창 5개는 WindowFit이 이미 보이는 폭 1440 기준으로 맞춘다).
