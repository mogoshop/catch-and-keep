## 메이커 확인 대기 (2026-10-07)
- 규칙: 재접속 시 마을 시작 / 마을에서 공격·스킬 막힘 / 새 캐릭터 퀵슬롯 빈 칸 → 스킬 배우면 자동으로 들어감 / 집결은 배우기 전 안내만
- 타격감: 넉백 거리(knockbackSpeed 5 × 0.12초)·경직 모션·붉은 번쩍임·타격 정지·화면 흔들림·휘두르기 궤적·사망 연기, 효과음 2종(휘두르기·타격)이 어울리는지
- 밸런스: 1레벨 일반 몬스터가 2~4대에 죽는지
- UI: 테마 그림이 실제로 보이는지(마스크 색), 미니맵 점 위치, 맵 이름 표시·사라짐, NPC 머리 위 표시 위치, 모바일 패드 배치·터치 크기, 소지품 아이콘·등급 테두리, 스킬 지정 창
- 코덱스 요청: 생명·마나 오브 그림 (지금은 임시 원형)
