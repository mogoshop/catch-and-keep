# 혼각 룬 & 룬워드 시스템 — 초안 v0.2

디아블로2 룬워드의 구조(소켓 + 순서대로 룬 삽입 → 특수 효과)만 차용하고, 룬 이름·조합·효과·룬워드 이름은 전부 오리지널로 설계한 초안. 핵심 테마: **그림자 군단(소환수) 강화**.

v0.1 원본은 `rune-system-draft-v0.1.md`에 보존.

## v0.2 변경 요약

| # | v0.1의 문제 | v0.2 해결 |
| --- | --- | --- |
| 1 | 배치 한도가 룬워드 보상의 중심이라 상한에 닿으면 죽은 옵션이 됨 | 배치 한도를 거의 고정(기본 5 + 스킬 트리 최대 +3). 장비 합산 +2 상한. 보상은 그림자의 **질**(능력치·정예 승격)로 이동 |
| 2 | 룬워드 14종이 전부 같은 방향의 선형 업그레이드 | 4개 유형(군세/정예/본체/저주·서포트)으로 분리. 본체형 신설 |
| 3 | 3:1 전체 승급 체인은 2187개가 필요해 도달 불가 | 비율 인하 + 드롭 분포로 체인 깊이를 실질 3단 이내로 제한 |
| 4 | 셀 3개로 룬워드 없이 그림자 스킬 +3 | 셀 개별 효과에서 스킬 레벨 제거. 스킬 레벨은 룬워드 전용 + 합산 상한 |
| 5 | 임시 그림자 기상이 엔티티 폭발 유발 | 신규 스폰 폐지, 기존 그림자 버프 스택으로 치환 (엔티티 증가 0) |
| 6 | 레브(갑옷)와 「죽음 이후」 부활 중복 | 부활 스택 금지 + 쿨 공유 |
| 7 | 전체 72개 효과를 한 번에 구현하는 범위 | 단계별 출시(Phase 0~3) 정의 |

## 1. 기본 규칙

| 항목 | 내용 |
| --- | --- |
| 명칭 | 혼각(魂刻) 룬 — 망자의 혼이 새겨진 돌 |
| 소켓 가능 부위 | 무기 / 갑옷 / 투구 / 보조(영혼 등불) |
| 소켓 수 | 무기 2~6, 갑옷 2~5, 투구 2~3, 보조 2~3 |
| 소켓 뚫기 | 재료 「공허의 정」으로 **확정 뚫기**. 최대 소켓 수는 아이템 레벨 구간으로 제한 (아래 4장) |
| 룬워드 성립 조건 | ① 일반 등급(무옵션) 아이템 ② 소켓 수 = 룬워드 룬 개수 (정확히 일치) ③ 정해진 순서대로 룬만 삽입 ④ 부위 일치 |
| 룬 제거 | 기본 불가. 「망각의 의식」(고급 재료 소모) 시 아이템 파괴 + 룬 회수 |
| 효과 적용 | 룬워드 성립 시 개별 룬 효과 + 룬워드 효과 모두 적용 |
| 거래 | 룬·재료는 거래 가능. **완성된 룬워드 아이템은 귀속** (대리 제작·작업장 차단) |

### 보조 장비: 영혼 등불 (오리지널)

네크로맨서 전용 왼손 장비. 디아2의 해골 방패 포지션 대체. 소환수 관련 옵션이 주로 붙는 부위.

### 그림자 수치 규칙 (v0.2 신설)

| 항목 | 값 | 비고 |
| --- | --- | --- |
| 기본 배치 한도 | 5 | 필드 동시 소환 수 (보유 수는 무제한) |
| 스킬 트리 보너스 | 최대 +3 | 배치 한도는 사실상 **8이 절대 상한** |
| 장비 배치 한도 보너스 합산 | 최대 +2 | 군세형 룬워드 ①·⑩ 에서만 발생 |
| 장비 그림자 스킬 레벨 합산 | 최대 +3 | 룬워드 전용. 개별 룬은 스킬 레벨 보너스 없음 |
| PvP 배치 한도 | 5 고정 | 장비·스킬 보너스 무시 |
| 정예 승격 | 지정 그림자 1기를 정예로 승격 (능력치 ×1.5) | 정예형 룬워드가 슬롯·강도를 늘림 |
| 부활 효과 | 스택 금지, 레브(갑옷)·⑫와 쿨 공유 | 발동한 쪽의 쿨 값을 공유 쿨로 사용 |

설계 원칙: **물량이 아니라 질로 보상한다.** 5마리가 보스를 녹이는 판타지를 만들고, 서버 부하 상한을 숫자로 못 박는다.

- PvP: 「그림자 일격」 피해 50%, 혼 흡수 비활성

## 4. 룬 획득 & 승급

### 드롭
- 던전 **심도(층수)** 가 깊을수록 상위 룬 드롭 테이블 개방
- 보스 처치 시 해당 심도 등급 룬 1개 확정
- 신화 룬: 최심층 보스 / 주간 보스 전용
- **드롭 분포 설계 (v0.2)**: 같은 등급 안에서도 번호가 높은 룬이 해당 심도에서 직접 드롭되도록 가중치를 둔다. 예를 들어 하급 던전 후반부에서는 1~4번뿐 아니라 5~6번도 드롭된다. 그 결과 승급 체인이 1번부터 시작하는 일은 드물다.

### 승급 — 「혼합 제단」 (v0.2 비율 인하)

| 재료 | 결과 |
| --- | --- |
| 하급 룬 ×2 | 다음 번호 룬 ×1 |
| 중급 룬 ×3 + 그림자 정수 ×1 | 다음 번호 룬 ×1 |
| 상급 룬 ×2 + 짙은 그림자 정수 ×1 | 다음 번호 룬 ×1 |
| 신화 룬 | 승급 불가 (드롭 전용) |
| 등급 경계 (8→9, 16→17, 21→22) | **승급 불가**. 드롭 전용 |

등급 경계를 막는 이유는 승급 체인이 전체를 가로지르지 않게 하려는 것이다. 한 등급 안 체인의 최악 비용은 하급 2^7 = 128개, 중급 3^7 = 2187개지만, 드롭 가중치로 시작 번호가 높아지므로 실제 요구량은 한두 자릿수다. 수치는 플레이 테스트에서 조정한다.

**그림자 정수** = 그림자를 **분해**해서 얻는 재료. "무제한 보유"로 쌓인 약한 그림자의 소모처 역할.

### 소켓 뚫기 (v0.2 신설)

| 항목 | 내용 |
| --- | --- |
| 재료 | 「공허의 정」 — 심층 던전 드롭, 분해로는 얻을 수 없음 |
| 방식 | 확정 1소켓 추가 (실패 없음) |
| 최대 소켓 | 아이템 레벨 구간으로 제한. 룬워드가 요구하는 소켓 수에 도달하려면 해당 레벨대 아이템이 필요 |
| 목적 | 랜덤 드롭의 좌절을 줄이고, 룬워드 제작 시점을 레벨 구간에 맞춰 통제 |

## 5. 구현 메모 (MSW / mLua)

### 데이터 구조 예시

```lua
-- RuneData: 룬 번호 → 부위별 효과
RuneData = {
  [1]  = { id = "as",   tier = 1, weapon = { dmgPct = 15 }, armor = { def = 15 }, lantern = { maxMp = 10 } },
  [21] = { id = "xil",  tier = 3, weapon = { freezeChance = 3 }, armor = { maxHpPct = 5 }, lantern = { shadowAllStatPct = 4 } },
  -- ...
}

-- RunewordData: 부위 + 정확한 룬 순서
RunewordData = {
  first_command = {
    name = "첫 번째 군령", slot = "lantern", reqLv = 9, archetype = "legion",
    runes = { "as", "irn" },
    effects = { deployCap = 1, summonDmgPct = 15, extractPct = 5, maxMp = 20 },
    pvp = nil,
  },
  -- ...
}

-- 합산 상한 (서버 전용 상수)
StatCaps = {
  deployBase = 5,
  deployFromSkillTree = 3,
  deployFromGear = 2,
  shadowSkillLevelFromGear = 3,
  pvpDeploy = 5,
}
```

### 판정 로직
1. 룬 삽입 시 아이템 등급이 `normal` 인지 확인
2. 모든 소켓이 찼을 때 `slot + runes` 배열을 키로 `RunewordData` 조회 (예: `"lantern|as|irn"` 문자열 키로 해시)
3. 일치하면 아이템에 `runeword = id` 부여, 아이템 이름 교체, 귀속 처리
4. 스탯 계산은 **서버에서만**, 클라이언트는 표시만 (치트 방지)
5. 합산 시 `StatCaps` 로 배치 한도·스킬 레벨 클램프, 부활 효과는 단일 공유 쿨 변수로 관리

### 밸런스 레버
- 배치 한도가 상한 8로 고정되어 서버 부하의 최악 상황을 예측 가능 (플레이어 4명 × 8 = 맵당 소환수 32)
- 혼 흡수는 신규 엔티티를 만들지 않고 기존 그림자의 버프 스택만 갱신하므로 부하 증가 없음
- PvP 보정은 룬워드별 `pvp` 필드로 덮어쓰기

## 6. 출시 단계 (v0.2 신설)

72개 룬 효과와 14개 룬워드를 한 번에 만들지 않는다. 룬 삽입 UI(인벤토리·소켓·제작 UI)가 판정 로직보다 훨씬 큰 작업이다.

| 단계 | 범위 | 완료 기준 |
| --- | --- | --- |
| Phase 0 | 룬 없이 코어 루프: 그림자 추출 → 소환 → 전투 → 분해 | **재미있는가**를 먼저 확인. 이게 안 되면 이후 작업은 무의미 |
| Phase 1 | 하급 룬 8종(24개 효과) + 룬워드 4종 (유형별 1개: ① 군세, ② 저주, ④ 본체, ⑤ 정예) + 소켓 UI | 룬워드 하나가 빌드를 바꾸는 체감이 있는지 |
| Phase 2 | 중급 룬 + 승급 제단 + 그림자 정수 경제 + 룬워드 ③⑥⑦⑧ | 승급 비율·드롭 분포 튜닝 |
| Phase 3 | 상급/신화 룬 + 후반·엔드게임 룬워드 + PvP 보정 | 서버 부하 테스트 통과 |
