# 35. 온보딩 가이드 개편 — 책갈피 목차 + 움짤 + 설명 (2026-10-27, 기획안 · 승인 대기)

사용자 피드백 (10-26 플레이어): 온보딩 가이드가 더 고도화돼야 한다.
사용자 방향: 왼쪽에 책갈피 목차, 오른쪽에 지금처럼 큰 화면 — 화면 녹화 영상 + 설명.

## 0. 지금 가이드의 문제

- 쪽 6장을 「이전 / 다음」으로만 넘긴다 — 원하는 내용으로 바로 못 간다.
- 글만 있다 — 「혼 추출」, 「소환 지정」처럼 처음 듣는 말을 글로만 설명한다.
- 내용이 낡았다 (`UI/Windows/GuideWindow.mlua` BuildPages):
  - 「액트 1 → 2 → 3」, 「액트 3 보스를 쓰러뜨리면 악몽」 → 지금은 액트 4 · 재의 왕
  - 「한 채널에는 4명까지」 → 지금은 채널 20명 · 게임 방은 4명
  - 「끝없는 심도에서 최고 층」 → 심연은 지금 숨김 (config depthEnabled 0)
- 상황 카드(GuideCoach — Lv5 그림자, 첫 그림자, 군단 확장)는 좋다 → 남기고 책갈피와 잇는다.

## 1. 화면 구성

```
┌──────────────────────────────────────────────────────┐
│ 게임 안내                                         [X] │
├───────────┬──────────────────────────────────────────┤
│ ▌시작하기  │  ┌────────────────────────────────────┐  │
│  군단 ●    │  │                                    │  │
│  성장      │  │      움짤 (3~6초 반복, 16:9)        │  │
│  장비·파밍 │  │                                    │  │
│  모험      │  └────────────────────────────────────┘  │
│  함께하기  │  제목                                    │
│  위험 신호 │  설명 3~5줄 (키는 금색 · PC/모바일 다름)   │
│  그 밖에   │                                          │
│            │  ○ ● ○   (이 책갈피 안의 쪽)  [이전][다음] │
└───────────┴──────────────────────────────────────────┘
```

- 왼쪽 책갈피 8개. 누르면 그 묶음의 첫 쪽. 책갈피 안 쪽은 점(○●○)과 이전/다음.
- 안 본 쪽이 있는 책갈피에 붉은 점 → 다 보면 꺼짐 (계정에 기록, 지금 GuideSeen 확장).
- 상황 카드에 「자세히 보기」 버튼 → 해당 책갈피 쪽으로 바로 연다.
- 모바일: 같은 구성, 책갈피 글씨를 아이콘 + 두 글자로 줄인다.

## 2. 영상은 어떻게 넣나 — 움짤 방식

- MSW UI에는 동영상 재생기가 없다. 대신 UI 그림 칸(`SpriteGUIRenderer.ImageRUID`)이 **animationclip을 바로 재생**한다.
- 메이커에서 장면을 녹화 → 3~6초로 자르고 → 640×360 · 초당 8~10장으로 줄여 → 프레임을 올려 animationclip 하나로 만든다. 클립 등록이 막히면 프레임을 타이머로 넘긴다 (펫·몬스터와 같은 방식).
- 한 쪽에 30~50장 × 쪽 수 → 전체 프레임 수와 용량을 보고 쪽마다 움짤/정지 그림을 고른다. **움짤은 핵심 10쪽만**, 나머지는 캡처 한 장 + 표시 화살표.

## 4. 처음 들어온 사람의 순서 (지금 흐름 유지 + 보강)

1. 시작 이야기 카드 → 가이드 **1) 시작하기** 3쪽만 자동으로 연다 (지금은 6쪽 전부).
2. 나머지 책갈피는 붉은 점으로 남겨 두고, 그 순간이 오면 상황 카드가 「자세히 보기」로 데려간다:
   - 첫 혼 → 2-1 · Lv5 → 2-2 · 첫 그림자 → 2-3 · 첫 레어 템 → 4-1 · 첫 룬 → 4-3 · 첫 보스 방 → 5-3 · 첫 붉은 원 → 7-1
3. 메뉴 「게임 안내」로 언제든 전체.

## 5. 할 일 순서 (안)

1. 이 목차 확정 (사용자) — 쪽 빼기·더하기, 움짤 10쪽 고르기

## 7. 책갈피 5~7을 띄우는 순간 (Claude 판단 · 다음 단계에서 GuideCoach에 연결)

모두 계정에 한 번. 그 순간 상황 카드 한 장 → 「자세히 보기」로 그 쪽.

| 쪽 | 띄우는 순간 | 왜 그때인가 |
|---|---|---|
| 5-1 의뢰 따라가기 | 첫 의뢰를 받고 마을 밖 사냥터에 처음 들어갔을 때 | 받은 직후는 NPC 대화가 이어지는 중이라 끊긴다. 밖에 나가면 「뭘 하지」가 생긴다 |
| 5-2 웨이포인트 | 웨이포인트를 처음 켰을 때 | 켠 순간이 「이게 뭔지」 궁금한 때 |
| 5-3 보스 | 보스 방(최종·중간 보스 맵)에 처음 들어갔을 때 | 싸우기 직전에 집결·물약을 알려 준다 |
| 5-4 난이도 | 악몽이 처음 열렸을 때 (재의 왕 처치) | 열린 순간에만 의미가 있다 |
| 6-1 함께 출발하기 | 액트 1 마지막 보스(묘지기 여왕)를 처음 쓰러뜨리고 마을로 돌아왔을 때 | 혼자 한 액트를 끝낸 때가 「친구랑 해 볼까」 생각이 드는 때. 로비 방 고르기 창은 첫 진입 흐름 앞이라 그때 띄우면 시작부터 막힌다 |
| 6-2 파티 · 거래 · 결투 | 다른 플레이어에게 파티·거래·결투 요청을 처음 받았을 때 | 요청 팝업과 같이 보면 바로 이해된다 |
| 7-1 바닥의 붉은 원 | 붉은 원(범위 공격 예고)이 처음 내 근처에 생겼을 때 | 처음 맞고 쓰러지기 전에 |
| 7-2 푸른 몸 · 발밑 색 원 | 변종 우두머리나 오오라 몬스터가 처음 화면에 들어왔을 때 | 「저건 뭐지」 하는 순간 |
| 7-3 마나 | 마나가 모자라 스킬이 처음 안 나갔을 때 | 안 나가는 이유를 바로 알려 준다 |

- 전투 중(7-1 · 7-2)에는 창이 싸움을 막으면 안 된다 → 카드를 바로 띄우지 않고 **주변에 적이 없어진 뒤 2초**에 띄운다 (GuideCoach의 CardCalm과 같은 방식).
- 둘 이상이 겹치면 하나씩, 앞 카드를 닫은 뒤.

## 8. 움짤 방식 시험 결과 (10-27 메이커 실측)

- GIF는 못 쓴다: 그룹 저장소에 GIF를 sprite로 올리면 업로드가 거절된다 (MCP 업로드 종류도 sprite · audioclip · avataritem뿐).
- **유튜브 UI 재생(A안) 된다**: `YoutubePlayerGUIComponent`가 게임 안내 화면 칸에서 홍보 영상을 재생했고, `Jump(초)`로 다른 장면으로 바로 넘어갔다.
  - 조건: 재생기는 **UI 파일에 처음부터** 넣어야 한다 (실행 중 AddComponent로 붙이면 주소가 들어가도 화면이 안 나왔다).
  - 넣는 법: `b.empty("GuideWin/Media/Video", …)` + `b.addComponent(…, "MOD.Core.YoutubePlayerGUIComponent", { Urls: ["https://www.youtube.com/watch?v=…"], Loop, PlayOnAwake, Shuffle: false, Volume: 0 })`. 영상 위에 그림(Shot)을 켜 두면 덮이니 끈다.
  - 메이커가 새 칸을 못 읽은 적이 한 번 있었다 → 빌드 후 플레이 멈춘 상태에서 touch → refresh, 실행 중 자식 목록으로 확인.
- 남은 일: 안내 영상 한 편(쪽마다 4~6초 장면 10개) 녹화 → 채널에 일부 공개로 업로드 → 쪽마다 시작 초 · 길이를 표에 적고, 그 길이가 지나면 시작 초로 다시 Jump (구간 반복).
