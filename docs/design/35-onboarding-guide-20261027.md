# 35. 온보딩 가이드 개편 — 책갈피 목차 + 움짤 + 설명 (2026-10-27, 기획안 · 승인 대기)

사용자 피드백 (10-26 플레이어): 온보딩 가이드가 더 고도화돼야 한다.
사용자 방향: 왼쪽에 책갈피 목차, 오른쪽에 지금처럼 큰 화면 — 화면 녹화 영상 + 설명.

## 0. 지금 가이드의 문제

- 쪽 6장을 「이전 / 다음」으로만 넘긴다 — 원하는 내용으로 바로 못 간다.
- 글만 있다 — 「혼 추출」, 「소환 지정」처럼 처음 듣는 말을 글로만 설명한다.
- 내용이 낡았다 (`UI/Windows/GuideWindow.mlua` BuildPages):
  - 「액트 1 → 2 → 3」, 「액트 3 보스를 쓰러뜨리면 악몽」 → 지금은 액트 4 · 재의 왕
  - 「한 채널에는 4명까지」 → 지금은 채널 20명 · 게임 방은 4명
  - 「끝없는 심도에서 최고 층」 → 심연은 지금 숨김 (config depthEnabled 0)
- 상황 카드(GuideCoach — Lv5 그림자, 첫 그림자, 군단 확장)는 좋다 → 남기고 책갈피와 잇는다.

## 1. 화면 구성

```
┌──────────────────────────────────────────────────────┐
│ 게임 안내                                         [X] │
├───────────┬──────────────────────────────────────────┤
│ ▌시작하기  │  ┌────────────────────────────────────┐  │
│  군단 ●    │  │                                    │  │
│  성장      │  │      움짤 (3~6초 반복, 16:9)        │  │
│  장비·파밍 │  │                                    │  │
│  모험      │  └────────────────────────────────────┘  │
│  함께하기  │  제목                                    │
│  위험 신호 │  설명 3~5줄 (키는 금색 · PC/모바일 다름)   │
│  그 밖에   │                                          │
│            │  ○ ● ○   (이 책갈피 안의 쪽)  [이전][다음] │
└───────────┴──────────────────────────────────────────┘
```

- 왼쪽 책갈피 8개. 누르면 그 묶음의 첫 쪽. 책갈피 안 쪽은 점(○●○)과 이전/다음.
- 안 본 쪽이 있는 책갈피에 붉은 점 → 다 보면 꺼짐 (계정에 기록, 지금 GuideSeen 확장).
- 상황 카드에 「자세히 보기」 버튼 → 해당 책갈피 쪽으로 바로 연다.
- 모바일: 같은 구성, 책갈피 글씨를 아이콘 + 두 글자로 줄인다.

## 2. 영상은 어떻게 넣나 — 움짤 방식

- MSW UI에는 동영상 재생기가 없다. 대신 UI 그림 칸(`SpriteGUIRenderer.ImageRUID`)이 **animationclip을 바로 재생**한다.
- 메이커에서 장면을 녹화 → 3~6초로 자르고 → 640×360 · 초당 8~10장으로 줄여 → 프레임을 올려 animationclip 하나로 만든다. 클립 등록이 막히면 프레임을 타이머로 넘긴다 (펫·몬스터와 같은 방식).
- 한 쪽에 30~50장 × 쪽 수 → 전체 프레임 수와 용량을 보고 쪽마다 움짤/정지 그림을 고른다. **움짤은 핵심 10쪽만**, 나머지는 캡처 한 장 + 표시 화살표.

## 4. 처음 들어온 사람의 순서 (지금 흐름 유지 + 보강)

1. 시작 이야기 카드 → 가이드 **1) 시작하기** 3쪽만 자동으로 연다 (지금은 6쪽 전부).
2. 나머지 책갈피는 붉은 점으로 남겨 두고, 그 순간이 오면 상황 카드가 「자세히 보기」로 데려간다:
   - 첫 혼 → 2-1 · Lv5 → 2-2 · 첫 그림자 → 2-3 · 첫 레어 템 → 4-1 · 첫 룬 → 4-3 · 첫 보스 방 → 5-3 · 첫 붉은 원 → 7-1
3. 메뉴 「게임 안내」로 언제든 전체.

## 5. 할 일 순서 (안)

1. 이 목차 확정 (사용자) — 쪽 빼기·더하기, 움짤 10쪽 고르기
2. 글 다듬기 → 사용자 확인
3. 메이커에서 움짤 장면 녹화 · 프레임 올리기 (Claude)
4. 가이드 창 다시 빌드: 책갈피 · 쪽 점 · 움짤 칸 · 「자세히 보기」 연결 (Claude)
5. 메이커에서 PC·모바일 둘 다 확인
