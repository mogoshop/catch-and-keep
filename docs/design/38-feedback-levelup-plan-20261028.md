# 38. 피드백 반영 레벨업 방안 (2026-10-28)

10-27 접수한 팀원 피드백 5개와 10-28 추가된 「전반 템포」·「맵 전면 개편」을 F1~F7로 묶어, 진단 → 복수안 → 검증 → 추천 조합 → 로드맵까지 한 번에 적은 문서다. 다음 로드맵 「피드백 반영」의 출발점이며, 사용자가 원래 요청한 「메이플 리저렉션 레벨업 방안」이 이것이다.

- 근거는 `파일:줄`로 적는다. 숫자는 10-27 밤 데이터(커밋 6255271 기준)에서 읽은 값이고, 검증(verify-F1~F6)에서 바로잡힌 수치는 바로잡은 값으로 쓰고 「(검증 정정)」을 달았다. 추측은 「추정」.
- 메이커 실측은 이 문서에서 하지 않았다(메인 세션이 황무지 샘플을 짓는 중). 실측이 필요한 항목은 §4 「검증 방법」에 모았다.
- 입력: `scratchpad/plan38-inputs/` 22개(항목별 분석 7 · 검증 6 · 스킬 창 현황 1 · 스킬 창 4안 2벌 · 심사 3 · 레퍼런스 3).
- 본문은 게임 안 이름(해골 전사 · 망령 질주 · 묘지기 여왕 …)으로 쓰고, 코드 이름은 근거 표기에만 쓴다.

## 1. 출발점

### 1-1. 반응과 피드백

- 디시 커뮤니티(10-25 출시 뒤): 「AI 슬롭」. 사용자: 「개좆망 게임이라는 낮은 시선에서 다시 출발」 · 「전반 템포를 올리자」 · 「AI를 활용한 압도적 작업량」.

### F1. 액트 1을 넘어갈 명분이 없다

**진단** — 「어떻게 가는지」는 막혀 있지 않다(해금 = 앞 액트 마지막 의뢰 보고, `PlayerTravel.mlua:115-121` · 잠긴 이유는 카라반 창 본문에 상시 표시, `NpcWindow.mlua:261-270` · `story.csv:17`). 「왜 가야 하는지」가 비어 있다.
1. 액트 1 끝 보상이 기억에 남지 않는다. 여왕 의뢰 보상 = 경험치 20,000(Lv12→13의 반 레벨) · 골드 900 · 유니크 1(`quests.csv:7`). 유니크는 「어디서나 나오는 것」 11종에서 뽑는데(검증 정정: 6종 아님) 계열을 1:1:1:1로 먼저 고르는 규칙 탓에 **Lv1 바탕 무기(단낫 6 vs Lv12 희귀 낫 14)가 나올 확률이 약 51%**(`ItemData.mlua:512-548` · `item_bases.csv:2,4`). 여왕의 상징 전리품(묘지기의 왕관 · 여왕의 송장 손, `item_uniques.csv:8-9`)은 처치당 약 3.7%, 보스 혼 추출은 기본 5%(검증 정정, `monster_ranks.csv:6`). 확정 보상은 심연 열쇠 1 + 일반 유니크 1 + 칭호 「여왕의 몰락」·골드 1,500(15a2e9f, 검증 정정).
2. 연출 뒤에 글의 벽. 처치 연출(섬광·흔들림·빛 9번, `ActClearFx.mlua:12-47`)은 D2급인데 보고 → 알림 한 줄 → end1 2쪽 + scene1 7쪽 → 카라반 → 도착 카드 → 의뢰 intro 4쪽 = **17쪽**(검증 정정, `story.csv:11,21` · `quests.csv:7-8`). 유니크는 가방으로 바로 들어가 빛기둥·드롭 연출이 없다(`PlayerQuest.mlua:394`).
3. 액트 2 첫 10분(8분 46초, Lv12→13)에 「새 것」이 보이지 않는다. 정확히는 **있는데 액트 2의 보상으로 묶여 보이지 않는다**(검증 정정) — 해골 마법사·쇠약은 여왕의 무덤 안에서 Lv12에 열리고, 중급 룬 8종(`runes.csv:10-17`)과 룬워드 「망자의 행진」(`runewords.csv:4`)은 액트 2가 첫 무대인데 안내가 없다. 오아시스는 야영지와 같은 상점·대장장이·창고이고 떠돌이 상인은 오히려 없다(`maps.csv:2, 18`). 첫 의뢰는 「사막 자칼 45마리」(`quests.csv:8`, 13번 설계 「액트 1보다 확실히 어렵게」).
4. 갖춰진 것: 새 지역 분위기·BGM·모래폭풍, 새 몬스터 7종 + 고유 5 + 보스(`monsters.csv:16-28`), 웨이포인트. 빠진 것: (a) 보스의 확정 상징 전리품·「내 편」 장면 (b) 진입 즉시 쥐는 새 시스템 (c) 액트 1 안에서의 예고 (d) 글 다이어트. 심연은 액트 1 끝에 열리지만 「액트 1에 남을 이유」지 액트 2로 갈 이유가 아니다(`docs/design/23:17`).

### 3-5. 다른 안(opus-design-versions)에서 가져올 것

정본은 위 4안이다. 다른 모델의 4안(V1 망자의 석판 · V2 망자의 별자리 · V3 스킬 서고와 세 갈래 · V4 운명의 카드와 군단 문장)은 구조가 거의 같으므로 장치만 가져온다.
- **창 안 스킬 칸 띠**(A·S·D·F·우클릭 육각 88 다섯 개 상시, Act(slot) 재사용) — 칸 지정을 창 안에서 끝내 모바일 패드 편집 모드를 생략. 정본 공통 전제에서 「별도 과제」로 미룬 것인데, 어느 안을 골라도 2차에 얹을 만하다.
- **「찍을 곳 N」 순환 단추 + 탭/가지 「+N」** — 누를 때마다 다음 찍을 수 있는 후보로 이동. 어느 구조에도 붙고, V3의 「지금 배울 수 있음 N 토글」(심사 보완)과 같은 뜻.
- **지금 레벨 금선이 레벨업 뒤 첫 열기 때 한 칸 내려가는 0.5초 연출** · **잠긴 줄에 「Lv18 · 2레벨」 남은 수** — V3 시간선 표지·「다음 해금」 줄과 합친다.
- **잠긴 카드 = 뒷면 안개, 레벨 되면 뒤집힘**(UIScale x 1→0→1 0.4초) + **트리별 투자 게이지**(찍은 랭크 합·색 일관) — V4 보드 머리 줄에.
- **선 없는 연출 세트** — 빛 알갱이 32px 스프라이트가 선을 따라 0.35초 이동(SetPos만으로) · 막대 Filled 0→1 채움(0.4초) · 선 3단 후퇴 계획(line() → UIRotation 막대 → ㄱ자). V3 공방 부채 선·V1 시너지 선의 line 첫 사용 위험을 단계화.
- **need 기반 I·II·III 자동 단 분류 + 「강화 1·1·0」 빌드 코드 + 강화 없는 메인은 랭크 곡선** — 정본 V4와 같음(확인).
