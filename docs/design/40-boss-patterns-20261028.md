# 40. 보스 패턴 보강 (2026-10-28)

10-28 사용자: 「랜드마크랑 보스 크기를 키울까 · 액트별 보스 공격 패턴이 어떻게 되지 — 특정 체력 시점 스킬이나 기본 스킬」
→ 크기 B안(보스 ×1.4 / 최종 ×1.2 · 보스 배경 랜드마크 ×1.15, 662cf94) + 패턴 보강 결정.

## 1. 지금 (보강 전)

- 공통 틀(BossPattern): 5~7초마다 내려찍기(1초 예고) · 약 5초마다 무작위 기술 · 50%에서 분노(졸개 + 간격 ×0.65/0.7).
- 액트 최종 보스만 오라 · 50%·25% 2초 무적 + 졸개 · 소환수 쓸기 · 25% 궁극기 + 보스별 의식(Rite) 3~4단계.
- 끝방 우두머리 14명 중 11명은 공통 틀 + 장판 속성만 다름(고유 기믹은 크라그 껍질뿐). 모르그·테오·렌은 공통 틀도 없다.
- 액트 1 중간 보스(처형인·근위대장)는 오오라 + 일반 공격만. 대주교는 체력 시점 이벤트가 50% 분노뿐.

- 구현은 보스마다 의식 스크립트 하나(`<보스>Rite`) + 공통 훅(Monster.RiteTakenMult · RiteDealtMult).

## 4. 구현 메모

- 의식은 `bosses.csv extra`(공통 틀이 있는 보스) 또는 `monsters.csv rite`(공통 틀 없는 보스 — 처형인·근위대장·렌)로 붙는다.
- 받는/주는 피해 배율은 의식이 Monster.RiteTakenMult · RiteDealtMult를 바꾼다 (보스별 분기를 Monster에 늘리지 않는다).
- 죽거나 맵에 플레이어가 없으면 처음 상태로 (소환물 정리) — 기존 의식과 같은 규칙.
