사용자 피드백: 「습격이 온다」 글귀가 촌스럽다 · 떼가 한꺼번에 겹쳐 몰려온다 · 20마리가 평타 3방에 다 죽는다.
사용자 결정: **A + 1 + 3 조합 + 떼 몬스터도 아이템 드롭**. 기획서 41(습격) 위에 얹는 변경이며, 소환수 진형은 바꾸지 않는다(10-28 #5-C).

## 2. 연출 구조 (A)

- 글귀 「습격이 온다」(RaidText) · 상단 띠(TopPushFor `raid:warn`) **없음**.
- 파도마다 `raidWarnSec` 동안 (`HudMain.RaidWarn` → `RenderRaid`):
  - 떼가 솟을 쪽 화면 가장자리 표식이 **붉게 맥동**(0.5초마다 64 → 92px · 알파 0.45 → 1).
  - **미니맵 붉은 점**(`HudMap.RaidDots` — 파티원 점 P1을 실행 중 복제, ui 파일 변경 없음).
  - 바닥 조짐(액트별 코덱스 4프레임) 그대로.
  - **낮은 북소리 1회**: `sounds.csv raid_drum`(5384d174… 규칙적인 저음 2.3초) · 비교 후보 `raid_drum_alt`(17cd6171… 묵직한 한 번 1.7초) · 예전 = 저주 저음 SfxCurse.
- 소환 직후 `raidRiseSec` 동안 **땅을 뚫고 솟음**(`MonsterTraits.RiseTick` · 클라이언트): 세로 0.2 → 1(발밑 기준) · 알파 0 → 1 · 발밑 튐(액트 1·2 흙·모래 먼지 · 액트 3 물보라 · 액트 4 재 먼지 + 잿빛 김 — 엔진 기본 효과, 무덤 구더기 EmergeFx와 같은 방식 · 코덱스 생성 없음). 그동안 추격을 꺼서 제자리.
- 첫 습격 1회만 안내 줄 「사방에서 떼가 몰려옵니다」(`PlayerQuest.StorySeen` `raidintro` · 캐릭터 저장) · 이후 글귀 없음.
- 격퇴 「습격 격퇴 · N마리」 + 골드 주머니는 유지.

## 3. 파도·간격 구조 (1 · 3)

- 규모 N → `raidWaveSize`씩 파도(끝 파도가 1마리면 앞 파도에 붙임). 파도 k는 8방향 고리에서 `시작 + 3(k-1)` 칸(135°씩 회전)에 가장 가까운 열린 방향.
- 한 방향 최대 `raidDirMax`(3) — 넘치면 가장 가까운 옆 방향. 방향마다 고리 자리에서 바깥으로 `raidSpawnGap` 간격 한 줄 · 이 파도와 살아 있는 떼 모두와 1.2칸 이상(막히면 옆으로 비켜 봄).
- 속도: 파도 안에서 빠름·느림 번갈아 배정 → 줄마다 앞(플레이어 쪽)이 빠름 · 뒤가 느림이라 따라잡아 겹치지 않는다 (`Monster.HordeSpeedMul` → `RefreshSpeed`).
- 끝: 모든 파도가 나오고 살아 있는 떼 0 → 도망 0이면 격퇴, 수명(60초)·거리 정리로 사라진 떼가 있으면 timeout.
- 지옥 2파: 첫 파도 묶음의 70%를 잡으면 그 50%를 파도로 나눠 뒤에 붙인다.
