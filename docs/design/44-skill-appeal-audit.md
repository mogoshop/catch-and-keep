# 44. 스킬 매력 전수조사 — 스킬트리가 「계속할 이유」가 되나 (2026-10-29)

사용자 (10-29): 「스킬트리 UI는 완성됐고 너무 마음에 들어. 다만 사용자가 우리 스킬에 흥미를 느낄 수 있는지 전반적으로 스킬트리에 대해서 전수조사해서 개선할 방향이 있는지 파악해 줘. 게임에서 스킬은 중요해 — 네크로맨서 기본기는 갖췄지만 이미 진화된 스킬트리 UI나 맵에 부합한지, 사용자가 매력으로 느껴서 이 게임을 지속할 만큼의 매력이 있는지, 보완해야 한다면 뭐가 있는지.」

- 범위: 메인 스킬 29개(병합 뒤) + 강화 노드 57개(10-29 뼈 의식 강화 3 · 뼈 공명 포함), 해골·마법사 변이, 그림자 능력, 선택 보상(38 부록 I), 룬·장비의 스킬 옵션, 43 결정(뼈 의식 · 갈래 · 공명/당구).
- 방법: 게임 파일 읽기 + 시뮬(`tools/sim_balance.py`의 `build()`를 불러 빌드 변형 계산 — 부록 A) + 웹 레퍼런스(부록 B). **메이커는 띄우지 않았다**(다른 에이전트 사용 중). 「화면에 이렇게 보인다」는 모두 코드 근거로 판단한 것이고, 서버에서만 부르는 파티클 3곳은 「확인 필요」로 남겼다.

### 0-2. 진단 다섯 줄

1. **기본기와 창은 됐다. 가장 약한 것은 「눈에 보이는 것」이다.** 7항목 평균에서 ② 화면 효과가 2.07점으로 꼴찌이고 30개 중 22개가 2점 이하다. 모든 스킬이 같은 「Heal」 몸짓(SB:1065-1067), 시전음이 있는 메인은 29개 중 10개(SD:185-196 · 39는 의식 추가 전 9로 셈), 투사체 5종이 같은 궤적 그림(FxShardShot), 저주 6종이 같은 원 하나에 색만 다르고(SE:1097-1105), 궁극기급 화면 연출은 0이다.
2. **뒤에 오는 스킬일수록 약하다.** Lv15 이하 메인 14개 평균 22.2점, Lv27 이상 8개 평균 16.8점(−25%). Lv30 이후 메인 7개 중 6개가 강화 노드 0개다 — V3 「스킬 공방」 오른쪽 노드 판이 비어 있는 메인이 8개, 1개뿐인 메인이 5개(합 13/29).
3. **강화 57개 중 동작·외형이 바뀌는 것은 22개(39%)다.** 나머지 35개는 숫자이고, 그중 10개는 사실상 체감이 없거나 설명과 다르게 동작한다(질풍 걸음 +2%/랭크 · 흐릿한 형체 +0.05초 · 저주 지속이 공포에 안 먹음 등, §3-2).
4. **빌드는 「군단」 하나로 모인다.** 시뮬 기준 빌드(P60)에서 플레이어 몫은 6~18%, 그림자 몫이 53~73%다. 그런데 그림자에 플레이어 손이 닿는 스킬은 소환·집결·희생·승격 넷뿐이고 그중 둘은 대상을 자동으로 고른다. 주문 빌드는 Lv41에 P60의 77% 화력으로 성립하지만(플레이어 몫 65%), 저주 빌드는 75% 화력에 플레이어 몫 4% — 저주는 「빌드」가 아니라 「양념」이다(부록 A).
5. **우리 게임에 없는 재미의 종류**: 궁극기 연출 · 장비가 스킬 동작을 바꾸는 것(유니크 90개 중 0) · 조합 진화 · 저주끼리의 결합 · 소환수 명령(집결 하나) · 지형을 쓰는 스킬. 시체(혼) 자원 순환은 반쯤 있다(혼 구슬 → 해골) — 터뜨리는 쪽은 10-20에 모바일 조준 문제로 지웠다(`docs/design/24-skill-expansion.md:11`).

2. **투사체 단계 사건이 숨어 있다.** 뼈 창 10마리 관통(Lv37) · 서리 파편 4개(Lv40)는 공백 구간에 떨어지는 진짜 「오!」인데, 랭크 12까지 그 스킬에 11포인트를 더 넣어야 오고(Lv41 포인트 합 49, 부록 A), 랭크 사다리·시간선·카드 어디에도 「12랭크에 무엇이 바뀐다」가 표시되지 않는다(SW:270-278 — 랭크 점은 3상태뿐).
3. **Lv13~18은 반대로 넘친다.** 6레벨 동안 메인 6개 + ◆ 노드 7개가 열리는데 포인트는 6점이다. 「뭘 찍을지 모른다」(38 F4 진단 ⑥)가 여기서 가장 크다 — 스킬 추천 카드가 이 구간의 길잡이 역할을 해야 한다.
4. **20랭크 도달 사건은 지금 「상한만 풀림」이다.** 메인 20랭크 도달은 보통 4 · 악몽 19 · 지옥 6번(`docs/design/43-endgame-pull-plan.md:107-110`) — 악몽·지옥의 해금 공백을 메울 수 있는 가장 큰 사건 묶음인데 화면에 아무 일도 없다.
5. **해골 폭탄이 Lv10 → Lv24로 밀렸다.** 38 #3(폭탄 Lv10)은 43 #2·#3(의식 1기 단계로 병합 · 의식 Lv24)에 덮여, 지금 `bone_rite` row는 24다(csv:56). 그래서 Lv10에는 새 메인이 없고(그림자 본격만), 39 §2-2 표의 「Lv10 · 해골 폭탄」은 옛 값이다. 두 결정 모두 사용자 확정이라 되돌리는 안은 내지 않았다 — 다만 Lv9~12 구간은 변이 3종(Lv11)이 메워 공백은 아니다.

### 3-4. 조작 단조로움

1. **결정이 있는 조작은 셋뿐이다** — 질주(방향·충전), 뼈 의식(누르는 길이), 뼈 공명(평타로 해골 겨누기). 나머지는 「겨누고 누른다」 하나다.
2. **땅을 찍는 스킬에 범위 원이 없다.** 조준 표시는 방향 쐐기 하나(PA:321-358). 독안개·감옥·저주 6종은 「어디에 얼마나 크게」가 핵심인데 미리 보이지 않는다.
3. **모바일 끌기는 거리가 늘 5칸이다**(혼 스킬 2.5칸, SB:1241). 가까운 적 무리에 독안개·감옥·저주를 정확히 놓을 수 없다 — 「수동 조준」 결정의 모바일 쪽 구멍.
4. **소환수에 직접 명령하는 길이 집결(C) 하나다.** 그런데 소환수는 이미 「내가 고른 적」을 먼저 친다(SU:1001-1011) — 숨은 명령이 있는데 보이지 않는다. 습격·화약통(렌)·알 깨기(세르카)·저울(아메네트) 같은 보스 기믹은 명령이 있으면 더 재미있어질 자리다(`docs/design/40-boss-patterns-20261028.md:13-37`).
5. **고를 수 있어야 할 대상을 자동으로 고른다** — 정예 승격(최고 공격력) · 그림자 희생(조준점 최근접) · 성찬(체력 최저 해골). 「잡으면 내편」의 애착 대상(그림자)을 플레이어가 고르지 못한다.
