# 아이템 & 경제

룬·룬워드 상세는 [룬 시스템 v0.2](../rune-system-draft.md)에 있다. 이 문서는 그 바깥의 장비 체계 전체를 다룬다.

## 1. 장비 슬롯 (10)

| 슬롯 | 비고 | 단계 |
| --- | --- | --- |
| 무기 | 직업별 무기 타입 | P0 |
| 보조 | 네크로맨서: **영혼 등불**. 타 직업: 방패·보조 무기 | P1 |
| 투구 | 소켓 최대 3 | P1 |
| 갑옷 | 소켓 최대 5 | P1 |
| 장갑 | | P2 |
| 허리띠 | 포션 슬롯 수 결정 (D2 방식) | P2 |
| 신발 | 이동 속도 옵션 | P2 |
| 목걸이 | | P2 |
| 반지 ×2 | | P2 |

P0~P1은 **무기 + 보조 + 투구 + 갑옷**만 구현한다. 룬 소켓이 있는 4부위이기도 하다.

## 2. 인벤토리 & 보관함

| 항목 | D2 | 우리 | 이유 |
| --- | --- | --- | --- |
| 인벤토리 | 10×4 격자, 아이템 크기 다름 | **슬롯 방식 (예: 30칸), 아이템 크기 동일** | 격자 UI·충돌 처리 구현 비용 |
| 보관함 | 계정 공유 | 계정 공유, 48칸 [가정] | |
| 보관함 확장 | 없음 | P3 | |
| 포션 벨트 | 4칸 | 단축키 4칸 | |

격자 vs 슬롯은 12장 결정 필요 목록에 올렸다. 슬롯 방식을 권장한다.

## 3. 아이템 등급

| 등급 | 색 | 옵션 | 획득 | 단계 |
| --- | --- | --- | --- | --- |
| 일반 | 흰색 | 없음 (**소켓 뚫기·룬워드 대상**) | 드롭 | P1 |
| 마법 | 파랑 | 접두 1 + 접미 1 | 드롭 | P1 |
| 희귀 | 노랑 | 옵션 4~6 | 드롭, 정예 이상 | P1 |
| 세트 | 초록 | 세트 보너스 | 드롭, 낮은 확률 | P3 |
| 유니크 | 금색 | 고정 옵션 + 변동 범위 | 드롭, 보스 | P2 |
| 룬워드 | 금색(변형) | 룬워드 고정 | 일반 아이템에 룬 삽입 | P1~P3 |

D2의 "저품질, 상급, 제작" 등급은 제외했다. 정보량이 늘고 구분 가치가 낮다.

## 4. 기본 아이템 3단계 (베이스)

| 단계 | 레벨대 | 예 (네크로맨서 무기) |
| --- | --- | --- |
| 기본 | 1~25 | 단낫, 나무 지팡이 |
| 정련 | 26~50 | 장낫, 뼈 지팡이 |
| 극 | 51~80 | 사신의 낫, 혼 지팡이 |

- 단계가 높을수록 기본 피해·방어와 **소켓 상한**이 커진다. 룬워드의 소켓 수 요구가 단계와 자연스럽게 연결된다.
- 아이템 이름은 오리지널. 베이스 수 목표: 무기 12 (3단계 × 4종) + 보조 6 + 투구 6 + 갑옷 6 (초기).

## 5. 옵션 (접두·접미) 설계

### 5.1 접사 풀 구조

| 필드 | 설명 |
| --- | --- |
| `id` | 고유 ID |
| `slot` | 붙을 수 있는 부위 |
| `tier` | 아이템 레벨 구간 |
| `group` | 같은 그룹 옵션은 한 아이템에 중복 불가 |
| `stat`, `min`, `max` | 능력치와 범위 |
| `weight` | 출현 가중치 |

### 5.2 초기 옵션 목록 (골격, 접두 / 접미 각 12종 [가정])

| 구분 | 예 |
| --- | --- |
| 접두 (공격) | 피해 +%, 속성 피해, 치명타 확률, 공격 속도 |
| 접두 (방어) | 방어력, 최대 생명, 최대 마나, 블록 확률 |
| 접미 (저항) | 각 속성 저항, 모든 저항 |
| 접미 (유틸) | 이동 속도, 아이템 발견, 골드 발견, 생명 재생 |
| 그림자 전용 | 소환수 공격·생명, 추출 확률, 재소환 대기 감소 (영혼 등불 중심) |

### 5.3 희귀 아이템 이름

접두 어근 + 접미 어근을 조합해 자동 생성한다. (예: "철혼 + 낫") 오리지널 어근 사전 30개 정도를 데이터로 둔다.

## 6. 소켓·룬·보석

### 소켓
- 소켓 수 상한은 베이스 단계와 아이템 부위로 결정 ([룬 v0.2](../rune-system-draft.md) 1장)
- 소켓 뚫기는 재료 「공허의 정」으로 확정 뚫기

### 보석 (D2 방식 유지)

| 종류 | 무기 효과 | 방어구 효과 |
| --- | --- | --- |
| 자수정 | 피해 증가 | 모든 능력치 |
| 황옥 | 아이템 발견 | 아이템 발견 |
| 청옥 | 냉기 피해 | 마나 |
| 녹옥 | 독 피해 | 민첩 |
| 홍옥 | 화염 피해 | 화염 저항 |
| 금강석 | 번개 피해 | 번개 저항 |
| 해골 | 생명 흡수 | 피격 시 반사 |

5등급 (조각 / 흠집 / 일반 / 결함 없음 / 완전). 합성 3:1. 룬과 달리 룬워드 대상이 아니라 일반 소켓 강화용이며 P2.

## 7. 드롭

### 7.1 구조 (D2의 보물 등급 단순화)

```
몬스터 처치
  → 몬스터 보물 등급(TC) 결정 (몬스터 등급·레벨·보스 여부)
  → TC에서 N번 추첨 (몬스터 등급별 추첨 횟수)
  → 각 추첨에서 "없음 / 아이템 / 재화 / 룬 / 재료" 가중치 롤
  → 아이템이면 아이템 레벨 → 베이스 선택 → 등급 롤(아이템 발견 보정) → 옵션 롤
```

### 7.2 등급 확률 [가정]

| 등급 | 기본 확률 (일반 몬스터) | 정예 | 보스 |
| --- | --- | --- | --- |
| 일반 | 70% | 45% | 30% |
| 마법 | 25% | 40% | 35% |
| 희귀 | 5% | 14% | 25% |
| 유니크 | 0.2% | 1% | 8% |

아이템 발견(MF)은 마법 이상 확률에 곱연산하되 **상한을 둔다** (D2에서도 수확 체감). 상한은 데이터 테이블에서 조정.

### 7.3 룬 드롭

룬 v0.2 4장. 심도·난이도로 상위 룬 개방, 보스 확정 1개.

### 7.4 드롭 소유

- 개인 전리품(Personal Loot)을 기본으로 한다. 파티 내 분쟁을 막고 서버 구현을 단순화한다.
- 바닥 드롭 이후 30초 소유권 유지, 이후 공개. [가정]

## 8. 제작·합성 — 「혼합 제단」

D2 호라드림 큐브를 대체한다. 룬 승급이 이미 이 제단에 있으므로 기능을 한 곳에 모은다.

| 기능 | 재료 | 단계 |
| --- | --- | --- |
| 룬 승급 | 룬 v0.2 4장 | P1~P2 |
| 보석 승급 | 같은 등급 보석 3개 | P2 |
| 마법 재굴림 | 마법 아이템 1 + 재료 | P2 |
| 소켓 추가 | 일반 아이템 + 공허의 정 | P1 |
| 그림자 분해 | 그림자 → 그림자 정수 | P0 |
| 룬워드 해제 | 「망각의 의식」 | P2 |

## 9. 경제

### 9.1 재화

| 재화 | 획득 | 소비 |
| --- | --- | --- |
| 골드 | 몬스터, 판매 | 상점, 소켓 재료, 강화, 보관함 |
| 그림자 정수 | 그림자 분해 | 그림자 강화, 룬 승급 |
| 짙은 그림자 정수 | 정예 그림자 분해 | 상급 룬 승급 |
| 공허의 정 | 심층 드롭 | 소켓 뚫기 |
| 망각의 재 | 보스 드롭 | 망각의 의식 |

### 9.2 골드 싱크 (경제가 무너지지 않게)

| 싱크 | 단계 |
| --- | --- |
| 포션 구매 | P0 |
| 상점 장비 구입 | P1 |
| 소켓 뚫기 보조 비용 | P1 |
| 스킬·능력치 초기화 | P2 |
| 수리 | P3 (내구도 도입 시) |
| 도박 (미감정 희귀 구매) | P3 |

### 9.3 감정·내구도

- 감정: **제외**. 획득 즉시 옵션 공개.
- 내구도: **P3 보류**. 도입하면 골드 싱크가 되지만 UI·서버·밸런스 비용이 크다.

### 9.4 상점 NPC

| NPC 유형 | 판매 | 단계 |
| --- | --- | --- |
| 무기상 | 기본 무기, 마법 무기 | P1 |
| 방어구상 | 방어구 | P1 |
| 약사 | 포션 | P0 |
| 잡화상 | 귀환 아이템, 재료 | P1 |

상점 재고는 영역(마을)별로 레벨에 맞게 갱신한다.

## 10. 거래

| 방식 | D2 | 우리 | 단계 |
| --- | --- | --- | --- |
| 직접 거래 | 거래창 | 거래창 (양쪽 확인 후 교환) | P2 |
| 룬 | 거래 가능 | 거래 가능 | P2 |
| 룬워드 완성품 | 거래 가능 | **귀속** | P1 |
| 경매장 | 없음 | 보류 (MSW 경제 정책 확인 후) | P3 |

거래는 사기·복제 취약 지점이다. 서버가 거래 상태를 단일 트랜잭션처럼 처리하고 로그를 남겨야 한다. (10장)

## 11. 아이템 데이터 모델

```lua
ItemInstance = {
  uid = "...",             -- 서버 발급 고유 ID (복제 방지)
  baseId = "scythe_basic",
  quality = "magic",       -- normal / magic / rare / unique / runeword
  ilvl = 12,
  affixes = { {id = "pre_dmg_pct", value = 18}, ... },
  sockets = { max = 3, runes = { "as", "irn" } },
  runeword = nil,
  bound = false,
}
```

MSW 기본 아이템 서비스가 이런 가변 옵션을 담을 수 있는지는 **미확인**이다. 담을 수 없으면 서버 자체 데이터로 아이템을 관리하고 MSW 아이템은 표시에만 쓰는 구조로 간다. (10장)
