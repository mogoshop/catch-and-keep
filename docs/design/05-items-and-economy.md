# 아이템 & 경제

룬·룬워드 상세는 [룬 시스템 v0.2](../rune-system-draft.md)에 있다. 이 문서는 그 바깥의 장비 체계 전체를 다룬다.

## 1. 장비 슬롯 (10)

| 슬롯 | 비고 | 단계 |
| --- | --- | --- |
| 무기 | 직업별 무기 타입 | P0 |
| 보조 | 네크로맨서: **영혼 등불**. 타 직업: 방패·보조 무기 | P1 |
| 투구 | 소켓 최대 3 | P1 |
| 갑옷 | 소켓 최대 5 | P1 |
| 장갑 | | P2 |
| 허리띠 | 포션 슬롯 수 결정 (D2 방식) | P2 |
| 신발 | 이동 속도 옵션 | P2 |
| 목걸이 | | P2 |
| 반지 ×2 | | P2 |

P0~P1은 **무기 + 보조 + 투구 + 갑옷**만 구현한다. 룬 소켓이 있는 4부위이기도 하다.

## 2. 인벤토리 & 보관함

| 항목 | D2 | 우리 | 이유 |
| --- | --- | --- | --- |
| 인벤토리 | 10×4 격자, 아이템 크기 다름 | **슬롯 방식 (예: 30칸), 아이템 크기 동일** | 격자 UI·충돌 처리 구현 비용 |
| 보관함 | 계정 공유 | 계정 공유, 48칸 [가정] | |
| 보관함 확장 | 없음 | P3 | |
| 포션 벨트 | 4칸 | 단축키 4칸 | |

격자 vs 슬롯은 12장 결정 필요 목록에 올렸다. 슬롯 방식을 권장한다.

## 3. 아이템 등급

| 등급 | 색 | 옵션 | 획득 | 단계 |
| --- | --- | --- | --- | --- |
| 일반 | 흰색 | 없음 (**소켓 뚫기·룬워드 대상**) | 드롭 | P1 |
| 마법 | 파랑 | 접두 1 + 접미 1 | 드롭 | P1 |
| 희귀 | 노랑 | 옵션 4~6 | 드롭, 정예 이상 | P1 |
| 세트 | 초록 | 조각 고정 옵션 + 2개·3개·전체 효과. **전체 효과에 그림자 절대 상한 +1~2** | 드롭 (일반 1%·정예 3%·보스 6%) | 구현 |
| 유니크 | 금색 | 고정 옵션 + 변동 범위 | 드롭, 보스 | P2 |
| 룬워드 | 연금색 | 룬워드 고정 (엔드 아이템 — 가장 강함) | 일반 아이템에 룬 삽입 (소켓 수 = 룬 수) | 구현 (6종) |

D2의 "저품질, 상급, 제작" 등급은 제외했다. 정보량이 늘고 구분 가치가 낮다.

## 4. 기본 아이템 3단계 (베이스)

| 단계 | 레벨대 | 예 (네크로맨서 무기) |
| --- | --- | --- |
| 기본 | 1~25 | 단낫, 나무 지팡이 |
| 정련 | 26~50 | 장낫, 뼈 지팡이 |
| 극 | 51~80 | 사신의 낫, 혼 지팡이 |

- 단계가 높을수록 기본 피해·방어와 **소켓 상한**이 커진다. 룬워드의 소켓 수 요구가 단계와 자연스럽게 연결된다.
- 아이템 이름은 오리지널. 베이스 수 목표: 무기 12 (3단계 × 4종) + 보조 6 + 투구 6 + 갑옷 6 (초기).

## 5. 옵션 (접두·접미) 설계

### 5.1 접사 풀 구조

| 필드 | 설명 |
| --- | --- |
| `id` | 고유 ID |
| `slot` | 붙을 수 있는 부위 |
| `tier` | 아이템 레벨 구간 |
| `group` | 같은 그룹 옵션은 한 아이템에 중복 불가 |
| `stat`, `min`, `max` | 능력치와 범위 |
| `weight` | 출현 가중치 |

### 5.1.1 부위별 옵션 (D2 규칙 차용, `data/item_affixes.csv`)

| 부위 | 고유하게 붙는 옵션 | 그 밖 |
| --- | --- | --- |
| 무기 | 피해 %·고정 피해·속성 피해, **공격 속도 10~20**, 생명력 흡수 | 힘·민첩·정신·마나 |
| 장갑 | **공격 속도 10~30**, 독 피해 | 힘·민첩·아이템/골드 발견·저항·방어 |
| 신발 | **이동 속도 10~30** | 민첩·아이템/골드 발견·저항·방어 |
| 반지 | **시전 속도 10**, 생명력 흡수, 속성 피해 | 생명·마나·능력치·저항·발견 |
| 목걸이 | **시전 속도 10~20**, 소환수 % | 생명·마나·능력치·모든 저항·발견 |
| 투구 | 추출 확률, 소환수 % | 방어·생명·마나·정신·저항·아이템 발견 |
| 갑옷 | 방어(높음), 활력(거인의) | 생명·힘·저항·재생 |
| 허리띠 | 활력(거인의) | 생명·방어·골드 발견·재생·저항 |
| 등불(보조) | 소환수 %, 추출 확률 | 방어·생명·마나·정신·저항 |

공격 속도 = 기본 공격 간격 단축, 시전 속도 = 스킬 재사용 대기 단축 (각 상한 75%).

### 5.1.2 세트 (`item_sets.csv`·`item_set_pieces.csv`)

| 세트 | 부위 | 2개 | 3개 | 전체 |
| --- | --- | --- | --- | --- |
| 잿빛 군단 (Lv1) | 두건·수의·장갑·행군화 | 소환수 +15% | 모든 저항 +10, 추출 +5 | **그림자 상한 +1**, 배치 +1, 소환수 +20% |
| 뼈의 합창 (Lv26) | 투구·갑옷·등불 | 소환수 +25%, 시전 +10 | — | **그림자 상한 +1**, 모든 저항 +20, 생명 +40 |
| 무덤왕의 유산 (Lv51) | 혼관·수의 갑주·혼백 등불·인장 | 소환수 +30% | 모든 저항 +25, 시전 +20 | **그림자 상한 +2**, 배치 +2, 소환수 +40%, 생명 +80 |

그림자 상한 보너스는 세트 전용이며 합계 최대 +2 (상한 8 → 10).

### 5.1.3 룬워드 (`runewords.csv`)

초중반 4종(첫 번째 군령·무덤의 속삭임·망자의 행진·검은 서약)과 엔드 2종: **끝없는 장례**(갑옷 5룬, 모든 저항 40·생명 150·방어 120·소환수 40%)·**망령 군주**(무기 6룬, 피해 250%·소환수 60%·공격 속도 40·시전 30·배치 +1). 상위 룬(Lv45~65)이 필요하다.

### 5.2 초기 옵션 목록 (골격, 접두 / 접미 각 12종 [가정])

| 구분 | 예 |
| --- | --- |
| 접두 (공격) | 피해 +%, 속성 피해, 치명타 확률, 공격 속도 |
| 접두 (방어) | 방어력, 최대 생명, 최대 마나, 블록 확률 |
| 접미 (저항) | 각 속성 저항, 모든 저항 |
| 접미 (유틸) | 이동 속도, 아이템 발견, 골드 발견, 생명 재생 |
| 그림자 전용 | 소환수 공격·생명, 추출 확률, 재소환 대기 감소 (영혼 등불 중심) |

### 5.3 희귀 아이템 이름

접두 어근 + 접미 어근을 조합해 자동 생성한다. (예: "철혼 + 낫") 오리지널 어근 사전 30개 정도를 데이터로 둔다.

## 7. 드롭

### 7.1 구조 (D2의 보물 등급 단순화)

```
몬스터 처치
  → 몬스터 보물 등급(TC) 결정 (몬스터 등급·레벨·보스 여부)
  → TC에서 N번 추첨 (몬스터 등급별 추첨 횟수)
  → 각 추첨에서 "없음 / 아이템 / 재화 / 룬 / 재료" 가중치 롤
  → 아이템이면 아이템 레벨 → 베이스 선택 → 등급 롤(아이템 발견 보정) → 옵션 롤
```

### 7.2 등급 확률 (D2 기준, `data/drop_tables.csv`)

D2처럼 장비 1개마다 **유니크 → 세트 → 레어 → 마법** 순서로 판정한다. 일반 몹은 대부분 일반·마법이고, 유니크는 보스·최상위가 주 공급원이다. (D2 노멀 일반 몹: 유니크 약 0.25%·세트 0.6%·레어 1%, 보스는 품질 보정으로 아이템 1개당 유니크 약 6%)

| 몬스터 등급 | 추첨 | 유니크 | 세트 | 레어 | 마법 |
| --- | --- | --- | --- | --- | --- |
| 일반 | 1 | 0.25% | 0.6% | 1.5% | 15% |
| 정예 | 2 | 1% | 2% | 6% | 30% |
| 변종 우두머리 | 2 | 1.5% | 2.5% | 8% | 35% |
| 최상위 | 3 | 4% | 4% | 15% | 40% |
| 보스 | 5 (+룬 확정) | 7% | 5% | 25% | 40% |
| 도박·의뢰 보상 | 1 | 1~3% | 2~4% | 15~35% | 마법 이상 보장 |

아이템 발견(MF)은 마법 이상 확률에 곱하되 체감 (최대 ×2.5).

**보스 보상감**
- 보스·최상위가 유니크를 떨구면 절반은 그 몬스터 **전용 유니크** (`item_uniques.csv` source): 묘지기 여왕 「묘지기의 왕관」·「여왕의 송장 손」, 처형인 「처형인의 사슬」, 바르그 「바르그의 인장」.
- **첫 처치 보상**: 캐릭터·난이도마다 처음 잡으면 전용 유니크(없으면 일반 유니크, 그다음 세트) 1개 확정 — D2 퀘스트 드롭에 해당. Lv12 여왕 처치가 그림자 본격 해금(Lv15) 전의 큰 보상 순간이 된다.

### 7.3 룬 드롭

룬 v0.2 4장. 심도·난이도로 상위 룬 개방, 보스 확정 1개.

### 7.4 드롭 소유

- 개인 전리품(Personal Loot)을 기본으로 한다. 파티 내 분쟁을 막고 서버 구현을 단순화한다.
- 바닥 드롭 이후 30초 소유권 유지, 이후 공개. [가정]

## 11. 아이템 데이터 모델

```lua
ItemInstance = {
  uid = "...",             -- 서버 발급 고유 ID (복제 방지)
  baseId = "scythe_basic",
  quality = "magic",       -- normal / magic / rare / unique / runeword
  ilvl = 12,
  affixes = { {id = "pre_dmg_pct", value = 18}, ... },
  sockets = { max = 3, runes = { "as", "irn" } },
  runeword = nil,
  bound = false,
}
```

MSW 기본 아이템 서비스가 이런 가변 옵션을 담을 수 있는지는 **미확인**이다. 담을 수 없으면 서버 자체 데이터로 아이템을 관리하고 MSW 아이템은 표시에만 쓰는 구조로 간다. (10장)
