1. 스킬 이름이 직관적이지 않다(「뼈 갑옷」·「뼈 의식」) — **그림은 더 문제(또 해골)**. 강화 노드 이름도 포함.

5. 디아 2/3/4 · 이모탈 · PoE 레퍼런스로 전수조사 + 메이플 에셋(아이콘)을 함께 붙이는 것까지 고려.

범위: `data/skills.csv` **90줄 전부**(메인 28 = 액티브 19 · 저주 6 · 상시 3 / 강화 노드 62 · 보류 2 포함). 조사·제안만 — 코드·데이터·UI는 고치지 않았다.

### 0-3. 추천 요지

- **이름 (§5)**: **A 외래어(메이플식 음역)를 메인 스킬 기본**으로, **노드는 「부모 + 기능」 짧은 외래어 접미(메이플의 `-리인포스` · `-퍼시스트` · `-익스텐드` · `-쿨타임 리듀스` 관례)**. 근거 — ① 사용자가 외래어를 선호(인벤토리 · 퀘스트 · 노말) ② 메이플 한국 공식 스킬명이 음역 체계(포이즌 미스트 · 텔레포트 · 헤이스트 · 다크 사이트)라 MSW 플레이어에게 익숙 ③ 노드 접미가 「무슨 강화인지」를 바로 보여 줘 하 25개 중 노드 21개가 한 번에 풀림. **주의**: 디아 2·3·4의 **한국어 공식 표기는 오히려 한국어**(뼈 갑옷 · 시체 폭발 · 뼈 감옥 · 피해 증폭 — 나무위키 D2 기술 표, 부록 A)라 「본 아머」식은 D2 **플레이어 통칭**(앰플 · 라탭 · 본스 · 본프)에 가깝다. 지금 「뼈 갑옷」은 D2 공식 한국어와 같은 말인데도 이해가 안 된다는 지적이므로, **표기 체계보다 「효과와 맞는 단어」가 더 중요**하다(낙인 → 앰플리파이, 갑옷 → 실드).
- **역할 과밀 (§2)**: **안 ① 거인 = 독립 액티브 「본 자이언트」 + 노드 12(지금 거인 노드 그대로)**, 뼈 의식은 「본 봄」(1·2·3단계)만. 저장은 거인 노드 포인트 **환급 1회**(49 뼈 창 선례 · 알림 없음). 위험 = 칸 1개 더 필요 → PC 전용 키(V) + 모바일 명령판에 두는 결정이 함께 필요.
- **UI (§3)**: 「직접 정하기」는 **노드 편성(포인트)**이 아니라 **해골 전사 변이 편성(대검·쌍칼을 몇 기 세울지)** 수동 모드다 — 사용자가 이걸 「노드 편성」으로 읽은 것 자체가 이름 실패의 증거. 추천 = **안 A 「편성 칸 상시 스테퍼」**(대검·쌍칼 각 −/+를 해골 전사 공방에 늘 두고, 자동/직접 토글 삭제 · 「자동으로」 되돌리기 글자 단추만): 최소 5클릭 → 3클릭, 노드를 고를 필요가 없어 「강화 +1」 오클릭 위험이 사라진다. 0.5~1일.
- **메이플 아이콘 (§4)**: **안 2 「코덱스 유지 + 불일치만 코덱스로 다시」 추천**. 메이플 스킬 아이콘은 32×32 · 흰 테두리 · 밝은 원색 · 버프 아이콘의 흰 막대 사람이 많아 코덱스 어두운 고딕(96~128px)과 한 판에 섞이면 튄다. 해골·뼈·거인 모티프는 메이플에 아예 없다(강령술사 직업 없음). 메이플은 **노드 아이콘 표본 6장 메이커 시험**(44px 칸이면 1.4배라 깨짐이 적다)으로만 열어 두고, 승인 시 노드 한정 혼합(안 3-b)으로 간다.

## 1. 전수표 (90줄)

### 1-1. 판정 기준

- **해금**: 메인 = csv `row`(캐릭터 레벨). 노드 = 부모 해금 + 2 × (필요 랭크 − 1) (`SB:131 NodeLevel` · 다음 랭크는 +4레벨). 그림자 증원 = Lv12·17·22, 군령 = 부모 3랭크마다. 거인 노드 = 악몽 해금 필요(`SB:1307 RiteGiantUnlocked`).
- **한 줄 역할**: csv `desc`와 코드(SB · US · SkillEffects)에서 실제로 하는 일. 수치는 핵심만.
- **이름 직관성**: 상 = 처음 보는 사람이 이름만으로 효과를 맞힘 · 중 = 방향은 맞히나 대상·조건이 모호 · 하 = 이름으로는 효과를 못 맞히거나 다른 스킬로 오해.
- **그림**: ○ = 역할이 그림으로 읽힘 · △ = 주제는 맞으나 「무슨 강화인지」·「누구 이야기인지」가 안 보임 · ✕ = 다른 것을 그림.
- **레퍼런스**: 영문 원어 + D2 한국어 공식 표기(나무위키 D2 기술 표로 확인 · 부록 A). D3·D4 한국어는 기억 기반이라 영문만 적었다. 대응이 없으면 「—」.
- **제안 A 외래어**: 메이플 한국 공식 음역 관례를 따른다 — 쉐도우(섀도 아님) · 익스플로젼 · 대쉬 · `-리인포스`(강화) · `-퍼시스트`(지속) · `-익스텐드`(범위) · `-쿨타임 리듀스`. 디아 원어가 있으면 그것을 음역(레이즈 스켈레톤 · 본 프리즌 · 앰플리파이 데미지 …).
- **제안 B 한국어 직관**: 효과가 드러나는 말. 노드는 「부모 + 기능」(독안개 범위 · 질주 재사용 감소).
- **메이플 아이콘 후보**: 이름만 — RUID는 §1-3. 괄호 = **뜻이 맞는 정도**(화풍 판단은 §4).

## 3. UI — 「직접 정하기」

### 3-0. 먼저 바로잡을 것: 「직접 정하기」는 무엇인가

- 코드 기준(`SW:589 RenderForm` · `US:1117 PlaceQuota` · `SB:940 RequestFormMode` · `SB:961 RequestFormHope`): **해골 전사의 변이 편성**(대검·쌍칼을 몇 기 세울지)을 자동(= 노드 랭크 수만큼 전부) ↔ 직접(= 노드 랭크 **이하**에서 희망 수) 으로 바꾸는 칸이다. 노드 포인트 편성이 아니다.
- 직접 모드가 할 수 있는 일은 **「찍은 변이를 덜 세우기」뿐**이다 — 희망 수 상한 = 그 변이 노드 랭크(`SB:984` 「배운 강화 랭크까지」). 남는 자리는 기본형(랭크 8부터 방패 해골)이 채운다. 즉 「대검 3랭크를 찍었지만 대검은 1기만, 나머지는 방패」 같은 선택.
- 해골 마법사 편성은 48-2로 변이가 없어져 칸이 숨는다(`SW:601`). 모바일 골편은 같은 칸이 「누르고 있으면 반복」 켜기/끄기로 바뀐다.
- 사용자가 이 기능을 「노드 편성 수동 모드」로 읽었다는 것 = **이름 「직접 정하기」가 대상을 말하지 않는다**는 증거다.

## 5. 추천과 순서

### 5-1. 이름: A(외래어) 기본 + 노드는 「부모-기능」 접미 — 근거

1. 사용자 선호(외래어 · 「장비창 → 인벤토리」)와 같은 방향.
2. 메이플 한국 공식 스킬명이 음역 체계(포이즌 미스트 · 텔레포트 · 헤이스트 · 쉐도우 파트너 · 메소 익스플로젼)라 MSW 플레이어가 「게임 스킬 이름」으로 받아들이는 말투다. 메이플 아이콘을 일부 쓰게 되면(§4 3-b) 이름과 그림의 결도 맞는다.
3. 노드를 「대쉬-쿨타임 리듀스」 · 「미스트-퍼시스트」 · 「커스-익스텐드」처럼 **부모 + 기능**으로 쓰면 노드 하 21개가 「어느 스킬의 무슨 강화인지」 문제를 한 번에 푼다(B안도 같은 효과지만 「독안개 지속」류는 설명문 같아 스킬 이름 느낌이 약함).
4. 단, **A 원칙보다 「효과와 맞는 단어」가 우선** — 어려운 원어는 쉬운 영어로 낮춘다(디크리피파이 → 슬로우 · 아이언 메이든 → 커스 리플렉트 · 컨테이젼 → 스프레드). 한국어에서 나쁜 뜻이 붙는 음역도 피한다(Terror → 「테러」 대신 「피어」). 지금 「뼈 갑옷」이 D2 공식 한국어와 같은데도 안 읽히는 이유는 표기 때문이 아니라 **효과(흡수막)와 단어(갑옷)가 어긋나서**다.
5. 유닛 이름(해골 전사 · 해골 마법사 · 방패/대검/쌍칼 해골 · 그림자)은 **한국어 그대로** 둔다 — HUD · 안내 · 퀘스트에 49·23·20번 박혀 있고(§5-3), 「레이즈 스켈레톤으로 해골 전사를 일으킨다」처럼 스킬(외래어) ↔ 유닛(한국어)이 갈리는 것이 디아 2의 구조와 같다.

대안: **B 전면**(한국어 직관) — 글귀 규칙(퀘스트 · 인벤토리는 외래어 유지)과 충돌은 없으나 사용자가 「뼈 갑옷은 그냥 한국어」라며 외래어 쪽을 예로 들었으므로 2순위.
