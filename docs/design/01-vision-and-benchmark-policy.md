# 비전 & 벤치마킹 원칙

## 1. 한 줄 컨셉

> 쓰러뜨린 적을 그림자로 거느리고, 룬워드로 군단을 완성하는 네크로맨서 핵앤슬래시 (MSW 2.5D 탑다운 · RectTile)

## 2. 핵심 재미 (우선순위 순)

1. **수집과 성장**: 약한 적도 그림자가 되어 쌓이고, 쓸모를 찾아 강해진다.
2. **빌드 선택**: 같은 직업이라도 군세/정예/본체/저주로 플레이가 갈린다.
3. **장비 사냥**: 룬을 모아 룬워드를 완성하는 장기 목표.
4. **반복 가능한 짧은 루프**: 5~10분 한 판에 보상이 한 번 이상 나온다.

## 3. 타깃과 플랫폼

| 항목 | 내용 | 확인 |
| --- | --- | --- |
| 플랫폼 | MSW (PC·모바일) | 모바일 지원은 MSW 클라이언트 기능에 의존 |
| 플레이 형태 | 솔로 + 소규모 파티(4인 이하) | **[가정]** |
| 세션 | 짧은 세션 위주 (모바일 고려) | **[가정]** |
| 타깃 | 핵앤슬래시·디아블로류 경험자, MSW 이용자 | **[가정]** |

## 4. 벤치마킹 원칙 (이 프로젝트의 핵심 규칙)

시간과 인력이 부족하므로 **D2를 가능한 한 그대로 가져오고, 바꿀 이유가 있는 곳만 바꾼다.**

### 4.1 판단 기준: 채택 → 변형 → 제외

| 분류 | 조건 | 처리 |
| --- | --- | --- |
| **채택** | MSW에서도 의미가 같다 | 구조와 수치 체계를 거의 그대로 사용 |
| **변형** | 원리는 유효하지만 입력 방식·시점·플랫폼 때문에 그대로는 안 된다 | 목적은 유지하고 구현만 바꿈 |
| **제외** | 구현 비용 대비 효과가 낮거나 MSW에서 불가 | 만들지 않고 근거를 기록 |

### 4.2 반드시 바꿔야 하는 것: 시점과 입력

> **2026-10-06 결정 변경:** 처음에는 "MSW는 횡스크롤만 된다"는 전제로 썼으나, MSW는 **RectTile(탑다운) 모드**를 지원한다. 상하좌우 자유 이동 + 높이 타일로 입체감을 내는 2.5D 탑다운으로 전환했다. 맵 `TileMapMode = 1`, 이동 바디는 `KinematicbodyComponent`다.

D2는 **쿼터뷰 + 클릭 이동 + 마우스 타겟팅**이고, 우리는 **탑다운 + 키보드(8방향)/터치 이동 + 스킬 키**다. 시점은 D2와 가까워졌고, 남은 차이는 입력 방식이다.

| D2 | 우리 | 이유 |
| --- | --- | --- |
| 클릭 이동, 클릭 공격 | 키보드 8방향/터치 이동, 스킬 키 발동 | MSW 기본 입력 구조. 클릭 이동은 Phase 1 이후 검토 |
| 명중률 vs 방어력 판정 | 방어력을 피해 감소 %로 변환 (03장) | 액션 게임에서 "빗나감"은 불쾌 |
| 랜덤 생성 맵 | 고정 맵 + 랜덤 몬스터/보스 배치 + 심도 던전 | 타일 맵은 런타임 `SetTile`/`BoxFill`로 절차 생성도 가능 (후속 검토) |
| 쿼터뷰 광역 전투 | 탑다운 광역 전투 (원형·사각 범위) | 시점이 같아 판정 형태를 거의 그대로 사용 |
| 쿨다운 없는 스킬(마나 기반) | 마나 + 짧은 쿨다운 병행 | 키 연타 환경에서 밸런스 보호 |
| 스태미나(달리기) | 제외 (재검토 가능) | Phase 0 범위 밖 |

점프는 RectTile에서 **시각 효과뿐**(실제 높이 변화 없음)이다. 지형 높낮이는 높이 타일과 이동 불가 타일로 표현한다.

### 4.3 그대로 가져오는 것

- 4대 능력치, 레벨당 능력치·스킬 포인트 분배
- 6속성 피해와 저항, 저항 상한, 난이도별 저항 페널티
- 장비 슬롯 구성과 아이템 5등급
- 접두·접미 옵션 풀 구조, 보물 등급(Treasure Class) 드롭 구조
- 소켓·룬·룬워드·보석 체계
- 몬스터 5등급(일반/정예/우두머리/최상위/보스)과 수식어
- 막 단위 진행, 웨이포인트, 귀환 포털, 공유 보관함
- 직업당 3개 스킬 트리, 선행 스킬, 스킬 시너지
- 난이도 3단계 반복

### 4.4 지식재산 주의

게임 **메커니즘**(규칙·수치 구조)은 참고할 수 있지만 다음은 쓰지 않는다. 룬 시스템에서 이미 적용한 방침과 같다.

- D2의 **고유 명칭**(룬 이름, 룬워드 이름, 스킬 이름, 몬스터·NPC·지역 이름), 스토리, 대사, 아트, 음악
- 「나 혼자만 레벨업」의 **고유 명칭·캐릭터·대사·연출**. "그림자 군단"이라는 개념 차용은 컨셉 수준에 머문다. 그림자 추출 연출은 오리지널로 만든다.
- 메이플스토리 IP 외 모든 외부 IP

넥슨의 MSW 운영 정책·저작권 정책에도 위배되지 않는지, 게시 전에 정책 문서를 확인한다. (12장 결정 필요 목록)
