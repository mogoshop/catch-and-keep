# 로드맵·역할·리스크

## 1. 단계

| 단계 | 목표 | 완료 기준 |
| --- | --- | --- |
| P0 | 코어 루프 검증 (추출→소환→전투→분해) | 맵 1개, 몬스터 3종, 그림자 소환/분해 동작, 부하 시험 통과 |
| P1 | 영역 1 수직 슬라이스 | 레벨 1~15, 장비 4부위, 룬 하급, 퀘스트 6, 보스 1, 저장 동작 |
| P2 | 영역 2~3 + 파티 | 중급 룬, 룬워드 일부, 파티 4인, 거래, 두 번째 직업 착수 |
| P3 | 영역 4~5 + 심도 | 상급·신화 룬, 심도 던전, 랭킹 |
| P4 | 확장 | 길드, PvP, 추가 직업 |

각 단계는 **그 단계만으로 플레이 가능한 버전**이어야 한다. P0만으로도 "그림자 모아 싸우는 재미"가 있는지 검증하고, 재미가 없으면 P1로 가지 않는다.

## 2. 역할 분담 (현재 가정: 사용자 1명 + Claude)

| 역할 | 담당 | 비고 |
| --- | --- | --- |
| 기획 결정 | 사용자 | 12장 5절 결정 목록 |
| 메이커 작업 (맵 배치, 에셋, UI 배치) | 사용자 | Claude는 메이커를 직접 조작하지 못하는 것으로 가정, MCP 확인 후 재평가 |
| mLua 스크립트, 데이터 표, 설계 문서 | Claude | 사용자 검토 |
| 밸런스 시뮬레이터 | Claude | MSW 없이 가능 |
| 실행 검증·플레이 테스트 | 사용자 | 결과를 Claude에 전달 |
| 에셋 제작 | 미정 | 09장 선택에 따름 |

**병목은 사용자의 시간**이다. 사용자가 한 번 접속할 때 확인해야 할 항목을 모아 **검증 체크리스트**로 넘기는 방식으로 왕복을 줄인다.

## 6. 즉시 다음 행동 (사용자 퇴근 후)

1. 설치·빈 월드 생성·GitHub 공유 (`docs/setup-checklist.md`).
2. Claude: 폴더 수령 후 구조 확인, Phase 0 step 0-1 조사 (저장·호출·엔티티·몬스터 이벤트).
3. 조사 결과로 `AGENTS.md`의 미확인 항목을 확정/수정하고 10장 갱신.
4. 밸런스 시뮬레이터와 데이터 표는 MSW와 무관하게 먼저 착수 가능.
