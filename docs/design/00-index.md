## 이 표를 쓰는 법

- **새 기능을 구현하기 전에** 해당 행의 문서를 읽고, 상태가 ⬜ 골격이면 먼저 문서를 채운다.
- 🔴 항목은 구현 전에 메이커·MSW 문서로 **기능 존재 여부부터 확인**한다. (AGENTS.md "미확인 항목")
- 상태가 바뀌면 이 표의 해당 행을 갱신한다.
