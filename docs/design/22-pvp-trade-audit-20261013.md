# 22. 결투(PvP)·거래 점검 (2026-10-13)

> [확인] = 코드 근거. 경로는 `RootDesk/MyDesk/` 기준.

## 1. 결투 — 지금 구조 [확인]
- 시작: 플레이어 창(P) → 「결투」 → 상대 수락. 같은 지역이어야 하고 마을에서는 안 된다 (`Social/PlayerSocial.mlua`).
- 적대 판정: `Combat/PlayerAttack.IsAttackTarget` 한 곳 — 결투 상대만 맞는다(일반 플레이어끼리는 서로 안 맞는다). PvP 피해 ×0.25. 판정·피해는 서버.
- 끝: 쓰러지거나 맵이 달라지면. 진 쪽은 제자리 부활(벌칙 없음). 승리 보상 물건은 없다 (예전 「귀」 드롭은 10-13에 제거 — 특정 게임 고유 요소라 저작권 위험. 예전 저장의 귀는 불러올 때 버린다).
- 신청 조건: 상대 수락(20초 안) · 같은 지역 · 마을 밖 · **레벨 차 `duelMaxLevelGap`(10) 이하** — 신청할 때와 수락할 때 모두 서버가 확인하고, 플레이어 창은 차이가 크면 결투 단추를 숨기고 「레벨 차로 결투 불가」를 띄운다.

## 2. 이번에 고친 것 (10-13)
| 문제 | 수정 |
|---|---|
| 결투 중에 **몬스터에게 죽어도** 결투 패배로 처리돼 사망 벌칙(경험치·골드·시체)이 없었다 — 결투를 걸어 두고 사냥하면 벌칙 회피 | 마지막으로 때린 플레이어(소환수면 주인)가 결투 상대이고 5초 안일 때만 결투 패배. 아니면 결투를 승패 없이 끝내고 일반 사망 (`Combat/PlayerVitals.Die`, `PlayerDuel.Abort`) |
| 결투 중인데 새 결투를 받으면 상대가 덮어써져 한쪽만 때릴 수 있는 결투가 생김 | 둘 중 하나라도 결투 중이면 수락 거절 |
| 결투에서 지면 소환수가 전부 무너짐 | 결투 패배는 군단 유지 |
| 거래 직후 바로 저장하지 않음 (120초 사이 서버가 내려가면 복제·유실) | 거래 완료 직후 양쪽 즉시 저장 |
| 거래 중 접속 종료 시 저장과 물건 반환 순서가 정해져 있지 않아 물건 유실 가능 | 나가기 저장 전에 거래를 먼저 취소해 물건을 가방에 돌려놓는다 (`PlayerSave` UserLeave) |
| 골드 부족으로 거래가 안 될 때 아무 말이 없음 | 양쪽에 안내 |

## 3. 남은 문제 — 결정이 필요한 것
| # | 문제 | 심각도 |
|---|---|---|
| R1 | **소환수가 PvP에 참여하지 않는다.** 그림자·해골·마법사는 몬스터만 공격하고, 상대 소환수를 칠 수도 없다. 「군단 대 군단」이 안 된다 | 높음 (게임 정체성) |
| R2 | **주력 스킬 대부분이 플레이어에게 듣지 않는다** (골편·뼈 창 투사체, 독안개, 저주는 몬스터 목록만 검사). 평타·폭쇄·뼈 폭풍 등만 맞는다 | 높음 |
| R3 | 결투 UI 없음 (카운트다운·상대 표시·항복·시간 제한) | 중간 |
| R4 | 거래 창이 글자 목록 수준 — **상대 물건의 옵션(접사·소켓)을 볼 수 없다**, 아이콘·등급 테두리 없음, 골드는 ±100 단추뿐 | 높음 (사기 위험) |
| R5 | 상대가 내용을 바꾼 직후 확인이 눌리는 「바꿔치기」 방어 없음 | 중간 |

방안:
- **P1 군단 결투** (R1·R2·R3): 적대 판정을 `_Util:IsHostile(a, b)` 하나로 모아 소환수(주인 기준)·투사체·장판·저주에 모두 적용, 결투 시작 3초 카운트다운·상대 이름 빨간색·항복 단추·120초 제한. 비용 2~3일, 위험: 몬스터 전용으로 짠 AI 탐색 경로를 건드려 PvE 회귀 가능 → 결투 중일 때만 분기.
- **P2 플레이어끼리만 결투 유지** (지금 + R3만): 소환수는 결투 중 대기. 비용 반나절. 「잡으면 내편」다운 맛은 약하다.
- **T1 거래 창 다시 만들기** (R4·R5): 소지품 창 칸 모양 재사용(아이콘·등급 테두리), 상대 칸 눌러 상세 보기, 골드 입력칸·+1천/+1만, 확인 2단계(잠금 → 최종)와 내용 변경 시 3초 대기. 비용 1~1.5일.

## 10-23 출시 전 최종 점검 반영

- **결투 패배 (사용자 결정):** 「귀」는 10-13에 이미 없앴다. 이제 진 쪽은 일반 사망처럼 시체(착용 장비)를 남기고 소환수가 무너지며 **마을에서 부활**한다. 경험치는 잃지 않고, 가진 골드의 `duelGoldDropPct`(20)%를 쓰러진 자리에 떨군다 — 이긴 사람만 줍는다 (`PlayerVitals.DropDuelGold`). 예전의 「제자리 체력 가득 부활 + 군단 유지」는 보스전 무료 부활 악용(감사 D1)이 되어 없앴다.
- **결투 시작 3초 유예**(`PlayerDuel.GraceSeconds`), 시작 알림에 규칙 안내, 마을로 가면 결투 종료, 나갈 때 타이머 정리.
- **거래 바꿔치기 방지 (R5, 감사 T1 P0):** 상대 제안이 바뀔 때마다 `TheirRevision`이 오른다. 확인은 내가 본 판(`RequestConfirm(seenRevision)`)이 지금 판과 같을 때만, 그리고 상대가 바꾼 뒤 3초가 지나야 받는다. 거래창에 「상대가 방금 내용을 바꿨다」를 붉게 띄운다. 상대 일치 검사(T6)도 넣었다.
- **남은 것 (출시 뒤):** 소환수끼리·소환수→상대 플레이어 피해(R1), 투사체·독안개·저주·흡수의 플레이어 적중(R2), 결투 포기 단추·상대 이름 색(R3), 상대 물건 상세 보기(R4), PvP 방어력·뼈 갑옷 적용, 골드 ±1천 단추. 메이커 가상 플레이어가 접속되지 않아 두 사람 실전 확인은 아직이다.
