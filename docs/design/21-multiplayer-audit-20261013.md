# 21. 다인원 동시 플레이 점검 (2026-10-13) — 채널당 4명 × 5채널 가정

> [확인] = 코드 근거, [추정] = 계산·판단. 경로는 `RootDesk/MyDesk/` 기준.

## 1. 지금 구조 [확인]

| 항목 | 동작 |
|---|---|
| 채널 | 채널 = 월드 인스턴스 하나, 4명 상한 (`channelMaxPlayers=4`). 꽉 찬 채널로는 이동 불가 (`Social/ChannelSystem.mlua`) |
| 맵 공유 | 심도 던전·캐릭터 선택 방만 개인/파티 인스턴스. **나머지 모든 맵(곁가지·보스 방·제단 포함)은 채널 안 4명이 공유** |
| 난이도 | 보통·악몽·지옥은 서로 다른 맵 — 같은 채널이라도 몬스터를 공유하지 않음 |
| 보스 재등장 | 고정 보스(여왕·문지기 형제·대사제·제독)·곁가지 끝방 보스·피의 사제 모두 쓰러지면 **300초 뒤** 다시 나옴 (`bossRespawnSec`). 「이미 잡았는지」 개인 확인은 없음 |
| 보상 | 한 대라도 때린 사람마다 각자 드롭·경험치·혼 (`Progress/RewardSystem.mlua`) — 남의 혼은 추출 불가 (서버에서 소유자 확인) |
| 저장 | 120초 자동 저장 + 이동·종료 전 저장 — 20명 부담 없음 |

퀘스트 진행 인정 범위 (`Quest/QuestSystem.mlua`):

| 종류 | 인정받는 사람 |
|---|---|
| kill (액트 보스 4종 포함) | **피해를 준 사람** + 근처(12칸) 파티원 |
| boss·ritual (곁가지 보스·피의 사제) | **맵 안 전원** + 어디 있든 파티원 |
| clear (굶주린 굴 등) | 정리 순간 맵 안 전원 + 파티원 |
| chest | 열쇠 = 맵 전원+파티 / 여는 것 = 연 사람+파티 (상자는 사람마다 따로 열림) |
| extract | 추출한 사람만 |

## 2. 문제 — 4명이 한 채널을 쓸 때

| # | 상황 (예시) | 심각도 |
|---|---|---|
| P1 | **정리 퀘스트 멈춤**: A가 굶주린 굴을 다 잡은 뒤 B가 들어옴 → B 화면엔 「남은 0」인데 완료가 안 됨. 맵이 다시 차려면 **안에 아무도 없어야** 함 → A가 남아 있으면 B는 무한 대기 | 높음 |
| P2 | **늦게 온 사람 300초 대기**: A가 대사제를 잡고 10초 뒤 B 도착 → 약 5분 기다려야 함. 피의 제단도 같음 (D2라면 새 방을 여는 상황) | 높음 (사용자 지적) |
| P3 | **같은 방에 있어도 액트 보스는 때린 사람만**: B가 성소에 서 있었어도 한 대도 안 때렸으면 퀘스트 인정 안 됨 → 5분 대기. 곁가지 보스는 맵 전원 인정이라 규칙이 엇갈림 | 중간 |
| P4 | **파티가 손해**: 파티 4명이면 처치 경험치 합계 2.05배를 나눠 **1인 약 51%**. 파티 없이 같이 때리면 각자 100% → 파티를 안 맺는 게 이득 | 높음 |
| P5 | **인원수 보정 없음**: 4명이 같이 때리면 4배 빨리 잡고, 드롭·경험치는 각자 100% → 보스(특히 이번 W2 벽)가 4명에겐 벽이 아님 | 중간~높음 |
| P6 | **파티원 퀘스트 대행**: 파티원이 마을에 있어도 곁가지 보스·의식·정리·열쇠가 인정됨 (의도된 설계라는 주석 있음) | 중간 |
| P7 | **난이도 열림·랭킹 무임승차**: 제독이 쓰러질 때 맵 안 전원이 다음 난이도가 열리고 랭킹 기록. 파티 귀환 포털에 액트 해금 확인이 없어 액트 1 캐릭터도 따라 들어갈 수 있음 | 중간 |
| P8 | 보스 체력이 맵이 비어도 안 돌아옴 — 남이 10%까지 깎아 둔 보스를 막타만 치고 인정받을 수 있음 | 낮음 |

## 3. 방안

### 보스·제단 (P2·P3)

| 방안 | 무엇 | 장점 | 위험 | 비용 [추정] |
|---|---|---|---|---|
| M1 공유 유지 + 대기 단축 | 액트 보스도 맵 전원 인정(곁가지와 통일) + 보스가 죽어 있을 때 **그 퀘스트가 남은 사람이 맵에 오면 재등장 300초 → 30~60초** | 코드 작음, 「같이 잡는」 MMO 느낌 유지 | 파밍 목적으로 퀘스트를 일부러 안 깨고 반복하는 사람 | 반나절 |
| M2 보스 방 개인/파티 인스턴스 | 성소·폭풍의 눈·여왕 무덤·사원 2층·피의 제단을 파티별 방으로 (심도 던전 방식 재사용) | D2와 같음 — 늘 내 보스, 대기 없음 | 방 생성·복귀 경로·연결 끊김 처리, 인스턴스 방 수 제한 확인 필요 | 2~3일 |
| M3 퀘스트 보스만 개인 판정 | 보스는 공유, 퀘스트가 남은 사람에게 「그 순간 맵에 있었으면 인정」 + 늦게 온 사람용 짧은 재등장 | M1과 비슷, 규칙이 단순 | M1과 같음 | 반나절 |

### 정리 퀘스트 (P1)

| 방안 | 무엇 | 장점 | 위험 |
|---|---|---|---|
| C1 정리된 맵에 들어오면 인정 | 이미 「정리됨」 상태인 맵에 퀘스트 가진 사람이 들어오면 완료 | 가장 단순, 막힘 없음 | 남이 정리한 걸로 쉽게 깸 (튜토리얼 1번 의뢰라 큰 문제 아님) |
| C2 퀘스트 가진 사람이 오면 다시 채움 | 맵에 들어와도 다시 몬스터를 채워 그 사람이 정리 | 직접 해야 함 | 이미 있던 사람에게 몬스터가 갑자기 생김 |

### 파티·인원 (P4·P5)

| 방안 | 무엇 | 효과 |
|---|---|---|
| X1 파티 경험치 = 각자 100% + 보너스 | 파티원 각자 (1 + 0.1 × (인원−1)) 배 | 파티가 늘 이득 |
| X2 인원수 보정 (D2 「players X」) | 맵 안 인원 1명당 몬스터 생명 +50%, 경험치·드롭도 소폭 + | 4명이 와도 보스가 벽으로 남음, 함께할수록 보상 |
| X3 둘 다 | — | 권장 조합 |

### 무임승차 (P6·P7·P8)
- 난이도 열림·랭킹은 「제독 퀘스트 진행 중 + 기여」일 때만, 귀환 포털에 액트 해금 확인 추가 (1~2시간)
- 파티원 원격 인정은 같은 맵 또는 근처로 좁히기 (선택)
- 맵이 비면 보스 체력·기여자 초기화 (1시간)

## 4. 제 판단 (결정은 사용자)
- 출시 전 꼭: **P1(C1), P4(X1), P7** — 막힘·역보상·무임승차라 플레이어가 바로 불만을 느낌. 작업은 합쳐 반나절~하루.
- P2·P3: **M1/M3로 먼저** 대기를 줄이고, 동접이 실제로 늘면 M2(인스턴스)로. 20명·5채널이면 같은 보스를 동시에 노리는 경우가 채널당 드물어 M1로 충분할 가능성이 큼 [추정].
- P5(X2)는 이번 W2(보스 벽)와 맞물림 — 넣지 않으면 파티로 오면 벽이 사라진다.

밸런스 [추정, 60~70% 빌드 · 맵 한 판 = 이동 약 절반 + 전투 약 절반]:

| 함께 하는 방식 | 전투 시간 | 처치당 경험치 | 1인 시간당 경험치 (혼자 = 1) |
|---|---|---|---|
| 혼자 | 1 | 1 | 1 |
| 파티 아닌 4명이 같은 맵 | 2.5/4 = 0.63 | 1.15 | 약 1.4 |
| 파티 2명 | 1.5/2 = 0.75 | 1.05 × 1.1 = 1.16 | 약 1.3 |
| 파티 4명 | 0.63 | 1.15 × 1.3 = 1.5 | 약 1.8 |

- 파티가 늘 이득 (예전: 4명 파티 1인 51%).
- 보스 벽(W2)은 4명이면 생명 2.5배라 「4배 빨리 녹는」 일이 없다 — 4명 기준 보스전 시간은 혼자의 약 0.63배.

메이커 확인: 인원 보정 적용·복귀(4명 강제 → 다음 틱 1명), 맵이 10초 비면 보스 생명 42,900 회복·기여자 초기화, 의뢰 남은 사람이 있을 때 대사제 재등장 남은 시간 300초 → 43초(미니맵 머리글 「0:16」 표시). 여러 클라이언트가 필요한 파티 경험치·4명 실제 플레이는 메이커 한 명으로는 확인하지 못했다.
