# 25. 첫 1시간 점검 (2026-10-20)

새 캐릭터(4번 칸)를 만들어 메이커에서 실제 입력으로 진행했다. 키보드와 마우스를 쓰고, 화면 단추는 클릭 이벤트로 눌렀다. 처음 약 5분(캐릭터 만들기 → 마을 → 첫 의뢰 → 첫 사냥터 → 첫 전투)을 지켜보고 막히는 곳을 적었다. 테스트 플레이 기록 장치(Telemetry)가 같은 세션을 기록했다.

## 고친 것 (메이커 확인)

| 문제 | 원인 | 수정 |
|---|---|---|
| 스킬 창 오른쪽에 「해골 전사」 설명이 떠 있는데 「습득」을 눌러도 아무 일이 없다 | 카드를 따로 누르기 전에는 「고른 스킬」이 비어 있어 버튼이 무시됐다 | 고른 것이 없으면 오른쪽에 보이는 스킬을 배운다 (`SkillWindow.Act`) |
| 사냥터에 들어가자마자 1초 만에 마을로 되돌아간다 | 도착 지점이 귀환 포털에서 2칸이라, 이동키를 누른 채 들어오면 바로 포털에 들어갔다 | 맵에 들어온 뒤 2.5초 동안 포털이 반응하지 않는다 (`PlayerTravel.ArrivedAt` · `WarpGate.ArrivalGrace`) |
| Lv1인데 미니맵에 「심도」 보라 점이 보인다 | 잠긴 심도 문은 숨겨지는데, 그러면 맵 표의 고정 표식이 대신 그려졌다 | 숨긴 문도 「문이 있다」로 쳐서 고정 표식을 건너뛴다 (`HudMap.MapFeatures`) |

## 정해야 할 것 (보고만, 아직 안 고침)

| # | 관찰 | 근거 | 방안 |
|---|---|---|---|
| 1 | 첫 전투 약 10초 만에 사망. 세션 시작 4.8분, Lv1 | 기록: `[TEL] death lv=1 map=map01 cause=잿불 들개 min=4.8`. 맨몸(장비 0)에 기본 공격과 스킬 1개뿐인데 들개 3마리(Lv1~2) 무리를 만났다. 물약 3개가 있었지만 쓰지 않았다(신규 이용자는 1번 키를 모른다) | 몬스터 수치는 그대로 두고(10-08 결정) 아래 중에서 고른다. (a) 시작 장비 지급(낫·로브). (b) 첫 사냥터 출구 쪽 첫 무리는 1~2마리. (c) 생명 30% 아래로 처음 떨어지면 「1번 키 = 물약」 안내 |
| 2 | 처음 조작하기까지 글이 13장 | 이야기 카드 5장 + 오렌 대사 8장 → 의뢰 수락 | 오렌 대사를 3~4장으로 줄이고, 나머지는 의뢰 일지(Q)로 옮긴다. 또는 「건너뛰기」를 둔다 |
| 3 | 설정이 서로 어긋난다 | 오프닝은 「망자를 부리지 않고, 혼을 등불에 거두는 자」라고 하는데 첫 스킬이 「해골 전사를 일으킨다」 | 오프닝 문장을 「망자를 노예로 부리던 교단과 달리, 혼을 거두어 함께 싸운다」 정도로 고친다 |
| 4 | Lv1 스킬 창에 잠긴 카드가 대부분이다 | 소환 탭 9장 중 8장 잠김(Lv5~45) | 지금 레벨 +10 밖의 카드는 흐리게 접고 「Lv20 이후 스킬 6개」 한 줄로 묶는다 |
| 5 | 아직 못 쓰는 메뉴가 보인다 | Lv1에 「그림자」·「그림자 추출(E)」 버튼이 보이는데 Lv5에 열린다 | 열리기 전엔 자물쇠 표시와 「Lv5」 안내 |
| 6 | 대화·이야기 카드가 스페이스 입력을 가끔 놓친다 | 메이커 입력 도구로 0.6초 간격으로 눌렀을 때 절반쯤 무시됐다. 1초 간격은 모두 먹혔다. 입력 도구 탓일 수 있다 | 실기기·실제 키보드로 다시 확인한다 |
| 7 | 이야기 카드 뒤로 HUD가 비친다 | 카드 가운데로 캐릭터와 NPC 이름이 흐리게 보인다 | 카드 배경 불투명도를 올린다 |

## 기록 장치로 볼 것 (다음 점검부터)

- 레벨별 걸린 분, 사망 원인 상위, 시간당 처치와 전리품.
- 메이커 서버 스크립트에서 `_Telemetry:Dump(50)`을 부른다.
- 같은 캐릭터로 Lv1~10을 끝까지 하면 「Lv5 그림자 해금까지 몇 분」과 「첫 의뢰 완료까지 몇 분」이 숫자로 나온다.
