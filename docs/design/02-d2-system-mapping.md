# D2 시스템 대응표

디아블로2의 시스템을 하나씩 우리 게임에 어떻게 옮길지 정리했다. D2 수치는 기억에 기반한 **참고용**이며 공식 자료로 검증한 값이 아니다. 우리 수치는 각 문서에서 [가정]으로 표시하고 플레이 테스트로 조정한다.

판정: **채택**(그대로) / **변형**(목적 유지, 구현 변경) / **제외**

| 7개 직업 | 변형 | 6개 원형 정의, **네크로맨서 1개 먼저 완성**, 나머지는 후속 | 04 |

## 7. 이 표에서 얻는 요약

- **채택**: 그대로 구현하면 되는 설계 자산
- **변형**: 시점·입력·플랫폼 때문에 구현만 바꿈
- **제외**: 감정, 스태미나, 용병, 하드코어, 격자 인벤토리

항목별 분류는 위 표가 기준이다. (비율은 집계하지 않았다.)

변형 항목 중 **격자 인벤토리**, **랜덤 맵**, **명중 판정**은 설계 영향이 커서 12장 "결정 필요 목록"에 올렸다.
