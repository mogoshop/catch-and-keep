3. **중복 0 · 칸 넘침 0.** ③은 「효과 범위 증가」가 6번 나와 추천 카드·노드 칸에서 구분이 안 되고, 대응 보조가 없는 줄이 22개다.
4. ★는 ②보다 효과가 분명히 같은 실존 이름이 따로 있는 줄만 바꿨다 — `skeleton_mastery` 해골 숙련 · `mage_curse` 사술 손길 · `giant_mage_resist` 인화성 · `shard_multi` 효과 집중. ★를 쓰지 않고 ② 순수안으로 가도 된다(§3 메모에 ② 이름).

②의 약점(정직하게): ○ 대응 18줄은 이름 뜻은 맞지만 D3 원래 효과는 다르다(예: 「파문」은 D3에서 밀침·둔화, 우리는 평타로 해골을 쳐서 충격파). 설명 첫 줄이 계속 중요하다. 또 「주인님을 위해」 · 「힘세고 강한 돌진」처럼 말투가 가벼운 룬이 있다 — 바꾸고 싶으면 §3 후보 2·3번이 대안.
