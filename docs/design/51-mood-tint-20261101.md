# 51 · 장면 분위기 색 (mood tint) — 조사와 안 (2026-11-01)

> 사용자 제안 (11-01): 「액트 4에서 오렌의 죽음 이후 배경이 빨개진다. 영화가 특정 러닝타임이나 장면 분위기를 살리려고 옅은 초록·새벽의 옅은 파랑을 쓰듯, 모든 맵은 아니어도 특정 맵 군데군데 옅은 배경색을 줘서 분위기를 살리는 요소로 쓰면 어떨까.」
>
> 이 문서는 조사와 안이다. 게임 코드·맵·UI는 바꾸지 않았고, 메이커도 쓰지 않았다. 미리보기 4장은 메이커 캡처 위에 근사 합성한 그림이다(§6). 실제 게임 화면이 아니다.

## §1 지금 구조 — 「오렌 처치 뒤 붉어짐」은 전체 조명(Global overlay light)의 색이다

### 1-1 붉어짐의 정체

## §3 맵별 색 안 (세 가지)

색 적용식(공통): `전체 조명 색 = 기존색 × (1 − sG) + 틴트 × sG`, `내 주변 빛 색 = (1,0.92,0.8) × (1 − sP) + 틴트 × sP`. 「알파」는 섞는 비율 sG/sP다. 기존색은 액트 1~3이 푸른 밤빛 (0.55,0.6,0.85), 액트 4가 (0.9,0.5,0.4), 해방 뒤가 (1,0.97,0.92)다. 심연(depth 12장)은 모든 안에서 제외한다(전용 보랏빛 유지). 액트 4의 각성 핏빛은 모든 안에서 **최우선으로 그대로 둔다**.

이야기 국면 기준 (`story.csv`·`quests.csv`): 프롤로그(잿불 야영지) → 액트 1 사냥(의뢰 1~5) → 여왕의 무덤(6) → 해방 「처음으로 고요한 밤」 → 액트 2 → 대사제의 성소(12) → 「백 년 만에 비」 → 액트 3 → 폭풍의 눈(18) → 「등대에 불」 → 액트 4 행군(19~22) → **배교자의 수도원 · 오렌(23)** → 붉은 하늘(`r`) → 옥좌(24) → 「그림자가 돌아왔다」(`4`) → 심연.

- **특징**: 전체 66장 중 7장(6곳)이다. 늘 보는 맵은 그대로 두고, 이야기가 꺾이는 방만 색이 다르다. A5 → 각성 핏빛은 「색이 빠졌다가 → 피가 도는」 대비다 (미리보기 ②).
- **예상 효과**: 플레이어가 「이 방은 다르다」를 색으로 먼저 느낀다. 보스 방 입장에 의식 같은 느낌이 생기고, 붉은 하늘의 충격이 커진다. 홍보 스크린샷에서 액트마다 「결정적 장면」 한 장씩을 고르기 쉬워진다.
- **위험**: 보스 방은 원래 밝기 0.07 → 하한 0.24로 어둡다. 그래서 틴트는 가장자리 어둠에서 주로 보이고, 내 빛 안쪽은 옅다(sP로 보완). A1은 첫 15분 화면이라 첫인상 톤이 바뀐다 → 사용자 승인 대상. 파티원끼리 이야기 단계가 다르면 같은 방 색이 다르다 (붉은 하늘과 같은 성질).

## §4 추천과 근거

**안 A를 먼저 하고, 메이커 확인 뒤 안 C의 던전 몫을 덧붙일지 정한다. 안 B는 지금은 비추천이다.**

1. **사용자 의도와 가장 가깝다.** 「모든 맵은 아니어도 특정 맵 군데군데」, 「특정 러닝타임·장면」은 이야기 국면에 색을 거는 안 A다. 영화의 색 보정도 장면 전환에서만 바뀌어야 눈에 띈다.
2. **이미 있는 붉은 하늘을 살린다.** A5(잿빛) → 핏빛 대비는 지금 연출에 「앞 장면」을 붙이는 것이다. 새 체계가 아니라 연장이다.
3. **액트 정체성을 지킨다.** 메모(액트 3 = 얕은 바다, 갈색 사막 액트 1·2)와 안 B는 충돌한다. 미리보기 ④가 근거다.
4. **비용·위험이 가장 작다.** 맵 7장, 표 7행, 스크립트 약 60줄이다. 맵 재빌드·UI 수정·새 셰이더가 없다.
5. **안 C로 넓힐 수 있게** 표 구조를 처음부터 「맵 + 조건 + 색 + 두 비율」로 만든다(§5). 안 A 반영 뒤 행만 더하면 안 C가 된다.

먼저 확인할 것 (메이커 1회차): ① 해방 뒤 밝은 맵(예: wasteland 0.82)과 어두운 맵(apostate 0.24)에서 같은 틴트가 보이는지 확인한다(clamp 여부). ② 이름표·피해 숫자·운석 예고 원 색이 그대로인지 본다. ③ iPad 레이아웃에서 화면 톤을 본다.
