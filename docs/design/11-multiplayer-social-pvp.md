# 멀티플레이·소셜·PvP

## 1. 기본 방침

D2는 멀티플레이 파티 사냥이 핵심이다. MSW는 접속 방 구조 자체가 멀티이므로 **파티 사냥은 P2에서 구현**하되, P0~P1부터 서버 구조를 멀티 전제로 짠다. (싱글 전용으로 만들면 나중에 전부 고쳐야 한다.)

## 2. 파티

| 항목 | 내용 | 단계 |
| --- | --- | --- |
| 인원 | 최대 4 | P2 |
| 경험치 | 처치 기여 + 근접 시 분배, 인원 보너스 | P2 |
| 드롭 | 개인 전리품 (05장) | P1 |
| 몬스터 보정 | 인원당 체력 +50% (06장) | P2 |
| 파티 UI | 구성원 체력·그림자 수 표시 | P2 |

## 3. 소환수와 멀티플레이

- 맵 최대 소환수 = 8 × 4 = 32 (10장 부하 기준).
- 타 플레이어 소환수는 서로 **충돌·피해 없음**, 아군 판정만 한다.
- 소환수 표시 크기·시야 혼잡: 타 플레이어 소환수는 **반투명 또는 간략 이펙트**로 줄이는 옵션 [검토].

## 5. PvP

| 항목 | 내용 |
| --- | --- |
| 도입 시점 | **P3 이후, 선택**. 밸런스 비용이 크다 |
| 방식 | 전용 결투 맵 (D2의 적대 선언 방식은 제외) |
| 소환수 | 배치 한도 PvP 5 (룬 v0.2 StatCaps) |
| 저주·상태이상 | PvP에서 지속시간 50% (D2 방식) |
| 룬워드 | PvP 전용 보정 계수 적용 [검토] |
| 보상 | 칭호·외형 위주 (경제 영향 최소) |

PvP는 이 게임의 최대 밸런스 위험이다 (소환수 32 vs 소환수 32는 서버 부하 위험). **출시 범위에서 제외하는 선택지**를 12장 결정 목록에 올려 둔다.
