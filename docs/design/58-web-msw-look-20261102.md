## 1. 토큰 (site.css `:root` 전면 교체 · 다크 모드는 두지 않음)
- 바탕 `--bg #FFFFFF` · 면 `--surface #F6F7F9` · 면2 `--surface-2 #EEF0F3` · 선 `--line #E3E6EA` · 글 `--ink #1C2024` · 글2 `--ink-2 #5B636B` · 글3 `--ink-3 #8A9299`
- 강조 `--accent #B8862B`(호버 `#9E7222`) · 보조 `--violet #6A4FB6` · 상태 `--ok #2F8F5B` `--warn #C98A12` `--muted #8A9299`
- 어두운 그림 받침(게임 캡처·아이콘 뒤) `--plate #15171A` — 스킬 아이콘·핫바 미리보기처럼 **게임 안 모습을 보여 줄 때만** 어두운 받침을 깐다
- 모서리: 카드 16 · 칩 999 · 단추 10 · 작은 칸 8. 그림자: 카드 호버에만 `0 6px 20px rgba(20,24,30,.08)`
- 글꼴 Pretendard(이미 자체 호스팅): 본문 15/1.6 · 메타 13 · 제목 h1 32/800 · h2 22/700 · 카드 제목 16/600
- 간격: **게임 규격 이식** — `tools/build/ui-tokens.cjs`의 SPACE 12 · gap 16 · INNER.pad 24를 웹 간격 단위로 그대로(12/16/24, 큰 묶음 40). 누르는 것 최소 44px(게임 88px의 절반 규칙).

## 2. 카드·면 정리 (지금 「surface 카드 + 골드 아이콘」 느낌 제거)
- 홈 입구 카드 3장: 골드 아이콘 박스 → **실제 그림 썸네일**(스킬 = 핫바 아이콘 6개를 어두운 받침에 나란히, 맵 = 황무지 캡처, 규칙 = 규칙 상세 중 한 장의 일러스트 없음 → 글머리 카드) + 제목 + 메타. 카드 안 「보기 ›」 글 링크는 빼고 카드 전체가 링크.
- 모든 목록 카드 = MSW 카드 틀(16:9 그림 · 아래 제목·메타). 맵 카드 메타 = 「액트 1 · 사냥터 · 70×50」. 스킬 상세 카드 메타 = 「기본 스킬 · Lv 24」.
- 배지(변경됨·신규·삭제됨·연결 상태)는 작은 알약, 색은 상태색만. 금색 배지 남발 금지(금색 = 선택·활성 하나뿐).
- 「스냅샷 11.02」 같은 출처·커밋·생성 시각은 **페이지 푸터 한 줄**로. 본문 위에 두지 않는다.

## 3. 필터 계층 (사용자 스크린샷의 효과 고르기가 기준 사례 — 다른 화면도 같은 3층)
| 층 | 무엇 | 모양 |
|---|---|---|
| 1 | 화면 선택 | 2차 내비 탭(하위 경로: 대조표·효과·거인·아이콘·효과 고르기) — 지금 그대로, 밝은 틀에 맞춰 밑줄 탭 |
| 2 | **한 줄 도구 막대**: 검색 + 분류 칩(현재 사용 중 74 · FX 261 · 메이플 추천 424 · 추천 장면 83 · 자리별 비교) + 오른쪽 끝 「필터 (n)」 단추 | 칩은 알약, 선택 1개. 한 줄 넘치면 가로 스크롤 |
| 3 | **필터 서랍**(「필터」 누르면 오른쪽에서 열림): 분류(83곳) · 바탕 맵 · 후보 크기 · 좌우 반전 · 가까이 보기 | 적용한 필터는 막대 아래 **지울 수 있는 칩**으로 표시. 기본값은 칩 없음 |
| 재생 | 전체 일시정지 · 속도 · 배경 | 오른쪽 아래 **고정 작은 묶음**(둥근 알약 3개). 도구 막대에서 뺀다 |
| 안내 | 「카드 아래 단추로 자리마다 하나를 고르고…」 「자리 기준: 게임 정본 bf54f7f0…」 「장면 보기 · 웹 합성(근사)…」 | 막대 오른쪽 ⓘ 팝오버 1개(사용법) + 페이지 푸터(출처·기준 커밋). 본문에서 제거 |
| 선택 결과 | 「선택 내보내기」「후보 남기기」 | 오른쪽 상세 영역 상단 고정 단추 2개 |
- 효과 고르기·효과 탭은 **분할 화면**: 왼쪽 320px 자리 목록(이름·현재 썸네일·선택 표시 점), 오른쪽 고른 자리의 후보들(현재/FX/메이플/추천 장면 순). 모바일에선 목록 → 상세 두 화면으로.
- 대조표·아이콘·맵·규칙도 같은 3층(탭 → 한 줄 막대 → 서랍). 서랍이 비는 화면은 「필터」 단추를 아예 두지 않는다.

## 4. 게임 UI 규격·그림 이식
- 간격·누르는 크기·글 규칙은 §1. 글귀 규칙 = `docs/ui/message-rules.md`·10-29 글귀 규칙(짧은 명사형 라벨 · 시스템 안내는 -해주세요 · 변경 해명 금지).
- **게임 그림을 웹 장식으로**(ui_icons.csv의 RUID): `sk_portrait_frame`(스킬 상세 카드 아이콘 테) · `sk_ws_node_frame_empty/learned`(노드 아이콘 테 — 도감의 44px 노드도 게임과 같은 테 안에) · `slot_frame`(핫바 미리보기 칸) · `btn_frame`(홈 CTA 단추 1곳만) · `win_paper`(규칙 상세 본문 배경 질감, 아주 연하게). PNG 확보는 msw-mcp `asset_get_group_thumbnail`/그룹 리소스 메타(OJYYQ) 또는 `tools/msw_mcp_call.cjs` 경로로 내려받아 `public/img/ui/`에(소스 커밋 가능 크기). 못 받으면 CSS 테두리로 대신하고 보고.
- 이 그림들은 **게임 요소를 보여 주는 자리에만**. 사이트 내비·푸터·일반 카드에는 쓰지 않는다(그래야 포털 느낌이 유지됨).

## 5. 영상·썸네일·로고
- 홈: 히어로를 **키 아트 썸네일 + 영상**으로. 왼쪽 큰 그림(`assets/codex-release-thumbnails-v8/exports/01-campfire-companions-1280x720.jpg` 기본, 4장 점 넘김), 오른쪽 또는 아래 「플레이 영상」 — YouTube `_tM92ViIeNw` **클릭하면 로드되는 가벼운 임베드**(썸네일 i.ytimg + 재생 단추, iframe은 클릭 뒤). 자동 재생 없음.
- 홈 중간 「특징」 4칸 = `assets/codex-promo-subimages-v3/exports/`의 1 네크로맨서 · 2 군단 전투 · 3 전리품과 파티(v2) · 4 이야기. 각 칸 = 그림(16:9) + 제목 한 줄 + 설명 두 줄(기획 문서의 실제 문장, 과장 금지).
- OG 기본 이미지 = 01 썸네일. 맵·스킬 상세는 각자 그림 유지.
- **로고**: 그림 로고 파일이 저장소에 없다. 이번엔 **글자 로고**(Pretendard 800 「메이플 리저렉션」 + 아래 11px 「MAPLE RESURRECTION」)로 통일하고 파비콘은 「리」 한 글자 SVG. 그림 로고는 코덱스에 별도 요청(이 레인 범위 밖, 보고에 적기).
- 그림은 `public/img/`에 webp로(각 300KB 이하, 히어로 1600 · 특징 960 · OG 1200×630). 원본 jpg·png는 그대로 두고 복사만.
