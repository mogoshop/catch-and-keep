# 몬스터 & 보스

## 1. 몬스터 등급 (D2 5등급 유지)

| 등급 | 표시 | 설명 | 그림자 추출 | 드롭 |
| --- | --- | --- | --- | --- |
| 일반 | 이름 흰색 | 무리로 등장 | 15% (등급 1) | 기본 |
| 정예 | 파랑 이름 | 수식어 1~2개, 체력 증가 | 8% (등급 2) | 증가 |
| 무리 우두머리 | 금색 이름 | 수식어 2~3개 + 부하 | 8% (등급 2) | 높음 |
| 최상위 | 보라 이름 | 특정 장소에 고정, 고유 이름 | 5% (등급 2) | 높음 + 고정 보상 |
| 보스 | 별도 | 영역 마지막, 특수 패턴 | 100% 1회 (등급 3) | 확정 룬 |

Phase 0 추출 확률(`docs/phase0-core-loop-design.md`)과 맞췄다. 최상위의 추출 5%는 **[추가 가정]**.

## 2. 몬스터 능력치 규칙

| 항목 | 규칙 [가정] |
| --- | --- |
| 몬스터 레벨 | 영역 기본 레벨 + 난이도 보정 |
| 체력 | `baseHp × levelCurve(level) × 등급 배율` (정예 ×3, 우두머리 ×4, 최상위 ×6) |
| 공격 | 속성(물리/마법/속성)과 레벨에 따른 기본 피해 |
| 저항 | 몬스터 종류별 기본 저항 + 난이도 보정 |
| 파티 보정 | 파티 인원 1명 추가마다 체력 +50% (D2 방식 단순화) |

수치는 데이터 테이블에 둔다 (10장). 영역별 몬스터 5~8종이 목표.

## 3. 몬스터 수식어 (12종으로 시작)

| 수식어 | 효과 | 위험도 |
| --- | --- | --- |
| 강화 | 피해 +50% | 보통 |
| 신속 | 이동 속도 +40% | 보통 |
| 강인 | 체력 +100% | 보통 |
| 불꽃 인챈트 | 공격에 화염 피해 추가, 화염 면역 대신 저항 | 높음 |
| 냉기 인챈트 | 공격에 냉기 + 둔화 | 보통 |
| 번개 인챈트 | 공격에 번개, 연쇄 | 높음 |
| 흡혈 | 피해 일부를 체력으로 | 보통 |
| 다중 사격 | 원거리 몬스터의 투사체 수 증가 | 보통 |
| 순간 이동 | 플레이어 근처로 이동 | 높음 |
| 시체 폭발 | 사망 시 시체가 폭발 (그림자 추출 재료 손실) | 네크로 대응 |
| 반사 | 피해 일부 반사 | 높음 (소환수 위험) |
| 저항 면역 | 한 속성 면역 | 높음 |

### 면역 정책
- 면역은 **수식어로만** 발생한다. 일반 몬스터는 면역 없음.
- 면역 몬스터가 일정 비율을 넘지 않게 한다. (초기 [가정]: 정예 이상의 15%)
- 네크로맨서에게는 **저주 「저항 붕괴」** 와 **룬 `녹스`·`아비스`** 가 면역 대응 수단이 된다. 대응 수단이 없는 직업이 막히는 상황을 막는 장치다. (D2의 가장 큰 불만점 중 하나)

## 4. 몬스터 AI 유형

| 유형 | 행동 | 사용 예 |
| --- | --- | --- |
| 근접 추적 | 가까운 플레이어 추적 후 공격 | 기본 졸개 |
| 원거리 카이팅 | 거리 유지하며 사격 | 궁수 계열 |
| 순찰 | 정해진 구간을 돌다 발견 시 추적 | 문지기 |
| 매복 | 땅·벽에서 갑자기 등장 | 함정형 |
| 소환형 | 일정 주기 부하 소환 | 주술사 |
| 자폭 | 접근 후 폭발 | 후반 특수 |
| 지원형 | 아군 회복·버프 | 정예 부대 |
| 비행 | 발판 무시 이동 | 일부 |

2D 횡스크롤이므로 **발판 상의 이동**이 핵심 제약이다. 비행 몬스터를 제외한 모든 몬스터는 발판 경계에서 떨어지지 않도록 처리해야 한다. 이 처리를 기본 AI 컴포넌트가 해주는지는 **미확인**.

AI 탐색은 0.3~0.5초 주기 타이머로 한다. (Phase 0 서버 부하 기준)

## 5. 몬스터 패밀리 (영역별 5~8종 목표)

영역 상세는 07장. 패밀리는 영역 테마에 맞는 오리지널 구성이다.

| 영역 | 패밀리 예 (오리지널) |
| --- | --- |
| 1. 잿빛 변경 | 들개, 재투성이 병사, 갈가마귀, 구덩이 벌레 |
| 2. 모래 폐허 | 사막 전갈, 해골 사제, 모래 정령, 묘지기 |
| 3. 늪 숲 | 늪 도마뱀, 독 두꺼비, 덩굴 인간, 안개 유령 |
| 4. 불의 심연 | 화염 박쥐, 용암 거인, 악마 병사, 불길한 사제 |
| 5. 서리 정상 | 빙설 늑대, 얼음 병사, 서리 거인, 얼어붙은 용사 |

종마다 필요한 에셋: 대기·이동·공격·피격·사망 애니메이션 (09장). 같은 베이스를 재채색해 종 수를 늘리는 방식으로 에셋을 절약한다.

## 6. 보스 (영역별, 오리지널)

| 영역 | 보스 | 레벨 | 특수 패턴 | 확정 보상 |
| --- | --- | --- | --- | --- |
| 1 | 묘지기 여왕 | 10 | 부하 소환, 독 분무, 땅 파고 이동 | 하급 룬, 첫 번째 영역 스킬 포인트 |
| 2 | 모래 폐허의 대사제 | 25 | 시체 부활, 저주 시전 (플레이어 저주 중첩) | 중급 룬 |
| 3 | 늪의 어머니 | 40 | 독 지대, 소환 | 중급 룬 + 퀘스트 보상 |
| 4 | 불의 심연의 군주 | 55 | 3단계 변신, 용암 바닥, 불 구체 | 상급 룬 |
| 5 | 정상의 파괴자 | 68 | 전 속성 공격, 부하 파도 | 신화 룬 가능성 |

### 보스 설계 원칙

- **패턴은 3단계 이하** (체력 70%, 35% 전환), 각 단계는 새 행동 1개 추가.
- 처음 보는 공격에는 **예고 연출 1초 이상**. (모바일·지연 고려)
- 보스 전용 면역·내성: 기절·공포·빙결은 지속 감소, 저주는 효과 50% 감소. (D2 보스 방식)
- 보스 그림자는 **1회만 추출**, 데이터에 `bossShadow = true` 로 표시하며 분해 불가. (Phase 0 규칙)
- 영역당 보스 1명으로 시작하고, **우두머리급 최상위 몬스터**가 중간 보스 역할을 한다. 보스 수 5 + 최상위 15 정도가 초기 목표.

## 7. 주간 보스·심층 보스 (P3)

룬 v0.2의 신화 룬 드롭원. 별도 던전(심도)의 최하층에 위치하며 입장 횟수를 주간 제한한다. 서버 부하 기준에 맞춰 파티 인원과 보스 부하를 먼저 검증한 뒤 설계한다.
