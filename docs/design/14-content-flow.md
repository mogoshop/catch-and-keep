### 1.1 (질문 1번) 레벨 범위와 악몽 가산이 왜 같이 움직이나

- 악몽 맵은 보통 맵을 복제하고 몬스터 레벨에 **가산**만 더한다 (지금 +15 → 악몽 황무지 Lv 16~18).
- D2처럼 「보통을 다 깬 레벨 ≈ 악몽 첫 맵 레벨」이어야 악몽 첫 맵이 너무 쉽지도 어렵지도 않다.
- 보통을 끝내면 Lv 21인데 악몽 황무지가 Lv 16이면, 악몽 액트 1 앞부분은 레벨이 5 낮은 몬스터라 경험치도 줄고 지루하다.
- 그래서 **액트 2를 넣을 때 악몽 가산을 +20(지옥 +40)으로 올린다** (악몽 황무지 Lv 21~23, 악몽 여왕 32, 악몽 대사제 41 → 지옥 첫 맵 41~43).
- 지옥까지 깨면 최대 Lv 61 몬스터 — 레벨 상한 80은 심도 던전이 채운다.
- 가산 변경은 `difficulty.csv` + 맵 다시 빌드(맵마다 MapAmbience.LevelBonus에 박혀 있음). **액트 2가 들어갈 때 같이 바꾼다** (지금 바꾸면 악몽 액트 1만 있는 상태에서 Lv 13 → 21로 점프).

### 1.2 (질문 4번) 「영구 보상을 난이도마다」의 뜻

- **보스를 잡을 때마다가 아니다.** 그 의뢰를 **난이도마다 한 번** 완료하면 받는다 (의뢰 진행이 이제 난이도마다 따로이므로).
- 예: 「지하실의 수장」 보상 「그림자 배치 +1」 → 보통에서 한 번, 악몽에서 한 번, 지옥에서 한 번 → **최대 +3**. 같은 난이도에서 보스를 또 잡아도 더 오르지 않는다.
- D2의 아냐 퀘스트(난이도마다 모든 저항 +10, 최대 +30)·스킬 포인트 의뢰와 같은 방식.
- 「한 번만」으로 하면 악몽·지옥에서 같은 의뢰를 다시 해도 영구 보상이 없어 반복 동기가 약해진다 → **난이도마다 (권장)**.

## 2. 의뢰 보상 구조 — 「의뢰마다 대표 보상 하나」

지금은 모든 의뢰가 경험치 + 골드 + 아이템을 한꺼번에 준다 → 보상이 흐려진다. D2처럼 **의뢰마다 기억에 남는 대표 보상 하나**를 주고, 경험치는 일부 의뢰만.

| 보상 유형 | 쓰는 곳 | 비고 |
| --- | --- | --- |
| 스킬 포인트 | 곁가지 던전을 끝까지 정리하는 의뢰 | D2 악의 소굴 |
| 영구 강화 (그림자 배치·저항) | 이름 있는 적 처치 | 난이도마다 1회 |
| 능력치 포인트 | 탐험·의식 | |
| 확정 아이템 (희귀·유니크·룬) | 유물·보물 의뢰 | 수락 전에 미리보기 |
| 경험치 (큼) | 액트 보스 | 액트 끝 보상 |
| 경험치 (작음) | 첫 의뢰(길 안내) | |

- 2·3·5번은 **곁가지 던전 안**에서 끝난다 → 늪·형장·숲 곁가지에 들어갈 이유가 생긴다.
- 4번 제단은 의식 전투로 바꾸고, 끝나면 맵 신전처럼 계속 쓸 수 있게 남긴다.
- 의뢰인 여러 명: 3번은 대장장이. NPC 머리 위 「!」를 의뢰인마다.
- 의뢰 경험치는 **6개 중 3개(1·4·6)** — 첫 의뢰·중간 고비·액트 끝에 한 번씩 몰아 줘서 속도감을 살린다. 합 33,450 → **29,500** (곁가지 사냥이 늘어 레벨은 비슷하게 유지 — 위 시뮬 「곁가지 다 감」 기준 ≈13).
- 악몽·지옥의 의뢰 경험치·골드는 `questRewardMul`(×5 / ×14). 영구 보상(스킬·능력치 포인트·그림자 배치)은 난이도마다 1회.

### 3.1 굶주린 굴 — 다시 나오지 않게 + 파티원과 따로 와도 끝낼 수 있게

문제: 지금 곁가지는 몬스터가 90초마다 다시 나온다 → 「모두 처치」를 끝낼 수 없다. 또 맵은 같은 방의 플레이어가 같이 쓰므로, 파티원이 먼저 굴을 비우면 나중에 온 사람은 잡을 몬스터가 없다.

| 규칙 | 내용 |
| --- | --- |
| **정리 중 리젠 없음** | 굶주린 굴(그리고 의뢰 목표가 「모두 처치」인 곁가지)은 리스폰을 끈다. 남은 수를 의뢰 창·화면에 「남은 망자 n」으로 표시 |
| **남은 위치 표시** | 5마리 이하로 남으면 미니맵에 남은 망자 점을 보여 준다 (구석에 낀 몬스터 때문에 못 끝내는 일 방지) |
| **완료 판정** | 굴이 비는 순간 **굴 안에 있는 모든 플레이어** + **의뢰 1을 진행 중인 같은 파티원(어디에 있든)**이 완료 |
| **다시 채우기** | 굴이 정리된 뒤 **안에 플레이어가 없고**, 의뢰 1을 진행 중인 사람이 **새로 들어오면** 굴을 처음 상태로 다시 채운다. 사람이 없어도 5분 지나면 다시 채운다 (사냥터로도 쓰게) |
| **파티 없이 따로** | 파티가 아닌 다른 플레이어가 먼저 비웠으면 → 그 사람이 나간 뒤 내가 들어올 때 다시 채워진다 (위 규칙). 같은 시간에 둘이 안에 있으면 함께 완료 |

- 같은 규칙을 다른 「모두 처치」 목표(액트 2 이후 `clear` 목표)에도 쓴다.
- 「이름 있는 적」 목표(모르그·유물 지기·피의 사제 등)도 같은 원칙: 처치 순간 맵 안의 모든 플레이어 + 그 의뢰를 진행 중인 파티원 완료, 맵이 비면 다음 진입 때 다시 나온다.

## 4. 곁가지 던전에 들어갈 이유 (모든 액트 공통 규칙)

| 장치 | 내용 |
| --- | --- |
| **끝방 봉인 상자** | 곁가지 던전 마지막 층 끝에 하나. **난이도마다 처음 열 때** 희귀 이상 1 + 룬 1 보장, 이후엔 일반 상자 수준. 미니맵·의뢰 창에 「봉인 상자: 안 열림」 표시 |
| **곁가지 우두머리** | 마지막 층마다 이름 있는 고유 몬스터 + 호위 (액트 1: 모르그·유물 지기 등). 고유 몬스터 그림자는 **고유 오오라**를 가진 정예 그림자 — 곁가지에서만 얻는다 |
| **의뢰 연결** | 액트마다 곁가지 2~3곳이 의뢰 목표 (위 표) |
| **정리 보상** | 곁가지 한 층의 몬스터를 다 잡으면 「층 정리」 알림 + 골드 묶음 (맵 진입마다) |
| **표시** | 의뢰 창 「지역」 탭: 지역별 곁가지 던전 · 봉인 상자 · 우두머리 처치 여부 (난이도별) |

## 5. 액트 1 → 2 연결

- 여왕 처치(의뢰 6) → 잿불 야영지에 **카라반 대장** 등장 → 「오아시스 시장으로」 (난이도마다).
- 액트 2 첫 의뢰는 카라반 대장이 바로 준다 (마을 도착 즉시 할 일).
- 웨이포인트 창은 액트 탭(액트 1 / 액트 2).

## 6. 구현 순서 제안 (액트 2보다 먼저)
