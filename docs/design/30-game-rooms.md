# 30. 게임 방 — 혼자 하기 · 공개 방 · 비공개 방 (2026-10-21)

사용자 결정(10-21): 「싱글플레이 / 비공개 / 공개 맵이 있어야 한다. 한 채널은 6명을 넘지 않는다. 단계로 나누지 말고 확정해서 한 번에.」

## 1. 업계 표준과 MSW

- 파티형 액션 RPG(디아블로2·패스 오브 엑자일·길드워)의 표준: **허브는 여럿이, 전투 지역은 파티마다 따로(인스턴스), 한 인스턴스 4~8명.**
- MSW 대응
  - 채널 = 월드 인스턴스. 출시 설정의 최대 인원이 차면 엔진이 새 채널을 연다.
  - 방 = 인스턴스 방(`RoomService`). 인스턴스 맵만 담을 수 있다.
  - 채널 사이 공유 = 월드 인스턴스 공유 메모리.
- **메이커 실측**
  - 방에 들어가거나 나올 때마다 플레이어가 다시 만들어진다. 저장했다가 다시 불러오며 메이커에서 5~20초 걸린다.
  - 사람이 모두 나간 방은 사라진다.
  - 그래서 마을을 방 밖에 두면 마을에 다녀올 때마다 로딩이 생기고 혼자 방이 사라진다. **마을도 방 안에 둔다**(디아블로2와 같다).

## 2. 구조

```
채널 (서버 하나 · 최대 6명 · 엔진이 연다)
 ├─ 로비 = 정적 방 map01: 캐릭터 고르기 → 게임 고르기 창
 └─ 게임 방 game:<id> = 그 난이도의 마을 4 · 사냥터 · 곁가지 전부 (63장)
     ├─ 혼자 하기 (id가 s로 시작, 목록에 없음)
     ├─ 공개 방 (목록에 보임, 최대 2~4명)
     └─ 비공개 방 (목록에 [비공개], 비밀번호, 최대 2~4명)
 심연 depth:… = 따로 (게임 방 ↔ 심연은 로비를 거친다)
```

- **맵**
  - 로비(map01, 월드 시작 맵)만 정적 맵이다.
  - 나머지 201장은 모두 인스턴스 맵이다 (`tools/build/maps.cjs`).
  - 사냥터 「피 묻은 황무지」는 map01 그림을 복제한 `wasteland`가 맡는다.
- **몬스터**
  - 방에 맵 63장이 함께 실려도 **사람이 처음 들어간 맵만 채운다** (`MonsterSpawner.Poll`).
  - 로비에는 몬스터를 채우지 않는다.
- **방 목록**
  - 월드 공유 메모리 `GameRoomsV1/list`에 둔다. JSON, 쓸 때 ETag로 겹쳐 쓰기를 막는다.
  - 게임 방 서버가 10초마다 인원을 적는다. 60초 넘게 소식이 없는 방은 지운다.
  - 비밀번호는 방 id를 섞은 해시로만 둔다.
- **다른 채널의 방**: 그 채널로 워프한다(`WarpToChannel(id, roomId)`, 워프 데이터 kind=room). 도착한 로비에서 그 방으로 바로 들어간다.
- **자리 예약**: 채널 상한(6)을 넘었는지 볼 때 이 채널 공개·비공개 방의 빈자리도 찬 것으로 센다(`ChannelSystem.CheckOverflow` + `RoomSystem.ReservedSeats`). 친구가 그 방에 들어올 자리를 남긴다.
- **방의 난이도**: 방을 만들 때 정한다. 방 안에서는 다른 난이도로 웨이포인트·난이도 변경이 막힌다. 「게임 나가기」 뒤 그 난이도로 방을 새로 만든다.
- **심연**
  - 마을의 심연 입구는 다음 층과 돌아올 게임 방(`RoomReturnV1`)을 적은 뒤 로비로 간다. 로비에서 1층 방에 넣는다.
  - 귀환하거나 쓰러지면 로비를 거쳐 원래 게임 방으로 돌아온다. 원래 방이 비어 사라졌으면 같은 id로 새로 연다.
- **메뉴**
  - 게임 방에서는 「게임 나가기」(로비로), 로비에서는 「채널 변경」이 나온다.
  - 캐릭터 선택은 로비에서 한다.
- **이어하기**: 끊긴 자리로 돌아가는 기능은 쓰지 않는다. 방은 끊기면 사라지므로 디아블로2처럼 로비에서 다시 고른다.

## 3. 부하 측정 (메이커, 10-21)

| 상황 | 서버 프레임 평균 | 최대 |
|---|---|---|
| 정적 방 | 28ms | 40 |
| 맵 63장 방 (몬스터는 들어간 맵만) | 31ms | 43 |
| 한 맵 몬스터 113 (6명 그림자 대신) | 38.7ms | 261 (소환 순간) |

부담은 「한 곳에 모인 유닛 수」에서 생긴다. 채널 6명이면 감당할 수 있다고 판단한다.

## 4. 출시 때 할 일

- 크리에이터 센터 출시 설정의 **최대 인원을 6**으로 둔다 (`config.csv channelMaxPlayers`와 같게).
- 채널 목록·워프·다른 채널 방 들어가기·자리 예약은 **출시 환경에서만** 동작한다. 메이커는 채널이 하나라 출시 뒤에 확인해야 한다.
