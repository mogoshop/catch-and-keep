# 에셋 (아트·오디오)

인력이 없으므로 **에셋 수가 곧 일정**이다. 이 문서의 목표는 "무엇이 필요한지"를 세고, 재사용·재채색으로 줄이는 것이다.

## 1. 최우선 결정: MSW 기본 에셋 vs 자체 제작

| 선택 | 장점 | 단점 |
| --- | --- | --- |
| MSW 공식 리소스(몬스터·맵·이펙트·사운드) 우선 사용 | 즉시 사용, 무료, 메이커에서 바로 배치 | 메이플 톤. 디아블로풍 어두운 분위기와 거리, 다른 월드와 차별 약함 |
| 외부 제작 에셋 업로드 | 차별화 | 제작 인력, 업로드·심사 정책 **미확인** |
| 혼합 (권장) | 몬스터·맵은 공식 리소스, UI·이펙트·그림자 색조 등은 자체 | 톤 통일 작업 필요 |

**권장: 혼합.** 공식 리소스를 베이스로 쓰고 색조·이펙트·UI로 어두운 톤을 만든다. 커스텀 에셋 업로드 가능 범위와 라이선스·심사는 설치 후 확인한다. (미확인)

## 2. 그림자 군단 비주얼 (고유 요소)

- 그림자 = **원본 몬스터 스프라이트에 색조(어두운 보라/반투명)를 입힌 것**. 몬스터마다 별도 에셋을 만들지 않는다.
- 등급 표현: 일반(어둡게), 정예(외곽선 발광), 보스(원본 크기 + 오라 이펙트).
- 색조 적용이 MSW 스프라이트 렌더러에서 가능한지 **미확인**. 불가하면 반투명 + 이펙트 오버레이로 대체.

## 4. 에셋 절약 원칙

1. 새로 그리기 전에 **재채색·크기 변경·조합**으로 만들 수 있는지 먼저 본다.
2. 룬 24종·보석 등은 **아이콘 템플릿 + 색·문양 코드**로 대량 생산한다.
3. 영역 5개 중 P1은 **영역 1~2까지만** 에셋을 만든다.
4. 마을은 재사용 가능한 NPC 배치 템플릿을 쓴다.
