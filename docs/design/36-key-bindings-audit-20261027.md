# 36. PC 키·마우스 전수 조사 (2026-10-27, Claude)

사용자 요청 (10-27): 「Z가 그림자 소환이었나? 스페이스가 망령 질주였던 것처럼 퀵메뉴에 없는데 키에 걸린 게 있는지 전수조사」.
코드(RootDesk/MyDesk) 기준. 모두 클라이언트 · 내 캐릭터에만 반응.

## 1. 두 방식 공통

| 키 | 하는 일 | 화면 표시 |
|---|---|---|
| A S D F | 스킬 칸 1~4 (마을에서는 스킬 안 나감) | 스킬 칸 |
| 우클릭 | 스킬 칸 5 | 스킬 칸 「우클릭」 |
| 1 ~ 4 | 벨트 물약 | 벨트 칸 |
| **Space** | 망령 질주(배웠을 때) · 근처 NPC 대화 · 웨이포인트 창 · 대화 넘기기 | NPC 옆 「[Space] 이름」만 |
| **Z** | **그림자 소환** — 그림자 창에서 「소환 지정」한 그림자를 부른다 (스킬 「그림자 소환」 필요 · 마나) | 없음 |
| **X** | 그림자 모두 회수 | 없음 |
| **C** | 집결 (스킬 「집결」 필요, Lv18) | 없음 |
| E | 가까운 혼 추출 | 메뉴 줄 「그림자 추출 E」 |
| **G** | 주변 장비·룬 줍기 (10-28 — HUD 「줍기」 단추 대신, 클릭 줍기·줍기 커서는 그대로) | 게임 안내 「조작 (PC)」 |
| **Ctrl** (누르고 있기) | 기본 공격 | 없음 |
| 방향키 | 이동 · 바라보는 방향(스킬·질주 조준) | 없음 |
| I U K H Q P L | 소지품 · 능력치 · 스킬 · 그림자 · 퀘스트 · 플레이어 · 랭킹 | 메뉴 줄 |
| **M** | 메뉴 창 | 없음 |
| **J** | 일지 | 일지 창 안에만 |
| **B** | NPC 대화 (예전 키, Space와 같음) | 없음 |
| Esc | 창 모두 닫기 · 확인 창 취소 | 없음 |
| **Enter** | 대화 넘기기 · 확인 창 확인 | 없음 |
| 휠 | 설명 글 스크롤 | 없음 |
| 벨트 칸 우클릭 | 넣을 물건 고르기 | 메뉴 도움말에만 |

W A S D 이동과 C 앉기는 일부러 막아 두었다 (ClickControl.BlockExtraKeys). R · T · Tab · W는 아무것도 안 한다.

## 2. 마우스 방식에서만 (기본)

- 바닥 클릭/누르고 있기 → 이동 · 몬스터 클릭 → 다가가서 계속 공격 · 웨이포인트 클릭 → 걸어가서 창 열기
- **Shift + 클릭** → 그 자리에서 커서 쪽으로 공격 (어디에도 안내 없음)
- 스킬 · 질주 · Ctrl 공격이 커서를 겨눈다

## 3. 키보드 방식에서만

- 클릭 이동 · 클릭 공격 없음 (방향키만)
- 스킬 · 질주 · Ctrl 공격이 바라보는 방향, 앞 ±40° · 7칸 안 가까운 적을 자동으로 겨눈다

## 4. 화면에 안내가 없는 키 (이번 안내 영상·가이드에서 다룸)

Z X C · Space(질주) · Ctrl · Shift+클릭 · M · J · B · Enter · 방향키.
→ 가이드 「조작」 쪽과 안내 영상 그림자 창 장면에 Z · X를 넣었다. Shift+클릭 · B는 아직 어디에도 없다.

## 5. 의심 가는 곳 (확인 안 함)

- 벨트 칸 우클릭이 스킬 칸 5도 같이 쓸 수 있다 (SkillBook 우클릭 처리에 UI 위 확인이 없다).
- 사냥터에서 Space는 질주와 NPC 대화·웨이포인트 창을 동시에 낼 수 있다.
- 창 단축키(U I K Q P M L H)는 죽은 동안에도, 다른 창 위에도 열린다.
