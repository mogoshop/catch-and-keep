# 16. 스킬·능력치 개편 — 메인 스킬 + 강화 (2026-10-11 확정안)

팀 테스트에서 2시간 만에 Lv20, 노말 액트 2까지 왔다. 진행 속도는 좋았다. 대신 다음 지적이 나왔다.

- 스킬 포인트가 너무 적다.
- 능력치가 무엇을 하는지 모르겠다. 디아블로를 해 보지 않은 팀원이다.

사용자가 정한 것은 네 가지다.
- 포인트는 **레벨당 2**.
- 초기화는 **Lv15까지 무료**.
- 트리 3개를 없애고 **「메인 스킬 + 강화」**로 간다.
- 능력치는 **우리 서비스(네크로맨서)에 맞게** 바꾼다. 다른 직업은 나중에 생각한다.

## 1. 지금 구조와 문제

| 항목 | 지금 | 문제 |
|---|---|---|
| 트리 | 군령·혼·저주 3개 × 10개 = 30개, 모두 최대 20레벨 | Lv20 포인트는 21개뿐이다. 1포인트를 넣어도 체감이 없다. |
| 포인트 | 레벨당 1, 의뢰 보상 skp 2개 | 스킬이 15개쯤 열려 있는데 포인트가 모자라 뭘 찍어야 할지 판단이 안 선다. |
| 숙련 패시브 | 해골 숙련·추출 숙련·군령 숙련·배치 확장·독 확산이 각각 따로 스킬 | 「해골을 키운다」는 느낌이 들지 않는다. 숙련에 1포인트를 넣으면 메인 스킬이 그만큼 약해진다. |
| 해금 | 요구 레벨 1·6·12·18·24·30·36·42·50 | Lv1~20 구간에 쓸 수 있는 액티브가 적다. |
| 능력치 | 힘·민첩·활력·정신 (디아블로 2 규칙) | 힘은 평타 %라 네크로맨서에게 쓸모가 거의 없다. 「활력 몰빵」이라는 정답을 모르면 막막하다. |

## 2. 새 구조 한눈에

```
메인 스킬 (해금 레벨이 되면 1포인트로 배움, 랭크 1~20)
 ├─ 강화 ① (메인 랭크 1부터, 최대 3)
 ├─ 강화 ② (메인 랭크 3부터, 최대 3)
 └─ 강화 ③ (메인 랭크 5부터, 최대 3~5)
```

- **포인트**: Lv2부터 레벨당 2포인트. 의뢰 skp 보상은 각 2포인트로 올린다. Lv20 기준 40포인트다.
- **메인 랭크 상한**: `min(20, 1 + floor((캐릭터 레벨 − 해금 레벨) / 2))`. (처음에는 최대 15였는데, 3단계 비교에서 Lv40 힘이 예전의 0.4~0.7배라 예전 최대 레벨 20에 맞췄다.)
  - 같은 스킬만 계속 찍을 수 없다.
  - 그래서 남는 포인트는 예전에 쓰던 메인 스킬의 강화로 간다. 사용자가 제안한 흐름이다.
- **메인 스킬 효과**: 지금의 레벨별 수치 공식(`RawEffectPower` 등)을 그대로 쓴다. 메인 랭크 = 예전 스킬 레벨.
  - 스킬 피해는 캐릭터 레벨로도 커진다 (`CharDamageScale`).
  - 최대 랭크 20 = 예전 최대 레벨 20이라 후반 힘은 예전과 같다.
- **강화**: 숫자만 올리는 것이 아니라 **동작을 바꾸는 것** 위주로 한다. 예: 투사체 +1, 튕김, 죽을 때 폭발, 저주 두 개.
  - 예전 숙련 패시브는 해당 메인 스킬의 강화로 들어간다.
- **트리 대신 하나의 목록**: 스킬 창은 해금 레벨 순서로 메인 스킬을 늘어놓는다. 「레벨이 오르면 새 스킬이 열린다」만 이해하면 된다.
  - 분류(소환·혼술·저주)는 색 띠로만 보여 준다.

## 4. 포인트·초기화·저장

- **레벨업**: 스킬 포인트 +2, 능력치 포인트 +5 (그대로).
- **초기화**
  - 스킬 창과 능력치 창의 「초기화」 버튼으로 한다. 스킬과 능력치를 따로 초기화할 수 있다.
  - **Lv15 이하는 무료**다.
  - Lv16부터는 야영지의 **사제 오렌**에게서 「초기화」를 한다. 비용은 Lv16 5만 골드 + 레벨마다 2,500 (10-24)다 (Lv20 = 4,000골드). 실수를 고칠 수 있을 만큼 싸게 잡았다.
  - 초기화하면 들인 포인트를 모두 돌려받는다. 장비로 얻은 「모든 스킬 +N」은 그대로다.
- **기존 캐릭터 전환** (한 번만)
  - 저장 버전이 오르면 스킬과 능력치를 모두 초기화한다.
  - 새 규칙으로 계산한 포인트를 돌려준다.
    - 스킬: `2 × (레벨 − 1)` + 끝낸 skp 의뢰 수 × 2
    - 능력치: `5 × (레벨 − 1)` + 끝낸 stp 의뢰 보상
  - 접속하면 알림 판으로 「스킬·능력치가 새로 바뀌어 포인트를 모두 돌려받았습니다」를 띄운다.
  - 퀵슬롯은 예전 스킬 id가 그대로 메인 스킬이면 유지한다. 없어진 스킬(숙련 패시브)은 비운다.

## 5. 능력치 — 네크로맨서용으로

저장 키(Str·Dex·Vit·Ene)와 장비 속성(str/dex/vit/ene)은 그대로 쓰고, **이름과 효과만 바꾼다**. 장비 데이터와 저장은 고칠 필요가 없다.

| 키 | 새 이름 | 1포인트당 | 이런 사람에게 |
|---|---|---|---|
| Str | **통솔** | 소환수(해골·마법사·되살림·그림자) 공격·생명 +1% | 소환수로 싸우는 사람 (기본 추천) |
| Ene | **정신** | 마나 +2 · 스킬 피해 +1% · 마나 재생 +0.02/초 | 골편·폭쇄 같은 주문으로 싸우는 사람 |
| Vit | **활력** | 생명 +3 | 모두. 자주 쓰러지면 여기에 |
| Dex | **민첩** | 공격·시전 속도 +0.3% · 평타 피해 +0.5% · 4당 방어 +1 | 평타·손맛을 원하는 사람 |

- **시작값**은 지금과 같다 (통솔 15, 민첩 25, 활력 15, 정신 25). 효과는 **시작값보다 올린 만큼**만 붙는다. 그래서 Lv1 수치는 바뀌지 않는다.
- **능력치 창 개편** (1단계의 「능력치 설명」을 여기서 같이 한다)
  - 줄마다 「이름 · 지금 값 · 역할 꼬리표(소환형/주문형/생존/속도)」를 보여 준다.
  - 쉬운 말로 「1포인트당 무엇이 오르는지」를 적는다.
  - **[+]에 마우스를 올리거나 한 번 누르면 미리보기**를 보여 준다. 「생명 182 → 185」를 초록 글씨로. 모바일은 첫 탭이 미리보기, 두 번째 탭이 확정이다.
  - **추천 분배** 버튼은 남은 포인트를 성향에 맞춰 한 번에 나눈다.
    - 소환형: 통솔 3 · 활력 2
    - 주문형: 정신 3 · 활력 2
    - 균형: 통솔 2 · 정신 1 · 활력 2
  - 「초기화」 버튼 (4절 규칙).
- **스킬 창 개편**
  - 해금 레벨 순서로 메인 스킬 카드를 둔다. 카드에는 아이콘, 이름, 랭크 `r/상한`, 한 줄 효과가 있다.
  - 카드를 고르면 오른쪽에 그 스킬의 **강화 노드**가 보인다. 지금 → 다음 랭크 수치와 필요 조건도 함께 보인다.
  - 아직 해금되지 않은 스킬은 흐리게 「Lv15에 열림」으로 보여 준다. 앞으로 무엇이 생길지 알 수 있게 하려는 것이다.

## 6. 구현 순서 (3단계)

1. **데이터와 엔진**
   - `skills.csv`에 열을 더한다: `parent`(강화가 붙는 메인), `unlock`, `maxRank`, `needRank`, `effect`(강화 효과 키).
   - `SkillBook`
     - 랭크와 강화를 저장한다.
     - 상한 공식을 적용하고 포인트를 레벨당 2로 바꾼다.
     - `GetPowerLevel(id)`가 「메인 랭크」를 돌려준다.
     - 예전 숙련 패시브 id(`skeleton_mastery` 등)는 해당 강화 노드 랭크를 예전 레벨로 환산해 돌려준다. 그래서 그림자·언데드 쪽 코드는 거의 그대로 둔다.
   - 저장 버전을 올리고 전환 환불을 넣는다. 초기화(무료·NPC 유료)도 넣는다.
2. **능력치**: 이름·공식·창 개편, 미리보기, 추천 분배, 초기화.
3. **스킬 창 UI**: 해금 순서 목록과 강화 패널.
4. **강화 효과 구현**: 투사체 수, 튕김, 뼈 파편, 저주 범위·지속·이중, 연쇄 폭발 등.
5. **새 메인 스킬**: 뼈 갑옷, 뼈 창.
6. **밸런스**
   - `tools/sim.py`로 Lv10·20·40에서 피해·생존을 지금과 비교한다. 목표는 ±15% 안이다.
   - 그 뒤 메이커에서 실제 진행(해골 + 골편 빌드, 주문 빌드)으로 확인한다.

각 단계를 끝낼 때마다 `npm test`와 메이커 검증을 하고 커밋한다.

## 7. 하지 않는 것

- 다른 직업용 능력치나 트리. 사용자 결정: 「이게 잘돼야 직군도 추가된다」.
- 장비 속성 이름(str 등)을 바꾸는 것. 표시 이름만 바꾼다.

## 8. 3단계 밸런스 비교 (2026-10-11)

메인 스킬 랭크 = 예전 스킬 레벨로 두고, 대표 빌드 두 가지를 예전 규칙과 비교했다. 계산은 `scratchpad`의 근사식이다. 공격 × 생명 × 수로 보고, 몬스터 쪽은 그대로다.

| Lv | 해골 소환형 (해골 수) | 골편형 (발 수) |
|---|---|---|
| 10 | ×1.4 (4 → 5) | ×1.1 (3 → 5) |
| 20 | ×1.2 (5 → 7) | 예전에 포인트 80%를 골편에 몰았을 때와 비교하면 ×0.6. 반반 투자와 비교하면 ×1.1 |
| 30 | ×0.9 | ×0.8 |
| 40 | ×0.8 | ×1.0 |

- **조정한 것**
  - 메인 최대 랭크 15 → 20.
  - 「뼈 군단」·「마법사 증원」 최대 3 → 2. 초반 해골 수가 너무 늘었다.
  - 「다중 투사체」 최대 3 → 4. 예전처럼 최대 5발이다.
- **남은 판단**
  - 레벨당 2포인트라서 같은 레벨이면 예전보다 조금 세다. 사용자가 원한 방향이다.
  - 실제 체감은 팀 테스트로 확인한다.
  - 몬스터 생명·공격은 바꾸지 않았다.
