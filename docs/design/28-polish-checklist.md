# 28. 다듬기 점검 목록 — 분야를 돌며 부분 수정 (2026-10-21)

사용자 방향(10-21):
- 시스템과 에셋은 대체로 완성됐다.
- 이제 한 분야에 몰입하지 않는다. 재미·스토리·UI/UX·HUD·의뢰 그림·몰입감·밸런스·몬스터 에셋을 **고루 부분 수정**한다.
- 대중적이되 디테일을 살린다.

근거는 이번 주 메이커 실제 화면(액트 1~4 사냥터 21곳 촬영), 첫 1시간 점검(25번 문서), 그림 수치(`tools/art_metrics.py`)다.

표의 「누가」 칸:
- **결정**: 사용자가 고를 것이 있다
- **Claude**: 바로 고칠 수 있다
- **Codex**: 그림이 필요하다

품은 소(반나절 이내), 중(1일), 대(2일 이상)다.
