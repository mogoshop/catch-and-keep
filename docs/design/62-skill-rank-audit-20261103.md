### 2-0. 공통 규칙 (코드)

- **랭크 상한 = 캐릭터 레벨 연동**: `min(maxLv, 1 + (캐릭터 Lv − 해금 Lv) // 2)` (`SkillBook.mlua:104` RankCap) → 랭크 r 최소 캐릭터 Lv = 해금 Lv + 2(r−1), 랭크 20 = 해금 Lv + 38.
- **공격 9종 피해** = `DamageCurve` × skillPowerMult 0.7 × skillDmgMult 2 × (1 + 0.2 × (캐릭터 Lv − 1)) (`SkillBook.mlua:576`·`:266`·`:291`, `GameData.mlua:233`·`:279`·`:289`).
  `DamageCurve` = 성격 배율 × (12 + 5 × (가상 레벨 − 1)), 가상 레벨 = 랭크 + (해금 Lv − 1) // 2 (`:576`, `GameData.mlua:284`·`:285`). 성격 배율: 티스 0.6 · 헥스 1.0 · 포이즌 0.35 · 드레인 1.2 · 프로즌 0.9 · 스톰 0.3 · 세크리 2.0 · 스피리트 0.8 · 데스 노바 2.5.

## 8. 랭크 열림 새 규칙 (해금 Lv ≥ 24)

### 8-1. 공식 · 코드

- 메인(해금 ≥ 24): `RankCap = min(maxLv, 1 + floor((캐릭터 Lv − 해금 Lv) / 1.5))` = 정수식 `1 + ((playerLevel - def.row) * 2) // 3`. 해금 < 24는 지금 그대로 `1 + (playerLevel - def.row) // 2`.
- 다음 랭크 레벨(`NextRankLevel`): 해금 ≥ 24 → `def.row + (3 * (rank - 1) + 1) // 2` (= 해금 + ⌈1.5 × (랭크 − 1)⌉) · 해금 < 24 → 그대로 `def.row + 2 * (rank - 1)`.
- 문턱 값은 `GameData`·`config.csv`에 `rankLateRow = 24` · `rankLateStep = 1.5` 로 두고 정수식은 step 1.5일 때만 위 형태(구현 레인이 일반식 `math.floor((L - row) / step + 1e-9)` 로 써도 됨).
- 파일:줄 = `SkillBook.mlua:104` RankCap · `:113` NextRankLevel · `:129` NodeLevel(아래 8-3).
- 이 규칙은 포인트 총량을 바꾸지 않는다(같은 레벨에서 늦은 스킬에 더 일찍 몰 수 있을 뿐). 새 상한이 늘 지금 상한 이상이라 상한 초과 환급이 생기지 않는다.
