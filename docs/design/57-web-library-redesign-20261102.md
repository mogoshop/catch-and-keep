## 1. 목표
1. **한 사이트, 한 디자인 체계.** /assets/의 남색 테마를 없애고 전 페이지가 같은 틀·같은 토큰.
2. **진짜 주소.** 해시 금지. 모든 화면이 고유 경로를 가지며 새로고침·공유·뒤로가기가 됨.
3. **랜딩 준비.** 지금은 자료실이지만 틀은 공개 랜딩 페이지를 얹을 수 있게(상단 내비 + 본문 + 푸터, 페이지별 제목·설명·OG 태그, 홈 히어로는 실제 게임 장면).
4. 내용(자료)은 바꾸지 않음. 사실성 규칙(스냅샷 날짜·커밋 표기, 연결됨/후보/실측 구분) 유지.

## 3. 디자인 체계
- **이름(사용자 결정 11-02)**: 사이트·게임 제목은 **「메이플 리저렉션」**(Maple Resurrection). 「잡으면 내편」·「Catch & Keep」은 제목으로 쓰지 않음(저장소 이름·주소에만 남음 · 푸터 한 줄 「개발명 잡으면 내편」 허용). 로고는 「메이플 리저렉션」 글자 로고 + 작은 영문. 「워크스페이스 / 오버뷰 / 아카이브 / 라이브러리」 같은 관리자·영어 낱말 제거 → 내비 = 「홈 · 스킬 · 맵 · 규칙 · 기록」.
- **틀**: 상단 가로 내비(로고 좌 · 메뉴 중 · 스냅샷 날짜 우) + 본문 최대 폭 1200px + 푸터(스냅샷 커밋·생성 시각·「원본 PNG 재생, 실제 녹화 아님」 고지). 사이드바 제거.
- **색 토큰**(지금 홈의 재·금 톤을 정본으로 — `app.css` 값에서 뽑아 `:root`에 정의): 바탕 재색 2단(bg/surface) · 선 1px · 글 상아색 2단 · 강조 금색 1개 · 보조 보라(언데드) 1개 · 상태색(연결됨 초록/후보 노랑/구버전 회색) 3개. 그라데이션 글자·네온 그림자 금지.
- **글꼴(사용자 결정 11-02)**: **Pretendard** 하나. 맥 로컬 설치본(`~/Library/Fonts` 또는 `/Library/Fonts`의 Pretendard*)에서 woff2를 만들거나(없으면 Pretendard 공식 배포 woff2 subset 사용 — OFL), `public/fonts/`에 자체 호스팅 + `@font-face` + `font-display: swap`. 굵기는 400·600·800 세 벌만. 영문 모노는 코드·id에만.
- **아이콘**: 이모지 금지. 인라인 SVG 16/20px 세트(스킬·맵·규칙·기록·검색·펼침·닫기·이전·다음) 하나로 통일. 외부 링크 화살표는 진짜 외부 링크에만.
- **구성 요소**: 카드(1px 선 · 모서리 10px · 호버 시 선만 밝게), 배지(상태색 3 + 「변경됨」「신규」「삭제됨」), 탭(하위 경로), 검색 입력, 필터 셀렉트, 다이얼로그 대신 **상세 페이지**. 8px 그리드. 터치 목표 40px 이상.
- **반응형**: 375px에서 가로 스크롤 0, 내비는 접힘 메뉴, 카드 1열.
- **글귀**: 짧은 명사형·한국어. 숫자는 표나 카드 안에서만. 영어 kicker 삭제.
- **메타**: 페이지마다 `<title>`(「맵 · 잿불 야영지 — 메이플 리저렉션」) · description · og:title/description/image(맵 상세는 그 맵 캡처, 스킬 상세는 아이콘) · favicon(지금 C·K 로고를 SVG로).

## 4. 성능·품질 기준
- `/skills/` 첫 화면 HTML 300KB 이하: 효과 스트립 그림은 지연 로딩(`loading="lazy"`), 프레임 재생은 화면에 보일 때만.
- 키보드 포커스 보이게, 대비 4.5:1 이상, `prefers-reduced-motion`이면 프레임 재생 정지.
- 검사: `npm test`에 라우트 생성 수·내부 링크 깨짐 0·해시 링크 0·이모지 0 검사 추가.
