# 32. 말투·용어 규칙 (10-22 사용자 확정)

이야기 카드, 장면, NPC 대사, 퀘스트 글이 모두 같은 세계의 말로 들리게 하는 규칙.
`npm test` 「말투·용어」(`tools/check_voice.cjs`)가 금지어·숫자·말투를 검사한다.

## 1. 누가 말하나

| 글 | 목소리 | 시제·형태 |
|---|---|---|
| 프롤로그 · 장 마무리 카드 (`prologue`, `act*_end`, `all_done`) | **오렌의 혼** — 심연에서 지난 일을 돌아본다 | 1인칭 과거 해라체 (「나는 …했다」), 플레이어는 「너」 |
| 장면 지문 (`scene*`, `reveal`의 `|`로 시작하는 쪽) | 무대 지문 | 3인칭 **현재형**, 짧게 (「오렌이 홀로 앉아 있다」) |
| 장면 대사 (`화자|대사`) | 그 인물 | 아래 말투표 |
| 지도 소개 (`maps.csv flavor`) · 몬스터 설명 | 해설 | 해라체 현재형 |
| 퀘스트 내용(`desc`) · 목표(`objective`) · 보상 줄 | 시스템 안내 | 숫자·규칙은 여기에만 쓴다 |

- 화자의 정체: 프롤로그 5쪽에서 「잿불 야영지에서 너를 기다렸다」로 오렌임을 알 수 있다.
  반전은 「누가」가 아니라 **「어디서」**다. 4장 마무리 마지막 쪽에서 「나는 지금 그 아래에서 이 이야기를 들려주고 있다」로 드러난다.
- 회고 화자는 결말을 알고 있다. 「그때는 몰랐다」 같은 복선은 한 장에 한 번만 쓴다. 고르의 정체를 직접 말하지는 않는다.

## 2. 인물별 말투 (`npcs.csv voice`)

| 인물 | voice | 끝맺음 | 플레이어를 부르는 말 |
|---|---|---|---|
| 오렌 (하르크의 딸, 파문 사제) | haera | 밝은 반말 ~야 · ~해 · ~지. 고르는 「행상 아저씨」, 하르크는 「아빠」. 무너질수록 말수가 준다 | 너, 네크로맨서 |
| 하르크 (대장장이, 오렌의 아빠) | haera | 무뚝뚝한 반말 ~다 · ~군 · ~마. 오렌은 「그 애」「녀석」「우리 딸」, 자신은 「애비」 | 너 |
| 그레이브 (초소 대장) | haera | 군인 말투 ~다 · ~지 | 자네 |
| 고르 (잿빛 행상) | hasipsio | 지나치게 공손한 ~습니다 · ~지요 · ~십시오 | 길손, 손님 / 오렌은 「사제님」 |
| 자파르 (카라반 보급관) | hasipsio | ~습니다 | 손님 |
| 무하드 · 오빈 · 브람 · 하그로 · 카이 | hage | 나이 든 말투 ~네 · ~게 · ~나 · ~군 | 자네 |
| 사디크 (떠돌이 상인) | hao | ~오 · ~소 · ~시오 | 당신 |
| 야스민 · 미라 · 엘리안 | haeyo | 부드러운 ~요 | 당신 |

- **말투가 바뀌는 순간은 연출이다.** 고르는 정체가 드러나는 `reveal`에서만 공손함을 버리고 해라체로 말한다. 다른 곳에서 말투를 섞지 않는다.
- NPC 창이 모든 인물에게 공통으로 하는 짧은 말(진행 중 인사, 다른 의뢰인 차례, 이동 인사)은 `NpcWindow:Stock()`이 voice로 고른다. 새 인물을 넣으면 `npcs.csv`에 voice를 꼭 적는다.

## 3. 용어

| 쓴다 | 쓰지 않는다 | 비고 |
|---|---|---|
| 조각 (모든 대사·지문·몬스터 설명) / 혼각 (프롤로그가 이름 붙이는 한 번 · 장비 이름 · 안내서) | 검은 돌, 검은 조각, 심장 돌 | 10-23 사용자: 「누구는 혼각, 누구는 조각」 → 대사는 전부 조각 (`npm test` 「말투·용어」가 검사). 모르는 사람이 부르는 「검은 부스러기」·「검은 짐」은 괜찮다 |
| 재의 왕 고르바스 / 고르 (행상일 때) | 불의 심연의 군주 | |
| 그림자 | — | 두 뜻을 일부러 겹친다: 풀려난 혼이 네크로맨서를 따르는 모습 = 그림자, 고르바스는 산 자의 그림자를 빼앗는다 (`reveal` 4쪽에서 고르바스가 직접 대비시킨다) |
| 무덤 왕국 · 모래 폐허 · 폭풍 해안 · 심연의 땅 | 잿빛 변경, 불의 심연 | 지역 이름 = `regions.csv` = `GameConst:ActRegionName` |
| 불탄 협곡 | 잿불 협곡 | 「잿불」은 야영지 하나에만 |

## 4. 대사에 쓰지 않는 말

- 요즘 말 · 게임 말: 대박, 좋은 의미로, 소름, 공짜, 레벨, 퀘스트, 아이템, 스킬, 버프, 보스, 능력치, 경험치, 소켓권, 웨이포인트
- 숫자: 「마흔다섯 마리쯤」 같은 수량, 「10분마다」 같은 시간. 수량·시간은 목표 칸이나 흐린 안내 줄(`<color=#9C9488>`)에 쓴다.
- 보상 설명: 「능력치를 다섯 더」 대신 보상 줄이 따로 보여 준다. 대사는 「이건 자네가 가지게」 정도로 끝낸다.
- 예외: 소켓 · 룬 · 물약 · 두루마리는 세계 안의 물건이라 대사에 써도 된다 (디아블로2와 같다).
