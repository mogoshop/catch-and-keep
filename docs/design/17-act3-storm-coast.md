## 0. 목표

- 액트 2가 **Lv 21~22**에서 끝나므로 액트 3은 **몬스터 Lv 22→29, 보스 30**. 보통을 다 깨면 **Lv 30 전후**.
- 액트 3를 넣으면서 **악몽 가산 +20 → +30, 지옥 +40 → +60** (보통 끝 레벨 ≈ 악몽 첫 맵 레벨, 14장 §1.1과 같은 원리).
  - 지옥 액트 3 보스가 **Lv 90** → **레벨 상한 80 → 99** (D2와 같음). 경험치 곡선(`100 × n^2.4`)은 그대로 늘린다.
- 액트 1·2와 다른 싸움: **번개가 적과 내 군단 사이를 튕긴다**. 군단을 한데 뭉치면 위험하고, **번개 저항이 처음으로 중요**해진다.
- 의뢰는 액트 2처럼 「대표 보상 하나」, 영구 보상은 난이도마다 1회.

## 3. 새 장치 — 번개 연쇄 적

| 항목 | 내용 |
| --- | --- |
| 누가 | 폭풍 주술사(최대 4번 튕김) · 전기 뱀장어(2번) · 보스 바렌(5번) · 미친 등대지기(4번) |
| 예고 | 첫 대상 발밑에 0.6초 동안 파란 표식 → 번개 (06장 「처음 보는 공격은 예고」 원칙) |
| 튕김 | 첫 대상을 맞히고, **3칸 안의 다른 아군(플레이어·그림자·언데드)** 중 가장 가까운 대상으로 튕긴다. 같은 대상은 다시 맞지 않는다. 튕길 때마다 피해 −15% |
| 피해 | 번개 속성 → **번개 저항**이 줄인다. 그림자·언데드는 호령 「모든 저항」과 주인 저항 일부를 받는다 (지금 구조 그대로) |
| 대응 | 군단을 흩뜨리기 · 주술사 먼저 잡기(원거리, 무리 뒤) · 번개 저항 장비·의뢰 보상 · 뼈 갑옷 흡수 |
| 연출 | 대상 사이를 잇는 번개 줄기 (메이플 번개 스킬 이펙트 → 코덱스 전용 이펙트로 교체) + 맞은 대상 파란 번쩍임 |

- 서버에서 대상·피해를 정하고, 줄기 연출은 모든 클라이언트에 Multicast (투사체 엔티티를 쓰지 않아 가볍다).
- 군단이 큰 후반일수록 위험해지므로 **튕김 수는 데이터(`monsters.csv` 새 칸 `chain`)**로 두고 4단계에서 조정한다.

## 6. 액트 2 → 3 연결

- 대사제 처치(의뢰 12) → 오아시스 시장의 **카라반 대장**이 「소금바람 항구로」 버튼을 보여 준다 (난이도마다). 항구에는 **선장**이 있어 돌아가는 배를 맡는다.
- 카라반·선장 모두 **열린 다른 액트 마을 전부**로 데려다준다 (오아시스 맵을 다시 빌드하지 않으려고 선장을 오아시스에 두지 않았다 — 10-11 구현).
- 액트 3 첫 의뢰(13)는 항구 관리인이 바로 준다.
- 웨이포인트 창 액트 탭 3개 (액트 1 / 2 / 3).
- **다음 난이도 개방은 바렌으로 옮긴다.** 이미 악몽을 연 캐릭터는 그대로 열려 있다 (개방 기록은 그대로 둔다).
