# 창이 HUD에 가려지는 문제 전수 검사 (2026-10-11)

## 사용자 지적

잿빛 행상 고르의 거래 창(ShopHUD) 아래 버튼(5개 구매·판매)이 HUD 메뉴 줄(소지품·능력치…)에 가려졌다.

## 원인

UI 그룹 GroupOrder가 같으면 어느 그룹이 위에 그려질지 정해지지 않는다.

- ShopHUD 5 = GameHUD 5 (하단 메뉴 줄·스킬 칸·오른쪽 위 메뉴 버튼이 거래 창을 덮었다)
- StashHUD 6 = ShadowHUD 6 (지금 화면에서 겹치는 조각은 없지만 같은 위험)

커밋된 파일은 ShopHUD 10·StashHUD 11로 문제가 없었다. **메이커가 다시 저장하면서 UI 그룹 GroupOrder를 0~15로 다시 매겼다.** 그 결과 Shop이 5(GameHUD와 같음)로, Stash가 6(ShadowHUD와 같음)으로 내려갔다. 메이커는 앞으로도 다시 매길 수 있으므로 검사를 `npm test`에 넣었다.

## 수정

- ShopHUD·StashHUD → GroupOrder 7 (`tools/build/shop.cjs`·`stash.cjs`가 빌드할 때마다 지정).
  - 창 그룹끼리는 같아도 된다. `UIKit:Open`이 다른 창을 닫으므로 동시에 열리지 않는다.
- **전수 검사 도구 `tools/check_ui_layers.cjs`**, `npm test` 「창 가림 검사」에 추가.
  - 모든 UI 파일의 엔티티 화면 좌표를 계산한다 (앵커·오프셋).
  - 창: `UIKit:RegisterWindow`로 등록된 판 · 이름이 `…Win` · 꺼진 채로 시작하는 큰 판.
  - 늘 보이는 HUD 조각과 PC·모바일 각각 겹치는지 본다.
  - 가림 판정 = HUD 쪽 그룹 순서가 더 크거나 같은데 다른 그룹. 같은 그룹 안은 `UIKit:Open`이 연 창을 맨 앞으로 옮기므로 제외.
  - 창이 열리면 스크립트가 끄는 HUD(모바일 패드·소환수 목록·안내 줄·모바일 일지 버튼)와 입장 전 캐릭터 선택 화면은 제외.
- 결과: 수정 전 PC 15·모바일 19곳(모두 거래 창) → 수정 후 0건.
