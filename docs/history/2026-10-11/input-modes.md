# PC 조작 모드 구분 — 마우스 / 키보드(WASD) (2026-10-11)

## 문제

MSW 기본 플레이어 컨트롤러는 W A S D와 방향키를 모두 이동으로, C를 앉기로 받는다. 그래서 두 모드 모두에서 다음 문제가 있었다.

- A·S·D를 누르면 스킬이 나가면서 캐릭터도 걸었다.
- 마우스 모드에서도 WASD로 걸을 수 있었다.
- C(그림자 집결)를 누르면 캐릭터가 주저앉았다.

## 변경

| | 마우스 모드 | 키보드 모드 |
| --- | --- | --- |
| 이동 | 마우스만 (W A S D·방향키 이동 끔) | W A S D·방향키 |
| 스킬 1~4 | A S D F | Q R F G |
| 우클릭 스킬 | 그대로 | 그대로 |
| 퀘스트 창 | Q 또는 O | O (Q는 스킬) |
| 그림자 추출 | E | E |

- `ClickControl.ApplyMoveKeys`: 엔진 기본 이동 키의 동작 이름을 처음 한 번 기억해 둔다. 모드에 맞춰 키를 떼거나(`RemoveActionKey`) 다시 붙인다(`SetActionKey`). C(앉기)는 항상 뗀다. 모바일은 가상 스틱이 방향키 신호를 쓰므로 건드리지 않는다.
- `SkillBook`: 키보드 모드면 Q R F G를 1~4번 칸으로 받는다.
- `HudMain.ApplyKeyLabels`: 조작을 전환하면 다음 표시를 모드에 맞게 바꾼다.
  - 칸 단축키 글자
  - 스킬 지정 창 탭
  - 메뉴의 퀘스트 단축키
  - 메뉴 도움말
- 메이커 확인은 하지 않았다 (사용자·팀원이 1레벨부터 테스트 중이라 코드만 반영).
