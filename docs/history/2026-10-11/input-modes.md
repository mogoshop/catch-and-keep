# PC 조작 — W A S D 이동·C 앉기 막기 (2026-10-11)

## 문제

MSW 기본 플레이어 컨트롤러는 W A S D도 이동으로, C를 앉기로 받는다. 그래서 다음 문제가 있었다.

- A·S·D 스킬을 쓰면 캐릭터가 같이 걸었다.
- 마우스 모드에서도 WASD로 걸을 수 있었다.
- C(그림자 집결)를 누르면 주저앉았다.

## 결정

팀 의견: 메이플처럼 방향키 기반이 맞다. 그래서 스킬 A S D F와 두 모드는 그대로 두고, W A S D 이동과 C 앉기만 뗐다.

- 처음에는 키보드 모드를 WASD 이동·스킬 Q R F G로 바꿨다 (c45dced). 이 의견을 듣고 되돌렸다.

## 변경

- `ClickControl.BlockExtraKeys`: 내 캐릭터(PC)에서 처음 한 번 `RemoveActionKey`로 W·A·S·D·C를 뗀다.
- 모바일은 가상 스틱이 방향키 신호를 쓰므로 건드리지 않는다.
- 조작:
  - 마우스 모드 = 클릭 이동 (방향키를 누르면 클릭 이동 취소, 기존과 같다)
  - 키보드 모드 = 방향키 이동·Ctrl 평타
  - 스킬 A S D F·우클릭
- 메이커 확인은 하지 않았다 (사용자·팀원이 1레벨부터 테스트 중이라 코드만 반영).
