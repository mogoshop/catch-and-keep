# 보스 다시 나타나기 5분 + 남은 시간 표시 (2026-10-11)

팀 테스트에서 나온 지적: 보스 리젠이 너무 빠르다 (고정 보스 90~120초). 피의 제단은 맵이 5초만 비면 다시 시작돼서, 포털을 켜 두고 무제한으로 파밍할 수 있었다.
팰월드처럼 오래 기다리더라도 남은 시간을 보여 주자는 요청이다.

## 바꾼 것

| 대상 | 예전 | 지금 |
|---|---|---|
| 맵에 놓인 보스 (처형인·해골 대장·묘지기 여왕·문지기 형제·대사제) | `monsters.csv` respawn 90~120초. 근처에 플레이어가 있으면 미룸 | `bossRespawnSec` = 300초. 시간이 되면 기다리던 사람 앞에도 바로 나온다 |
| 곁가지 끝방 우두머리 (모르그·유물 수호자·세르카·무덤 왕·사서) | 맵이 3초 비면 맵 전체와 함께 다시 나옴 (봉인 상자 포함) | 쓰러진 뒤 5분 동안은 맵이 비어도 다시 채우지 않는다. 시간이 되면 아래처럼 나온다 |
| 피의 제단 의식 (피의 사제) | 끝난 뒤 맵이 5초 비면 초기화 | 사제가 쓰러진 뒤 5분 동안 제단이 잠잠하다. 의뢰 중인 사람이 다가가면 남은 시간을 알려 준다 |

곁가지 끝방 우두머리는 5분이 지난 뒤 이렇게 돌아온다.
- 맵이 비어 있으면 맵 전체가 처음 상태로 다시 채워진다 (봉인 상자 포함).
- 사람이 있으면 우두머리와 호위만 끝방에 다시 나온다.

## 표시

- **미니맵 머리글**: 그 맵에 쓰러진 보스가 있으면, 맵 종류 대신 주황 글씨로 남은 시간을 보여 준다 (예: `목 없는 처형인 4:32`).
  - 보스가 여럿이면 가장 늦게 돌아오는 보스를 보여 주고 「외 N」을 붙인다.
  - 글자 칸에 best fit을 켰다 (15~22).
- **맵 입장 배너**: `… · 목 없는 처형인 4:32 뒤 다시 등장`.
- **알림**:
  - 보스가 쓰러지면 맵 전원에게 「<보스> — 5분 뒤 다시 나타난다」.
  - 다시 나오면 「<보스>이(가) 다시 나타났다」.
  - 제단이 다시 열리면 「피의 제단이 다시 꿈틀거린다」.

## 구조

- `World/BossRespawn.mlua` (@Logic)
  - 서버 `Timers`: 「맵 이름|보스 이름」 → 다시 나오는 시각 (`ServerElapsedSeconds`).
  - `@Sync Digest`로 클라이언트에 알린다.
  - API: `Start` / `Clear` / `Remaining` / `MapRemaining`, 클라이언트 `LabelFor`.
- `Monster.Die`: `IsFieldBoss()` (리스폰 있음 + 고유 이름 또는 보스 등급)이면 지연을 `bossRespawnSec`로 하고 타이머를 시작한다.
- `Monster.TryRespawn`: 보스는 근처에 플레이어가 있어도 나오고, 타이머를 지운다.
- `MonsterSpawner`
  - `NamedAlive`를 `{ e, row, down }`으로 바꿨다.
  - `TrackNamed`가 매초 우두머리가 쓰러졌는지 보고, 쓰러지면 타이머를 시작하고 시간이 되면 혼자 다시 소환한다.
  - `NeedsRefill`은 `MapRemaining > 0`인 동안 false를 돌려준다.
- `AltarRitual`
  - 끝나면 타이머를 시작한다.
  - `Tick`은 끝난 의식을 타이머가 끝난 뒤에만 지운다.
  - `OnReached`는 대기 중이면 남은 시간을 알려 준다 (사람마다 5초에 한 번).
  - 의뢰를 마친 사람의 피의 신전 효과는 그대로다.
- `config.csv`: `bossRespawnSec` = 300.
- `Util.NotifyMap(map, text)`.

## 확인

- `npm test` 8/8 통과. mLua 진단 오류 0건.
- 메이커 확인 (10-11). 테스트할 때는 `bossRespawnSec`을 20~30초로 낮췄다. 빌드 오류 0, SelfTest 177/0.
  - **처형인**
    - 쓰러진 뒤 미니맵 머리글에 주황 「목 없는 처형인 0:16」이 나왔다.
    - 20초 뒤 옆에 서 있던 플레이어 앞에 다시 나왔고, 머리글은 「사냥터」로 돌아왔다.
    - 실제 300초에서는 「목 없는 처형인 4:54」로 보였다.
  - **모르그 (곁가지 끝방)**
    - 쓰러진 뒤 맵을 10초 비워 두어도 다시 채우지 않았다 (`needsRefill=false`).
    - 시간이 끝나자 맵 전체가 다시 채워졌다.
    - 맵 안에서 기다리면 머리글에 「썩은 사제 모르그 0:24」가 보이고, 시간이 되면 모르그만 끝방에 다시 나와 「다시 나타났다」 알림이 떴다.
  - **피의 제단**
    - 사제가 쓰러진 뒤 다시 다가가도 의식이 시작되지 않았다.
    - 「피의 제단이 잠잠하다 — 0:28 뒤 …」 알림이 나오고, 머리글에 「피의 사제 0:25」가 보였다.
    - 시간이 지난 뒤에는 새 의식이 시작됐다 (wave 0).
  - **알림 문구**: 처음에는 30초 미만이 「0분 뒤」로 나왔다. `BossRespawn.WaitText`를 두어 「5분」·「2분 30초」·「20초」로 고쳤다.
- 같이 고친 것: `UndeadSystem.FindSoulInDirection`의 혼 변수에 `---@type SoulOrb`가 빠져 있었다. 이 때문에 메이커 빌드 오류 LEA-1103이 났다 (10-11 혼 규칙 변경 때 생긴 것).
- 남은 관찰: 교수대 숲의 「목 없는 처형인」은 데이터상 기본 레벨이 1이라 「최상위 Lv1」로 보인다. 맵 레벨은 6~9다. 이번 변경과는 별개다.
