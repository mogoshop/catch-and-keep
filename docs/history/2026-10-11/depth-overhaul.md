# 심도 개선 — 방 모양 돌림·층 저주·보스 층·보상·전용 분위기 (2026-10-11)

초반에 만든 뒤 손대지 않아 "대충 만든 유일한 던전"이던 심도를 다섯 갈래로 고쳤다.

## 변경

| 항목 | 내용 |
| --- | --- |
| 방 모양 돌림 | 1층 `depth`(바위 방) → 2층부터 `depth2`(지하 묘실 방) · `depth4`(잿빛 동굴) · `depth`(바위 방) · `depth3`(무너진 벽 마당) 순서로 돈다. 5의 배수 층은 늘 `depth3`. 새 방은 24~28×16칸 (`GameConst:DepthMapFor`, `data/maps.csv`·`data/map_layouts.csv`) |
| 층 저주 | 2층부터 보스 층이 아니면 한 가지: 신속(몬스터 이동 +35%) · 정예 다수(정예 확률 +35%p) · 독 장판(0.8초 예고 뒤 4초, 최대 생명 3%/0.5초, 독 저항 적용) · 칠흑(내 주변 빛 −45%). 저주 층 보상 +1회 |
| 보스 층 | 5층마다 세르카 → 묘실 수호왕 → 사서 순서로 보스 + 졸개 절반(최소 4). 레벨 +2. 보스 배경음 `abyssboss` |
| 층 보상 | 정복하면 파티 위쪽에 보상 상자 (파티원마다 한 번씩 열림). 추첨 2 + 층/5회 (최대 5), 보스 층은 보스 표, 10층부터 고유 표 |
| 기록 | 1층 입장부터의 시간을 잰다 (룸 키 끝 `~시작초`). 랭킹 심도 탭 = 최고 층 → 같은 층이면 빠른 순, 「5층 · 5분 37초」 |
| 분위기 | 심도 전용 전체 밝기 0.24(일반 하한 0.32)·보랏빛, 배경음 `abyss`. 층 도착 때 「심도 7층 · 저주: 독 장판」 + 저주 설명 알림 (HUD 알림 판) |

## 메이커 확인에서 잡은 문제

| 문제 | 원인 | 수정 |
| --- | --- | --- |
| 2층 문을 밟으면 "depth2 must be set to instance map"으로 이동 실패 | 메이커는 맵 파일 머리 `Usage`(1 = 인스턴스)로 방을 가른다. 빌더는 `IsInstanceMap`만 켜서 새 맵이 정적 방에 실렸다 | 빌더가 인스턴스 맵에 `Usage = 1`. `check_assets`가 인스턴스 맵의 Usage를 검사. 돌림 맵을 못 열면 기본 `depth`로 여는 안전장치 (`PlayerSave.ContinueDepthTravel`) |
| 새 방에서 몬스터가 도착 지점에 겹쳐 나오고 미니맵 지형이 비었다 | 새 맵이 빌더 템플릿 타일셋(번호 체계가 다름)으로 생겨 벽·충돌 판정이 전부 어긋났다 | 빌더가 모든 맵에 프로젝트 타일셋(`AshCampTiles`)을 쓴다. `check_assets`가 맵 타일셋을 검사 |
| 층 안내가 안 보였다 | 엔진 기본 알림(`ScreenMessageLogic`)은 이 HUD에서 보이지 않는다 | HUD 알림 판(`UXFeedback`)으로 제목 + 저주 설명 |
| 보상 상자가 하단 스킬 바에 가렸다 / 가운데 횃불과 겹쳤다 | 방 가운데 아래 (0, −1.5) / 바로 위 (0, 1.4) | 파티 중심 + (1.5, 0.9)의 걸을 수 있는 칸 |
| 1층 보상이 물건 하나뿐 | 추첨 1 + 층/5 | 2 + 층/5 |

## 메이커 확인

- 마을 입구 → 1층(`depth`) → 정복(24초) → 오른쪽 문 → 2층(`depth2`, 저주 정예 다수, 가장 가까운 몬스터 3.4).
- 독 장판 강제: 0.8초 뒤 피해 시작, 서 있으면 초당 약 82(최대 생명 2000 기준 4%).
- 신속 강제: 지옥견 이동 1.5 → 2.025. 칠흑 강제: 클라이언트 시야 감소 0.45 반영, 화면이 눈에 띄게 좁아짐.
- 5층(`depth3`): 독침 여왕 세르카 + 졸개 8, 배경음 `abyssboss`, 정복 상자 보스 표 3회.
- 4층(`depth4`): 정복 알림 「심도 4층 정복 (도전 3분 46초)」, 상자 위치·문 2개 정상.
- 랭킹 심도 탭: 「1. 인꾸 5층 · 5분 37초」.
- `npm test` 7/7.
