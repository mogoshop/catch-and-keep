# 잿빛 장막 6부위 동작 그림 제작

## 완료

- 이전 단일 착용 시안의 후드·로브·장갑·장화·낫·등불로 범위를 제한했다.
- 후드 2방향과 나머지 5부위 × 4동작 × 4프레임 = 82장. 실제 생성 결과에서 분할하여 20개 GIF 미리보기 제공.
- 등불 손잡이 잘림과 장갑 손끝 노출은 image_gen 보정본으로 교체했다. 프레임 셀 경계를 넘는 칼날/소매는 연결 영역으로 추출했다.
- 80개 동작 프레임의 투명도·빈 프레임·경계 잘림·해시 검사 통과. GIF 20개 각각 4페이지 및 개별 4프레임 해시 모두 다름.
- 공식 Cap PSD 16개 레이어 중 edithere 2개만 교체했고 나머지 레이어/기준점/메타데이터가 원본과 일치한다. 합성 이미지도 빈 이미지가 아니도록 생성했다.

## 미완료

- Maker 메뉴 자동 클릭이 반응하지 않아 사용자에게 AvatarItem Editor를 여는 UI 인계를 요청했다. 메이커가 다시 플레이 상태로 바뀌는 것도 관찰했다.
- 후드 가져오기·동작 미리보기·업로드 미검증.
- 로브·장갑·장화 전체 native 자세/신체 레이어 전환은 미완료. 낫·등불 무기/보조무기 등록 및 동시 착용 조건 확인 미완료.
- 6개 avataritem RUID는 아직 발급하지 않았으며 게임 장비에 적용하지 않았다. PNG/GIF를 native 착용 자산 완료로 보고하지 않는다.
