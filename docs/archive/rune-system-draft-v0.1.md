# 혼각 룬 & 룬워드 시스템 — 초안 v0.1

디아블로2 룬워드의 구조(소켓 + 순서대로 룬 삽입 → 특수 효과)만 차용하고, 룬 이름·조합·효과·룬워드 이름은 전부 오리지널로 설계한 초안. 핵심 테마: **그림자 군단(소환수) 강화**.

## 1. 기본 규칙

| 항목 | 내용 |
| --- | --- |
| 명칭 | 혼각(魂刻) 룬 — 망자의 혼이 새겨진 돌 |
| 소켓 가능 부위 | 무기 / 갑옷 / 투구 / 보조(영혼 등불) |
| 소켓 수 | 무기 2~6, 갑옷 2~5, 투구 2~3, 보조 2~3 |
| 룬워드 성립 조건 | ① 일반 등급(무옵션) 아이템 ② 소켓 수 = 룬워드 룬 개수 (정확히 일치) ③ 정해진 순서대로 룬만 삽입 ④ 부위 일치 |
| 룬 제거 | 기본 불가. 「망각의 의식」(고급 재료 소모) 시 아이템 파괴 + 룬 회수 |
| 효과 적용 | 룬워드 성립 시 개별 룬 효과 + 룬워드 효과 모두 적용 |

### 보조 장비: 영혼 등불 (오리지널)

네크로맨서 전용 왼손 장비. 디아2의 해골 방패 포지션 대체. 소환수 관련 옵션이 주로 붙는 부위.

## 3. 룬워드 목록 (14종)

표기: `룬1 → 룬2 → …` 는 삽입 순서. PvP 항목은 PvP 지역 내 효과 보정.

### 초반 (Lv 9~30)

**① 첫 번째 군령** — 영혼 등불 2소켓 · Lv 9 · 아스 → 이른
- 배치 한도 +1
- 소환수 공격력 +15%
- 그림자 추출 확률 +5%
- 최대 마나 +20

**② 무덤의 속삭임** — 투구 3소켓 · Lv 15 · 미르 → 노드 → 세브
- 저주 범위 +30%
- 소환수 공격에 독 피해 +15 (3초) 추가
- 마나 재생 +25%
- 독 저항 +30%

**③ 망자의 행진** — 갑옷 2소켓 · Lv 22 · 오르웬 → 바엔
- 이동 속도 +20%
- 소환수 이동 속도 +25%
- 소환수 공격에 화염 피해 +5~10 추가
- 화염 저항 +30%

**④ 검은 서약** — 무기(낫) 3소켓 · Lv 27 · 드라크 → 케일 → 쿠라
- 피해 +80%

- 플레이어가 적중시킨 대상에게 소환수 피해 +20% (5초 표식)

## 4. 룬 획득 & 승급

### 드롭
- 던전 **심도(층수)** 가 깊을수록 상위 룬 드롭 테이블 개방
- 보스 처치 시 해당 심도 등급 룬 1개 확정
- 신화 룬: 최심층 보스 / 주간 보스 전용

### 승급 — 「혼합 제단」

| 재료 | 결과 |
| --- | --- |
| 하급 룬 ×3 | 다음 번호 룬 ×1 |
| 중급 룬 ×3 + 그림자 정수 ×1 | 다음 번호 룬 ×1 |
| 상급 룬 ×2 + 짙은 그림자 정수 ×1 | 다음 번호 룬 ×1 |
| 신화 룬 | 승급 불가 (드롭 전용) |

**그림자 정수** = 그림자를 **분해**해서 얻는 재료. "무제한 보유"로 쌓인 약한 그림자의 소모처 역할.

## 5. 구현 메모 (MSW / mLua)

### 데이터 구조 예시

```lua
-- RuneData: 룬 번호 → 부위별 효과
RuneData = {
  [1]  = { id = "as",   tier = 1, weapon = { dmgPct = 15 }, armor = { def = 15 }, lantern = { maxMp = 10 } },
  [21] = { id = "xil",  tier = 3, weapon = { freezeChance = 3 }, armor = { maxHpPct = 5 }, lantern = { deployCap = 1 } },
  -- ...
}

-- RunewordData: 부위 + 정확한 룬 순서
RunewordData = {
  first_command = {
    name = "첫 번째 군령", slot = "lantern", reqLv = 9,
    runes = { "as", "irn" },
    effects = { deployCap = 1, summonDmgPct = 15, extractPct = 5, maxMp = 20 },
    pvp = nil,
  },
  -- ...
}
```

### 판정 로직
1. 룬 삽입 시 아이템 등급이 `normal` 인지 확인
2. 모든 소켓이 찼을 때 `slot + runes` 배열을 키로 `RunewordData` 조회 (예: `"lantern|as|irn"` 문자열 키로 해시)
3. 일치하면 아이템에 `runeword = id` 부여, 아이템 이름 교체
4. 스탯 계산은 **서버에서만**, 클라이언트는 표시만 (치트 방지)

### 밸런스 레버
- `deployCap`(배치 한도)은 서버 부하와 직결 → 전체 합산에 하드 상한 필요 (예: 기본 10 + 장비 보너스 최대 +15)
- PvP 보정은 룬워드별 `pvp` 필드로 덮어쓰기
