; 여왕의 무덤 — 장소 설계도 (60×40). 설계서 data/handmade/specs/act1.cjs → tools/build/handmade/compose.cjs가 만든다 (손으로 고치지 말고 설계서를 고친다)
; 칸 (c, r) → 월드 칸 x = c - 30, y = 20 - r. 한 글자 = 한 칸, 위가 북쪽
; 무덤 문을 지나면 순장자들의 방과 시녀들의 방 — 둘 중 하나를 지나야 봉인된 문간에 닿는다 (호위 무리).
; 문간 너머가 여왕의 안식처(아레나 27×21). 여왕은 석관 옥좌 앞에 선다. 동북 구석 문이 야영지로 돌아가는 길.
;
;   [1] 무덤 문
;   [2] 순장자들의 방
;   [3] 시녀들의 방
;   [4] 봉인된 문간
;   [5] 여왕의 안식처 — 아레나 · 여왕 · 기둥 넷
;
