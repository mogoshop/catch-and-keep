# 잡으면 내편 — UI 이미지 연결 안내

제작: Codex / 2026-10-07. 게임 코드 및 UI 엔티티 변경 없이 PNG 제작과 메이커 리소스 등록만 수행.

## 역할

- Codex: 메이커 조작, 타일·구조물 배치, 고유 UI·스킬 이미지 제작, 화면 검증.
- Claude: 선택 가능한 퀵슬롯, 모바일 메뉴, 미니맵, 퀘스트 추적, 장비 상태, HP/MP 표시와 이미지 연결.
- 장비 아이템·포션·NPC의 실제 그림은 메이플월드 제공 에셋 우선. 이 팩의 빈 장비 그림은 미착용 상태용이며 실제 아이템 그림과 구분.

## 스타일

검게 닳은 철, 낮은 채도의 낡은 청동, 회색에 가까운 뼈. HP는 짙은 붉은색, MP는 파란색. 소환은 보라색, 독은 녹색, 저주는 붉은색. 이미지 위에 텍스트를 구워 넣지 않아 모바일 크기·현지화에 대응.

## 오브

| 용도 | PNG | 규격 | 실제 업로드 RUID |
|---|---|---|---|
| HP/MP 공통 원형 프레임 | orb-frame.png | 256×256 | a782d0570f1d439f8fbe951a5f304b67 |
| HP 채움 | orb-life-fill.png | 240×240 | 1a87b1d2ea2e4dc98efe37f6b5278f7c |
| MP 채움 | orb-mana-fill.png | 240×240 | 79c62448dfcc4d97aa909994739b6082 |

프레임과 액체는 중심을 맞추고 240×240 액체를 256×256 프레임 뒤에 놓는다. 빈 상태의 바탕은 어두운 원형 배경을 별도로 사용한다. 액체 원본 크기는 고정하고 아래에서 위로 보이는 높이만 클리핑한다. 세로 스케일을 줄이면 구형 반사·문양이 찌그러지므로 금지. 0·25·50·75·100%에서 프레임 바깥 누출·빈 공간·정렬을 화면으로 검증할 것.

## 빈 장비 칸

프로젝트 item_bases.csv의 실제 슬롯: helm, armor, gloves, boots, belt, amulet, ring, weapon, offhand. 각각 empty-*.png. 장비가 없을 때만 보여주며 불투명도를 낮춰 비활성 상태로 표현. 장비 착용 시 숨기고 해당 메이플 에셋 아이콘을 표시. 다리 별도 슬롯은 현재 데이터에 없으므로 새 장비 슬롯을 임의 추가하지 않는다.

## 공통 UI 적용

- quickslot-frame: 아이템·스킬 칸 공통 외곽 틀. 학습한 스킬만 선택 가능하게 하고 미학습 스킬은 비활성/잠금 상태로 표시.
- minimap-frame: 맵 그림과 플레이어·NPC·출구 마커는 코드에서 구성. 틀 이미지만 바꾸는 것으로 미니맵 기능이 생기지는 않음.
- panel-frame: 인벤토리, 능력치, 스킬트리, 그림자 보관함, NPC 대화, 퀘스트 상세에 재사용. 배경은 어두운 면을 별도로 깔고 테두리를 겹친다. 장식이 찌그러지지 않도록 비율 유지 또는 실제 경계에 맞춰 9-slice 분할 후 사용.
- button-frame: 메뉴 버튼·탭·퀘스트 항목 공통. 선택 상태는 코드에서 청동/보라색 강조, 비활성 상태는 어둡게.
- region-banner: 첫 입장과 맵 변경 시 상단 중앙 약 2초 맵명 표시. 맵명을 별도 텍스트로 올린다.
- menu-inventory/menu-skills/menu-stats/menu-shadow/menu-quest: 모바일 통합 메뉴와 PC 메뉴 동일 아이콘.
- quest-marker: 퀘스트 추적·NPC 안내 마커. NPC 자체 이미지는 제공 에셋 활용.
- skill-*: skills.csv의 구현된 스킬용 고유 아이콘. 이름의 하이픈을 언더스코어로 바꾸면 데이터 id와 대응한다. skill-locked는 미구현 노드의 잠금 표시용 공통 아이콘이며 특정 스킬 그림을 대체하는 활성 아이콘으로 사용하지 않는다.

## 검증 범위

PNG 크기·알파와 메이커 업로드 결과/RUID를 확인한다. 실제 게임 HUD 연결, 모바일 터치 동작, 미니맵과 퀘스트 기능은 Claude 연결 후 별도 화면 검증 필요.

현재 업로드 확인 상태 및 리소스 ID는 같은 폴더의 RUIDS.csv, 원본 작업 프롬프트는 prompts.json, 사용 PNG는 png/에 정리.

## 현재 상태

PNG 42개 제작 및 메이커 My Resources 등록 완료. 각 업로드 성공 화면과 Copy RUID로 실제 ID를 확인했고 RUIDS.csv 42행에 기록했다. 메이커를 강제 종료 후 재로그인해 복구했으며 현재 정상 응답한다. 업로드는 메이커의 파일 가져오기로 수행했다. MCP upload_sprite는 이전 멈춤 원인이므로 재사용하지 않는다.

게임 코드와 UI 엔티티는 수정하지 않았다. Claude가 RUIDS.csv를 기준으로 연결한 뒤 Codex가 PC·모바일 화면을 검증한다. 모바일 버튼의 터치 영역은 최소 44 논리 픽셀을 시작 기준으로 잡고 실제 기기에서 오입력·겹침을 확인한다. 이미지 픽셀 크기와 화면의 터치 크기는 별개다.

오브 레이어 순서는 빈 배경 → 액체 채움 → 프레임이며, 프레임 256×256 안에 240×240 이미지를 중심 정렬하면 각 변의 여백은 8픽셀이다. 퀵슬롯은 학습·해금 상태와 사용자 선택을 반영하고 집결 등 고레벨 스킬을 기본 활성 슬롯으로 고정하지 않는다.
