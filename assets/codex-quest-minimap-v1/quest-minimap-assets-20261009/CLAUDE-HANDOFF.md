## CSV만 넣으면 바뀌는 부분과 추가 연결이 필요한 부분

### 의뢰 12장

`RootDesk/MyDesk/UI/Windows/QuestWindow.mlua:85`는 이미 `quest_artN` / `quest_art_grayN`을 조회하고, 비어 있으면 컬러 → `icon_quest`로 대체한다. 기본 이미지 가져오기 후 실제 RUID를 `data/ui_icons.csv`에 입력하고 프로젝트의 데이터 재생성·메이커 적용 절차를 진행한다.

CSV 형식은 **`key,ruid,color,alpha,note`**. 예:

```csv
quest_art1,<메이커에서 복사한 실제 RUID>,#FFFFFF,1,의뢰 그림 1 (코덱스)
```

`RUIDS-PENDING.csv`는 입력 준비표다. RUID가 빈 상태이므로 운영 CSV로 그대로 복사하지 않는다. 가짜 RUID를 생성하지 않았다.

주의: `QuestWindow.mlua:89`는 잠긴 그림을 여전히 `Color(0.22,0.22,0.24,1)`로 어둡게 칠한다. 흑백판까지 적용하면 매우 어두워질 수 있으므로 메이커에서 읽히는지 확인하고, 필요하면 흑백판을 쓰는 경우의 틴트를 조절한다.
